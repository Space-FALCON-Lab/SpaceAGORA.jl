# gnc/internal/

## Purpose
Bridge helpers that let the newer guidance and control code read the legacy configuration and solution records without depending on their layout directly.

## Design & Implementation
`_bridge_get_cnf` and `_bridge_get_solution` locate the records; `_bridge_required_field` and `_bridge_optional_field` read them; the `_bridge_aerobraking_*` accessors expose body shape, dry mass, entry and exit interfaces, heat-rate limit, thrust angle, topography and integrator name.

Simulation Setup API

This page documents the stable exported interface available from SpaceAGORA.

Simulation Setup

SpaceAGORA.SimulationModel.SimConfig.SimulationConfiguration — Type

Complete one-run scenario: simulation settings, mission configuration, environment, dynamics, guidance, navigation and control models, initial time, and integration tolerances. Pass it to run_simulation.

source
SpaceAGORA.SimulationModel.SimConfig.MissionConfiguration — Type

Mission length and bookkeeping: mission_type (MissionTime or MissionOrbits), mission_time, number_of_orbits, keplerian, orientation_sim, and num_steps_to_save.

source
SpaceAGORA.SimulationModel.SimConfig.MissionType — Type

Enum selecting how a mission ends: MissionTime (fixed duration) or MissionOrbits (fixed orbit count).

source
SpaceAGORA.SimulationModel.SimConfig.MissionTime — Constant

MissionType value: the mission ends after MissionConfiguration.mission_time seconds.

source
SpaceAGORA.SimulationModel.SimConfig.MissionOrbits — Constant

MissionType value: the mission ends after MissionConfiguration.number_of_orbits orbits.

source
SpaceAGORA.SimulationModel.SimConfig.EnvironmentModel — Type

Planet, atmosphere density model, ephemerides model, thermal model, entry-interface altitude EI (km), and topography/wind switches for a run.

source
SpaceAGORA.SimulationModel.SpacecraftModels.DynamicsModel — Type

Dynamics model of a run: the spacecraft list and the tuple of force/torque effectors, DynamicsModel([spacecraft], effectors).

source
SpaceAGORA.SimulationModel.SpacecraftModels.GuidanceModel — Type

Guidance effectors and their update rates for a run (guidance_effectors, guidance_rates).

source
SpaceAGORA.SimulationModel.SpacecraftModels.NavigationModel — Type

Navigation effectors and their update rates for a run (navigation_effectors, navigation_rates).

source
SpaceAGORA.SimulationModel.SpacecraftModels.ControlModel — Type

Control effectors and their update rates for a run (control_effectors, control_rates).

source
SpaceAGORA.SimulationModel.SpacecraftModels.SpacecraftModel — Type

Multi-link spacecraft: joints, links, root link, mass properties, propellant mass, initial condition, and id. Build the links with Link and Joint, or use make_three_body_spacecraft.

source
SpaceAGORA.SimulationModel.SpacecraftModels.Link — Type

One rigid body of a SpacecraftModel: mass, dimensions, reference area, offset r, attitude q, and reflection coefficient. Exported at the root; note that other packages may also export a Link name.

source
SpaceAGORA.SimulationModel.SpacecraftModels.Joint — Type

Articulated connection between two Links of a SpacecraftModel. Exported at the root; note that other packages may also export a Joint name.

source
SpaceAGORA.SimulationModel.SpacecraftModels.InitialCondition — Type

Initial orbit of a spacecraft from Keplerian elements (ra, rp, i, ω, Ω, ν).

source
SpaceAGORA.SimulationModel.SpacecraftModels.CartesianInitialCondition — Type

Initial spacecraft state given as a Cartesian position and velocity.

source
SpaceAGORA.SimulationModel.SimConfig.InitialTime — Type

Epoch at which a simulation starts (calendar date and time).

source
SpaceAGORA.SimulationModel.SimConfig.IntegrationTolerances — Type

ODE solver tolerances and maximum step sizes for the orbit and atmosphere phases (reltol_*, abstol_*, dt_max_*).

source
SpaceAGORA.SimulationModel.SimulationCallbacks.SaveField — Type

Declaration of one quantity written to the saved results.

source
SpaceAGORA.SimulationModel.SimulationCallbacks.default_save_fields — Function
default_save_fields(config::SimulationConfiguration)

Return the default SaveFields for config.

source
SpaceAGORA.SimulationModel.VehicleThermalModels.MaxwellianHeat — Type

Free-molecular heating model with a thermal accommodation factor (thermal_accomodation_factor) for a given planet.

source
SpaceAGORA.SimulationModel.DynamicEffectors.GravityEffectors.InverseSquaredGravityModel — Type

Point-mass (inverse-square) gravity effector.

source
SpaceAGORA.SimulationModel.DynamicEffectors.GravityEffectors.InverseSquaredJ2GravityModel — Type

Point-mass gravity with the J2 oblateness term.

source
SpaceAGORA.SimulationModel.DynamicEffectors.PerturbationEffectors.NBodyGravityModel — Type

Third-body gravity effector using ephemerides for the listed bodies.

source
SpaceAGORA.SimulationModel.ExampleConfiguration.make_example_config — Function
make_example_config(; planet, spacecraft, mission_time, initial_time, kwargs...) -> SimulationConfiguration

Build a single-spacecraft SimulationConfiguration with sensible defaults (J2 gravity, no atmosphere, SPICE ephemerides, Maxwellian heating, tight integration tolerances). Override dynamic_effectors, density_model, ephemerides_model (e.g. SimpleEphemeridesModel() for no SPICE), results, verbose, and solver_config as needed.

source
SpaceAGORA.SimulationModel.ExampleConfiguration.make_three_body_spacecraft — Function
make_three_body_spacecraft(; bus_dims, panel_dims, bus_mass, panel_mass_each,
                             panel_offset_y, ic, kwargs...) -> SpacecraftModel

Build a bus-plus-two-panel spacecraft (three Links, no joints) from box dimensions and masses. panel_dims[2] is the per-wing half-span. See the source comments for the bus_ram_face and attitude-quaternion options.

source

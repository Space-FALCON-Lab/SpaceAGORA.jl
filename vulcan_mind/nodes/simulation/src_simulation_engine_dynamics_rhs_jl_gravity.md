# simulation/engine/dynamics_rhs.jl · _gravity*

## Purpose
The split solver's gravity backbone: static-gravity acceleration for the implicit step and explicit velocity kicks for third-body forces, with state extraction from the solver's separate arrays.

## Design & Implementation
`_gravity_backbone_core_acceleration` and `_gravity_backbone_kick_acceleration` sum the classified effectors; `_gravity_backbone_half_kick!` applies the kick; `_gravity_backbone_state_sample` and `_gravity_backbone_xyz_chunk` read the position and velocity arrays under any layout.

# simulation/engine/solver_policy.jl

## Purpose
Chooses and configures the ODE solver for a run: auto-stiff switching, the split fast/slow multirate form, the IMEX partition, and the gravity-backbone second-order form, with the checks that decide when each is applicable.

## Design & Implementation
Mode parsers and `_build_solver_tolerances`; `_auto_stiff_*` detect smooth-gravity cases and switch algorithms; `_multirate_*` build the split problem; `_gravity_backbone_*` validate effector structures, build the partitioned second-order problem and manage fixed-step kicks; `_cache_integrator!` retains the integrator across segments.

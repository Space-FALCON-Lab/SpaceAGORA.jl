# JupiterGRAM

Targets:
* all: builds all of the following
* gram: builds the JupiterGRAM namelist program
* examples: builds the C++ JupiterGRAM examples
* cexamples: builds the C JupiterGRAM examples
* fexamples: builds the FORTRAN JupiterGRAM example
* clean: deletes libraries, object files, and executables.

# analysis/verification/telemetry_verification/error_tables.jl

## Purpose
Produces the per-channel error summaries and residual rows for both scenario kinds, the hand-off between running and reporting.

## Design & Implementation
`_orbit_rows_errors` handles apsis-event scenarios and `_time_aligned_rows_errors` handles time-aligned state scenarios, each applying biases, frames and altitude modes and calling the comparison metrics; `_telemetry_altitude_km` converts states to the scenario's altitude convention and `_tolerances_for` picks the quick or full tolerance set.

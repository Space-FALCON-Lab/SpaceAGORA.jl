## Findings

No unresolved correctness findings. Independent review identified and repaired:

1. Relative duration addition could round one ULP beyond a valid horizon, such
   as 0.1 + 0.2 at 0.3 seconds. Finite relative deadlines may now snap by one ULP;
   explicit deadlines and materially late transitions remain strict.
2. Ensemble export initially omitted the new mission sidecar from its protected
   inputs. Every sample's history is now protected, including symlink and
   hardlink aliases, with public-export regression coverage.
3. In the companion, a selector retaining its active value prevented jumping to
   the current segment's start or repeating a transition jump. Jump selectors
   now reset to a prompt; the active segment has its own live label. Real-browser
   tests exercise both repeated actions.

One solve owns physical state, caches and controller lifecycle. Segment actions
operate on run-owned command handles; no generic GNC wrapping, configuration
replacement or physical state reset is introduced. Conditions use immutable
numerical spacecraft samples and copied full state, enforce a finite scalar and
an unsatisfied starting side, and preserve directed root semantics. Commands
invalidate cached derivatives after transitions. Priority callbacks precede
ordinary discrete control and saving; continuous callbacks retain solver event
ordering. Finalization closes the active segment once at actual solver end.
Propagation errors still throw.

Mission metadata preserves actual times independently of telemetry cadence.
Export retains exact boundary rows when present and refuses an insufficient
frame budget. No missing pose is synthesized. Old payloads retain their existing
behavior; schema and service version remain 1 with an optional mission block.
Core and companion Julia validators match, and JavaScript enforces the same
history relationships. Names and reasons reach the DOM through textContent.

## Residual Risk

Command actions are application-specific and must clear any held actuation that
should end; the executor does not automatically deactivate arbitrary controllers.
Reference changes take effect according to their controller's evaluation cadence.
External MuJoCo state, physics-ownership transfers, checkpoint resume and other
solver modes remain unsupported. Exact history can outlast saved trajectory
coverage; those viewer jumps are visibly unavailable. User actions and predicates
must obey their ownership and purity contracts. Local tests do not replace hosted
native, coverage, optional-package and documentation gates.

## Companion precision repair

GitHub review identified a saved Float32 boundary, such as 0.7 seconds, being
misclassified as outside playback coverage. The companion now reconciles a
mission time only when its Float32 value occurs exactly in a finite,
nondecreasing saved grid. Bounds, seeking and active-segment lookup share this
mapping. Float64 times, missing values and invalid grids stay strict; original
mission metadata and saved poses are unchanged. An independent reader reviewed
the final source and verified renderer provenance.

The repair passed 168 Julia assertions, 22 JavaScript tests, 17 Python packaging
tests and six offline browser scenarios (four precision regressions plus
existing mission and no-history playback). Tests cover both rounding directions,
first/internal/final boundaries, collapsed boundaries, repeated jumps, strict
Float64 differences and truly uncovered times. No network requests or browser
errors occurred. The companion repair changes playback comparisons only; the subsequent core
provenance repair is reviewed below. Hosted documentation passed at the preceding core head
796d8c4; final published heads still require their own CI.

## Saved-history provenance repair

GitHub review identified stale history being auto-attached after an ordinary
simulation reused a mission output folder. The result manifest now owns a
relative history-file association with streaming SHA256 checks of history,
scene and Arrow content. Both saved-payload and development exports use that
association. Unbound sidecars are left untouched and never auto-attached; a
mismatched owned association fails before replacing viewer output. Explicit
caller-provided history remains supported. Complete relocated bundles retain
their association.

Canonical result persistence invalidates only the owned manifest field before
writing, including CSV-only and partial-failure output paths. Typed result
writes produce a fresh manifest without a history association. Results-disabled
runs leave the previous saved bundle intact. MissionRun binds history only
after this run produced its own manifest and scene; scene-disabled histories
remain readable without being attached to another scene. History files are
written atomically. Manifest, history and trajectory inputs are protected from
output overwrites, including filesystem aliases in ensemble exports.

An independent reviewer checked ownership, writer placement, both reader paths,
streaming digests, moved folders, input preservation and the final regressions.
The repaired source passed 1,488 output/persistence assertions and all 499
mission assertions. Real callback failures exercise both typed and CSV-only
partial persistence. The public companion passes both extension load orders
(47 assertions each), and the documented mission runs to 120, 180 and 300-second
segment boundaries with independently verified saved-file hashes and HTML
rendering. The three source-architecture gates pass. No equations, numerical
settings, schema version or renderer protocol changed. Hosted checks on the
final published head remain required.

# GRAM

Targets:
* all: builds all of the following
* lib: builds the GRAM namelist program (all GRAMs combined)
* examples: builds the C++ GRAM examples (all GRAMs combined)
* allgrams: builds the GRAM program (all GRAMs combined)
* gram_c: builds the example of the generic C interface
* clean: deletes libraries, object files, and executables.

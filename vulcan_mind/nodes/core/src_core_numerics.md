# core/numerics/

## Purpose
Quaternion and rotation primitives — multiplication, error quaternion, DCM conversion, Euler angles, the hat operator and unit projection — used by attitude dynamics and control.

## Design & Implementation
Seven small functions on static vectors and matrices in the project's scalar-last quaternion convention. `dcm_to_quaternion` is the stable largest-trace branch form; `project_unit_quaternion` renormalises after integration; `hat` builds the skew matrix for cross products.

# gnc/guidance/rpo/hypr/rrt_connect.jl

## Purpose
RRT-Connect and RRT* planners in the RTN frame, used to warm-start the swarm and as a comparison baseline.

## Design & Implementation
`RPORRTConnectSettings` and tree types; random state sampling within bounds, nearest and near queries, steering with collision-checked extension, bidirectional connect, path reconstruction and shortcutting; `rpo_rrt_star_plan_path` adds rewiring; `rpo_rrt_connect_bezier_plan_path` fits the result for the swarm.

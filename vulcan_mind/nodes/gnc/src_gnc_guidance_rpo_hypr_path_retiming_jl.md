# gnc/guidance/rpo/hypr/path_retiming.jl

## Purpose
Turns a geometric path into a timed reference by assigning speeds along arc length under curvature limits.

## Design & Implementation
`rpo_arc_length_params` and `rpo_interpolate_along_path` parameterise the path, `rpo_curvature_from_samples` estimates local curvature, `rpo_remove_near_duplicate_samples` cleans the input, and `rpo_retime_path` produces the time-stamped reference.

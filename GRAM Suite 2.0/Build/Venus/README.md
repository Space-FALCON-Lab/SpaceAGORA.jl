# VenusGRAM

Targets:
* all: builds all of the following
* gram: builds the VenusGRAM namelist program
* examples: builds the C++ VenusGRAM examples
* cexamples: builds the C VenusGRAM examples
* fexamples: builds the FORTRAN VenusGRAM example
* clean: deletes libraries, object files, and executables.

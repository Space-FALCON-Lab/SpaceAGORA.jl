# GRAM (all planets)

To build GRAM using a Linux/MinGW makefile, navigate to the folder /GRAM/Builds and follow the README instructions.

To build GRAM using MSVC++ 2017 or 2015, follow the instructions in the README file in \GRAM\MSVS.

Files and Subfolders:
- examples: Examples using multiple or all planet models.
- sample_inputs: Sample input files.

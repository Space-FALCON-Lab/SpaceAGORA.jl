# TitanGRAM

Targets:
* all: builds all of the following
* gram: builds the TitanGRAM namelist program
* examples: builds the C++ TitanGRAM examples
* cexamples: builds the C TitanGRAM examples
* fexamples: builds the FORTRAN TitanGRAM example
* clean: deletes libraries, object files, and executables.

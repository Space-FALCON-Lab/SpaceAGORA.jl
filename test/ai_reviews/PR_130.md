## Findings

The record function now executes each fallback getter independently of whether built-in fields were fused. Explicit field lists keep their getter semantics.

Resolved: explicit capacity bypassed sampling-rate validation. All construction paths now reject zero, negative and nonfinite rates with ArgumentError.

Default built-in output calculations were compared statically with the existing SaveField getters. The contributor's integrated unit test compares snapshots in a vacuum translational scenario. Broader attitude/thermal and combined-PR compatibility are not inferred from that case.

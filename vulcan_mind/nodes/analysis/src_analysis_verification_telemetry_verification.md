# analysis/verification/telemetry_verification/

## Purpose
The telemetry verification pipeline: from a TOML manifest of flight scenarios to a scored comparison of simulated versus measured orbits.

## Design & Implementation
Reads left to right as manifest parsing → scenario builders (a runnable `SimulationConfiguration` per scenario) → runner (one or many simulations) → telemetry loading and comparison metrics (aligned residuals and apsis extrema) → error tables and optional calibration (drag-scale, reflectivity, bias fits) → reporting (summary and error CSVs, plots, tolerance verdicts).

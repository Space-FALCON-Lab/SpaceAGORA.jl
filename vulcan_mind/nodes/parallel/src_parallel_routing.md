# parallel/routing/

## Purpose
Outer routing: chooses serial, threaded or process execution for a whole campaign from a learned bandit over workload features, and maps named parallel profiles onto environment settings.

## Design & Implementation
`profile_definitions.jl` enumerates the R0–R5 profiles; `env_mapping.jl` turns a profile into environment pairs and applies them; `outer_route_state.jl` holds the learned statistics and persists them; `outer_route_selection.jl` scores candidate routes and records feedback.

## Limitations
Feedback is amortised wall-clock per sample, so a campaign whose samples vary widely in cost trains the bandit on a noisy signal.

# core/types/abstract_types.jl

## Purpose
The abstract supertypes that let multiple dispatch select an implementation: planets, density, thermal, ephemerides, force-torque, guidance, control and thruster models.

## Design & Implementation
Eight `abstract type` declarations in the `AbstractTypes` module, each the root of one model family. Every concrete model in the repository subtypes one of these, and every engine hook dispatches on them.

# Windows Executables

These exectuables were created on Windows 10 using MSVS 2017.

To build your own executables on Windows, check out the README file in GRAM\MSVS.

Files and Subfolders:
- VenusGRAM.exe: The VenusGRAM 2023a exectuable.
- EarthGRAM.exe: The EarthGRAM 2023 exectuable.
- MarsGRAM.exe: The MarsGRAM 2021b exectuable.
- JupiterGRAM.exe: The JupiterGRAM 2021a exectuable.
- NeptuneGRAM.exe: The NeptuneGRAM 2019d exectuable.
- UranusGRAM.exe: The UranusGRAM 2021b exectuable.
- TitanGRAM.exe: The TitanGRAM 2020c exectuable.
- EarthCorrMonte.exe: The Earth CorrMonte exectuable.
- EarthCorrTraj.exe: The Earth CorrTraj exectuable.
- MarsRad.exe: The Mars solar and thermal radiation exectuable.

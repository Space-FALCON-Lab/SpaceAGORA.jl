Detailed Description

Generate a Monte Carlo of profiles.

The MonteCarlo class will generate a number of profiles each with a different random pertubation seed. The class requires a Profile, such as a Trajectory, and a PrinterProfile which have been initialized for use.

Examples
common/examples/MonteCarloExample.cpp, and common/examples/NamelistExample.cpp.

◆ generate()

void GRAM::MonteCarlo::generate ( )
virtual

Generate the Monte Carlo data.

This method will generate the specified number of profiles. Each profile will be given a different perturbation seed. The profile data will be passed to the ProfilePrinter for output. This routine does not store the generated data.

Examples
common/examples/MonteCarloExample.cpp, and common/examples/NamelistExample.cpp.

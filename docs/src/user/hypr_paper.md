# HyPR paper reconstruction

The reconstruction of the final iSpaRo HyPR experiment, with its saved inputs,
is kept in the private SpaceAGORARPOStudies repository. Lab members with
access use its pinned environment and reconstruction guide for the scientific
assumptions and the commands; outside collaborators need an invitation. The
reconstruction is not an exact reproduction of the original paper datasets.

This repository keeps the general RPO examples: MPC tracking, batch runs,
disturbances and replanning. For a new application, start with
[the planner guide](rpo_planner_pilot.md). The HYPR guide's section
[Relating a run to the paper](hypr_planning.md#Relating-a-run-to-the-paper)
explains how a run relates to the paper, and
[the example catalog](examples_catalog.md) lists the maintained
demonstrations.

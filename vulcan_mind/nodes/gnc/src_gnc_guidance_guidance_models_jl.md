# gnc/guidance/guidance_models.jl

## Purpose
The `GuidanceModels` module file that declares the guidance-effector interface every guidance model implements and includes the concrete models in dependency order.

## Design & Implementation
Declares the module, defines the `calcGuidanceEffect!` generic with an inert fallback so an effector without guidance behaviour is legal, and includes the energy-depletion bracketing model, the thruster guidance models and the RPO guidance hooks. The engine's guidance callback iterates the configured effectors and calls this generic on each at its own rate.

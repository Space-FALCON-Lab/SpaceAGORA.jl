# simulation/engine/setup.jl · _dynamic*

## Purpose
Effector-level threading: whether the dynamic effectors are thread-safe and parallelisable, and the per-call decision on how many workers to use for them.

## Design & Implementation
`_dynamic_effector_threadsafe` is a per-type predicate, `_dynamic_effectors_parallel_supported` requires all effectors to pass it, and `_dynamic_effector_thread_decision` consults the policy with the effector cost model to produce the decision record embedded in the execution plan.

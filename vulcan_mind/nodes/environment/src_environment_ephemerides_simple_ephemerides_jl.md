# environment/ephemerides/simple_ephemerides.jl

## Purpose
An analytic ephemerides model that needs no SPICE kernels: uniform planet rotation about a fixed pole from a reference epoch.

## Design & Implementation
`SimpleEphemeridesModel` stores the reference epoch seconds; its `planet_frame_lpi` builds a z-rotation from the elapsed angle, `ephemerides_time_seconds` counts seconds since J2000 UTC, and `ephemerides_requires_spice` returns false so the engine skips kernel-dependent caches.

## Limitations
No precession, nutation or polar motion, and no Sun or third-body positions — SRP and N-body effectors need SPICE.

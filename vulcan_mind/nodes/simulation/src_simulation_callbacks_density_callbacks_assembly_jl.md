# simulation/callbacks/density_callbacks/assembly.jl

## Purpose
Decides which callbacks a run needs from its configuration and assembles them into the callback set handed to the solver.

## Design & Implementation
A family of `_requires_*` predicates — density, staged density, drag state, entry end, orbit end, thermal, quaternion projection, guidance orbit counter — feed `_append_callback` and `_append_callbacks`; `_callback_tolerances_for_phase` and `_resolved_component_tolerances` size event tolerances per mission phase.

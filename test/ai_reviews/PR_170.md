# PR170: solver migration with nonlinear and atmospheric-phase repairs

## Scope

Resolve LinearSolve 5.18.1 with compatible OrdinaryDiffEq 7, DiffEqBase 7, SciMLBase 3 and SatelliteToolbox dependencies. Integrate main `3287f0fc145d779ce3bd0ac608eb3352d671b85e`, including PR171, PR172, PR174 and PR175, and the separately prepared atmospheric phase repair `b2f83f960b450fbf5e89b97f22424f45552bd56f`. Preserve componentwise ODE tolerances, SolverConfig.parallel, the dense/default versus sparse/KLU choices, Plots 1.41.7 and the EDL study's independent NetCDF graph.

KenCarp4 remains the default split method and uses `NLNewton(always_new=true)`. KenCarp47, KenCarp58 and other solver modes retain their existing nonlinear policies. Atmospheric settings now follow the aggregate active phase at startup, crossings, deactivation, reuse and checkpoint boundaries. This changes numerical results while preserving the configured tolerance values and physical models. The EDL study uses its repository-relative GRAMSuite path.

- `src/simulation/callbacks/event_callbacks.jl`: adapt signed simultaneous vector events, reconcile atmospheric flags and settings, preserve direction filtering and avoid derivative discontinuity notifications when no effect runs.
- `src/simulation/callbacks/state_anchor_callbacks.jl`: use the renamed derivative-discontinuity notification.
- `src/simulation/engine/setup.jl`: import the existing algorithms and KenCarp4 Newton policy binding; initialize phase flags for ordinary and partitioned state.

- `src/simulation/engine/solver_policy.jl`: adapt linear-system tolerances on an owned type, retain backend selection, refresh KenCarp4 Jacobians, apply startup settings and safely refresh reused physical callbacks for both erased and full-specialization storage.
- `src/dynamics/coupled/perturbations.jl`: retain the existing magnetic-library warning policy through its Val API.

Dependency files, development SGP4 API changes, regression tests and solver documentation complete the migration. No project or manifest bytes changed during the atmospheric follow-up relative to `e292746a03c8e3d52c877f4a1b86c7c94f0b03e0`.

## Findings

Claude's original independent review identified the study-path defect and nonlinear atmospheric regression missed by a linear probe. The path is repaired and the KenCarp4-only fresh-Jacobian policy improves the original nonlinear case. Applying that policy to every KenCarp algorithm was rejected because the shifted-time KenCarp47 analytic probe worsened; its established policy remains protected by tests.

The expanded 110 km case previously failed its 5e-5 m/s velocity limit. Claude subsequently reproduced the archived endpoints and confirmed that initially atmospheric runs still received the orbital cap. Old main also failed that same case more severely: against the tightened reference, its original policy produced 0.07234408 m position error and 5.457919e-4 m/s velocity error. The migrated original policy produced 150.622887 m and 1.323574 m/s; migrated fresh Jacobians reduced those errors to 0.001118482 m and 7.289408e-5 m/s before the phase repair. The earlier claim that the old-policy comparison covered only 130 km is superseded by that completed investigation.

The separate repair now covers actual initial state, mixed active members, crossings, deactivation, reuse and checkpoints. Checkpoint segments previously restarted with orbital settings. Explicit multirate subsolve overrides now restore their supplied cap and tolerances at every subsolve, changing physical multirate runs that previously inherited crossing settings across subsolves. Fixed-step drivers are exempt from adaptive phase updates; the pre-existing atmospheric gravity-backbone density-callback failure is outside this repair. Old solver libraries can omit identical simultaneous callbacks, so phase flags are reconciled from event geometry. Current callbacks are initialized before a reused integrator estimates its initial step. PR170 additionally needs compatibility handling for erased callback storage. Reuse is rejected when callback layout, vector length, discontinuity structure or a retained root condition changes, preventing stale callback caches.

The atmospheric mask is reconciled once, with every delivered event direction authoritative for its spacecraft. This prevents large-epoch root roundoff from allowing a later member to overwrite an earlier member's flag. Exit-cache invalidation and thruster scheduling still run for every delivered exit. The vector-event migration applies all exactly simultaneous events. Ignored-direction roots can still add internal steps or saved points. Cross-version internal-step or saved-row identity is not promised.

## Residual Risk

These bounded fixtures do not establish full-duration native GRAM mission accuracy or a general global-error bound. Strongly cancelling split problems retain a separately documented accuracy limitation. Fresh Jacobians and factorizations add work; large-constellation runtime cost has not been measured. Callback reinitialization intentionally repeats initialization hooks at reused physical-run and checkpoint boundaries; user callbacks with side effects merit review. Independent acceptance of the final candidate and fresh Linux CI, including coverage, remain required before merge.

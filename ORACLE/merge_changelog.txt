Why the ORACLE folder stays in this repo
================================================================================
ORACLE is research/application code that USES SpaceAGORA — it is not part of the
SpaceAGORA library itself and will never live in src/.  It is analogous to the
examples/ folder but for a full paper simulation.

  run_case2_laser_links.jl        -- simulation driver for the laser-links paper
  functions/                      -- mission-specific config, analysis, and plot helpers
  post_processing/                -- standalone scripts that read feather output files
  Paper_Numerical_Verification_Code/ -- conservation-law verification runs for the paper

It stays here (rather than a separate repo) because:
  1. It depends on include(common.jl) and SpaceAGORA internals that are not yet
     stable public API.
  2. Co-location makes it easy to keep in sync as SpaceAGORA's API evolves.

Future: once the paper is published and SpaceAGORA's API stabilises, ORACLE can
be spun out into its own SpaceAGORAOracle.jl repo with SpaceAGORA as a dependency.

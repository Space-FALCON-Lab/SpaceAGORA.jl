# analysis/verification/telemetry_verification.jl

## Purpose
The module file that assembles the telemetry verification package by including its component files in dependency order.

## Design & Implementation
Declares `TelemetryVerification`, imports the simulation model, DataFrames, CSV and Arrow, defines the repository-root and default-path constants, and includes types, manifest parsing, telemetry loading, comparison metrics, scenario builders, error tables, calibration, reporting and the runner. Everything else in this block is reached through those includes.

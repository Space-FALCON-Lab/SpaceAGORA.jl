# simulation/engine/setup.jl

## Purpose
Everything that happens between receiving a configuration and the first RHS call: validation, buffer and cache initialisation, ephemeris tables, environment snapshots, and the routing chain that plans RHS execution.

## Design & Implementation
Grouped by prefix: `_validate_*` checks the configuration; `_initialize_*` fills shared buffers; `_nbody_*`, `_srp_*`, `_planet_*` and `_ephemeris_*` build and reuse ephemeris tables; `_effector_*` and `_rhs_*` read routing knobs and implement `_rhs_execution_plan`; `_dynamic_*` decide effector threading; `_typed_*` read output policy; `_parse_*` are environment parsers.

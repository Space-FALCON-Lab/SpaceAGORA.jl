# analysis/verification/telemetry_verification/calibration.jl

## Purpose
The optional calibration search that fits drag scale, solar reflectivity and per-event biases so a scenario's simulation best matches its telemetry before final scoring.

## Design & Implementation
`_grid_values` expands a min/max/steps triple, `_single_point_calibration` runs one candidate and scores it with `_calibration_score` under the configured objective, `_estimate_event_biases` fits constant offsets per channel, and `_annotate_calibration_rows` writes the chosen values into the summary. `_calibration_active` gates the whole thing on the manifest's `calibration.enabled`.

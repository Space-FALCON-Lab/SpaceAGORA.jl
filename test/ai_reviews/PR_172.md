# PR 172: advanced surrogate route and data terms; two install warnings removed

## Scope

This closes the remaining Odyssey-preset documentation items and removes two warnings every fresh installation printed:
- the stale root-manifest warning;
- the density-without-drag diagnostic during precompilation.

Reviewed: the whole diff against `main`, the `_engine_env_get` and `_engine_env_get_with_env_fallback` semantics, the tests and CI steps that depend on the diagnostic, and the manifest change against `Project.toml`.

## Changed Files

- `src/simulation/engine/setup.jl`: `_density_without_aero_warning_enabled` reads `SPACEAGORA_WARN_DENSITY_WITHOUT_AERO` with `_engine_env_get_with_env_fallback`, so the process environment is honoured inside an active `SimulationEngineConfig` override scope.
- `src/precompile_workload.jl`: the workload's `run_simulation` runs under `withenv("SPACEAGORA_WARN_DENSITY_WITHOUT_AERO" => "0")`. The workload propagates without aerodynamics on purpose.
- Also changed:
  - `Manifest.toml`: project_hash, plus `Artifacts` and `Pkg` in SpaceAGORA's deps line;
  - `test/probes/coverage_targeted_90_probes.jl`;
  - `examples/odyssey_surrogate.jl`: script-mode input errors print one line;
  - docs: `docs/src/user/atmosphere_models.md`, `docs/src/tutorials/odyssey_surrogate.md`, `docs/src/assets.md`, `docs/src/extensibility.md`.

## Findings

- P2 (fixed in this PR), `src/simulation/engine/setup.jl`: the diagnostic's documented switch was ignored in every run that passes an engine config. `_engine_env_get` returns the override-set value or the default and never consults `ENV` while overrides are active. The switch is not part of the canonical override set, so users could not silence the diagnostic there, and the precompile workload printed it for every installation. The env-fallback getter is the one already used for the solver save switches.
- P3 (fixed in this PR), `Manifest.toml`: the committed manifest predated the `Artifacts` and `Pkg` dependencies, so `project_hash` was stale and every instantiate warned. Both packages already had manifest entries, so only the deps line and the hash change, with no version changes.
- Checked, no finding: nothing in `.github`, the test runners, scripts or examples sets `SPACEAGORA_WARN_DENSITY_WITHOUT_AERO` globally. The existing tests that expect the warning (`test/smoke/ci_no_gram_smoke.jl`, `test/probes/ei_partition_drag_probes.jl`) run with it unset, so the default still warns.
- Checked, no finding: the example's script-mode handler catches only `ArgumentError`; other errors are rethrown with their traces.

## P1 Assessment

No P1 findings. The code changes affect whether one diagnostic is printed, and the precompile workload's logging. Simulation numerics, defaults and outputs are unchanged.

Unresolved P1: No

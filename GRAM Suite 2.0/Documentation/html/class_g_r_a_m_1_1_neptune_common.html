Detailed Description

Common values for the Neptune atmosphere models.

Common values for the Neptune atmosphere models. All Neptune atmosphere models should inherit this class.

(1) Data from NSSDCA Planetary Fact Sheet for Neptune (https://nssdc.gsfc.nasa.gov/planetary/factsheet/neptunefact.html). Page last updated on Sept 27, 2018.

(2) Data from NAIF Spice files (nep081.cmt).

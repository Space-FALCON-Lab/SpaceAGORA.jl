# analysis/verification/telemetry_verification/runner.jl

## Purpose
The orchestration layer: select scenarios, run each simulation once or with a calibration search, collect error rows, and return or write the study result.

## Design & Implementation
`run_verification` and `run_verification_cli` are the entry points; `_run_verification` iterates `_select_scenarios`, `_run_single_scenario` builds the configuration and calls `_run_once` or `_final_run_or_reused_eval`, and `_run_simulation_dataframe` wraps the engine and reads the CSV back. `run_study` is the older name kept for scripts.

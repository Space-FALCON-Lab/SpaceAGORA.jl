## Residual Risk

- Seven registered public names still render placeholder documentation. They are exempted explicitly, and each will fail the build as stale once documented.
- Placeholder detection matches Julia's wording "No documentation found". A future Julia release that changes it would silently disable the text check; the `~1.12` bound limits this for now.
- Exemption keys use the owner module's short name. No two registered owners share one today, but a future owner with a duplicate short name could share an exemption.
- The public API checks run only in the docs build. A run that cannot complete that job (the authors report one external link-check timeout that passed on rerun) gets no protection from them.
- This review did not rerun the docs build, the gates or the test suites on `fcc9c5736` or `90b78ec82` (identical trees). It relied on the authors' logs, on targeted in-memory reproductions, and on the file-only docs contract gate.
- The HYPR adapter diagnostics (F8) were checked against a depot copy of the HYPR extension, not the pinned revision.
- The quickstart plot images were not inspected visually, and the quoted precompile warning was not reproduced.
- The strict CI instantiate ties CI to the manifest's minor version. The manifest and the CI Julia version must move together on the next minor release.
- #315 has merged into `main` (`b62e5f506`). Its content outside the items listed in Scope is outside this diff and this record.

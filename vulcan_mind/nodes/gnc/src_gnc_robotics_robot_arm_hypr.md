# gnc/robotics/robot_arm_hypr/

## Purpose
The obstacle-aware robot-arm motion planner: a particle swarm over joint-space control points, warm-started by joint-space RRT-Connect, scored on clearance, smoothness and the reaction wrench the arm would impart to the spacecraft bus.

## Design & Implementation
`config.jl` holds the settings, obstacle and result types; `rrt_warmstart.jl` finds a collision-free seed; `swarm_and_retiming.jl` provides culling, schedules, the base-wrench cost and speed assignment; `clearance.jl` scores collisions; `planner_core.jl` runs the search and returns a timed `RobotArmPlan`.

# PR178: Mars near-surface preset integration

## Scope

Independent Codex review of `7053318d846afbc0aab11c7b9ff0447979e446db` against main `3287f0fc145d779ce3bd0ac608eb3352d671b85e`. The PR adds a native-free near-surface adapter and named preset, with public GRAMSuite pinned to merged PR10 at `9d82cdbf73a8c8a21e36f6bd3dd6654fe2dfef4e`. This review covers the SpaceAGORA integration, distribution identities, compatibility and documentation. It does not repeat the completed native Mars-GRAM release-validation campaign or claim general mission accuracy.

The preset is a frozen scalar atmosphere. It returns zero wind, refuses unsupported queries, and does not cover the interval between its 75 km areoid-height top and the upper preset's 80 km floor.

## Changed Files

- `src/SpaceAGORA.jl`: expose and document `GRAMNearSurfaceAtmosphereModel` through the public API.
- `src/environment/atmosphere/gram_near_surface_atmosphere_model.jl`: define the adapter and the shared native-free snapshot union.
- `src/environment/atmosphere/surrogate_presets.jl`: dispatch by preset kind; validate terrain-following support, metadata and datum; construct the adapter and retain provenance.
- `src/environment/physical_models.jl`: include and export the new model in its owning module.
- `src/simulation/callbacks/density_callbacks/config.jl`: classify both owned snapshot models as safe for concurrent read-only evaluation.
- `src/simulation/callbacks/density_callbacks/runtime.jl`: bypass the vacuum trajectory cache for both snapshot models.
- `src/simulation/engine/effector_sampling.jl`: bypass held density samples, uniform light-model batching and equal-time buffers so every snapshot query sees its current coordinates.

Also reviewed: `ext/SpaceAGORAGRAMSuiteExt.jl` and `ext/gram_near_surface_atmosphere.jl` for optional API lookup and delegation; `data/surrogate_presets.toml` and `Artifacts.toml` for distribution contracts; `.github/gramsuite-revisions`, the `data/GRAMSuite.jl` gitlink and `examples/odyssey_surrogate_env/Project.toml` for consistent public pins; `test/surrogate_presets_tests.jl`, the public API registry and the three changed user-guide pages.

## Findings

No blocking findings in the reviewed standalone change.

- The adapter delegates units, coordinate conversion, evaluation and refusals to the pinned GRAMSuite implementation. The named-preset path verifies the payload identity, required metadata, support limits and reference radii before use. Unsupported kinds and policy overrides are rejected.
- Existing Odyssey and global-upper catalog entries are unchanged. Missing `kind` retains the existing grid behavior. The public package pin provides the near-surface API; a wrapper without that API retains a clear construction error. Its skipped near-surface model checks are not evidence of passing that API.
- The archive checksum advertised by GitHub matches both the artifact binding and catalog. The retained payload size and checksum match the catalog, and the evaluator source fingerprint matches the recorded provenance. The three public dependency pins agree on the merged evaluator commit. No native library is added by this PR.
- Independent current-coordinate probes confirm that stale buffers and enabled frozen-step or vacuum-cache options cannot hide a near-surface domain refusal. Batch calls and concurrent read-only queries agree with scalar calls, without loading native GRAM.

# parallel/policy/env_config.jl

## Purpose
Parsers for the parallel-policy environment variables and the derived defaults: thread budgets, modes, thresholds, adaptive gains and the persistent-hint path.

## Design & Implementation
Generic `parse_bool_env`, `parse_float_env`, `parse_nonnegative_int_env`, `parse_parallel_mode_env` and `parse_thread_threshold_env`; policy-specific readers such as `effective_inner_thread_budget`, `auto_thread_min_budget`, `inner_scheduler_mode` and `adaptive_rho`; `_snapshot_auto_min_budget` builds the run-scoped snapshot; `_safe_token` sanitises labels for signatures.

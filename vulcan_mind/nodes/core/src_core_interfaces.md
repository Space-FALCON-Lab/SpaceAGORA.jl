# core/interfaces/

## Purpose
Reference-frame and coordinate mathematics shared by every other module: inertial, planet-fixed, geodetic, orbital-element and RTN conversions.

## Design & Implementation
The `reference_system.jl` file provides SPICE-backed and analytic inertial↔planet-fixed transforms, Bowring's geodetic conversion, orbital-element↔Cartesian conversions with singular-case handling, LVLH and RTN frame builders, and the HCW relative-state transforms the RPO controller uses. It walks the module tree to find the process-wide SPICE lock because it is included at several depths.

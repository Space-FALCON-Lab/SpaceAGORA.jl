# PR 149: mission demonstrations and shared SPICE kernel compatibility

## Scope

Review of the mission demonstration extraction on top of viewer commit `2e4f3d4f005bb1f53143fa9ef76be2469404aedb`. The reviewed final source is `f0d4785e960d136297d133b9a50565278709b72e`, tree `69f4017448744807acf282d5391b00eb68408822`.

This package adds Magellan, Odyssey, Cassini TA/T5 and nominal Apollo lunar-orbit drivers, shared mission helpers and saved-output inspection. It also corrects Titan's text-PCK selection. The accepted viewer implementation, assets, basic drivers and shared option parser are unchanged. The viewer README is clarified and extended, and the unit-test registry gains the mission test.

The artifact author inspected the source, final diff, test registration and retained execution logs. The implementing agent executed the focused and full-duration runs. A second agent independently checked saved outputs against direct SPICE calls and independently located reference events. That second check reused the same kernel inputs; it was not a separate propagation or an independent flight-data validation.

Full-duration execution and the initial focused checks used `9abee82156c6508a3fc1c39d08b2aaad8c5bde93`, tree `25783785fd32b0e92f5a6ad37b022ed7c2ba82ea`. The final delta changes only README wording, explanatory/error text in the helpers, and the saved-output inspector's default directory. Production source, propagation drivers and tests are byte-identical between those revisions. The mission tests passed again on final head `f0d4785e`, 108/108 with exit 0; all 23 contract gates also passed on that head.

## Changed Files

- `src/environment/ephemerides/planets.jl`: Titan now requires `pck00011.tpc`, matching the modern text PCK used by the other constructors. Loading `pck00010.tpc` after `pck00011.tpc` could partially replace Mars's nutation/precession constants and break `IAU_MARS` in the process-wide SPICE pool.

This is the complete changed `src/**/*.jl` list relative to the viewer parent. Other changes are confined to `scripts/dev/viewer_demos/`, the reference-system probe, the mission unit test and its registration.

## Findings

- **Resolved P1, shared SPICE pool:** the retained negative control reproduces the mixed-PCK Mars frame error. Constructor-order regression tests now exercise Mars, Titan and Moon together, checking frames after each construction rather than only at the end. They also verify cache identity, stable kernel counts and a clean failure for an old-PCK-only asset directory.
- **Resolved P2, initial epoch consistency:** a searched SPICE epoch can be finer than the engine's millisecond clock and saved-scene epoch. The drivers now resolve that clock first, then initialize Cartesian state from the resolved epoch. Exported scene epochs and navigation references use the same clock. Fractional-time and rollover tests distinguish the old initialization from the corrected result.
- **Resolved P3, usability:** the README identifies bundled model assets and built-in mesh aerodynamics correctly, separates the four basic demonstrations from the SPICE/native-GRAM mission cases, and identifies their physical-validation limits. The Odyssey inspector defaults to the basic driver's actual `odyssey_two_orbits` directory.
- **Validation limit, not a flight-accuracy result:** initial state/reference agreement does not imply agreement throughout propagation. The executed default Odyssey case reaches approximately 551.5 km separation from its navigation reference over 34.6 hours; its second periapsis is about 120 seconds late. The README discloses this. The package provides executable demonstrations and comparison tools, not a validated reconstruction claim.

No additional blocking source finding was identified within this scope.

## Residual Risk

- Fresh Linux CI, the complete unit/integration suite and a documentation build were not executed for this mission candidate. Final-head mission revalidation passed 108/108; all 23 final-head contract gates also passed. An initial final-head gate invocation used a nonexistent script path and executed no checks; its failed record is retained separately from the successful original 23-gate run.
- Titan now requires `pck00011.tpc`. Asset installations containing only `pck00010.tpc` intentionally fail with a missing-kernel error. Sampled Titan/Moon frames and radii match the isolated old-PCK baseline in the regression, but this is not a proof of equality at every epoch or for arbitrary externally furnished kernels.
- The saved-output check uses the same SPICE kernels as the drivers. It validates internal timing, reference sampling and orientation conventions. It does not independently validate atmosphere time systems, coordinates, datums, climatology, spacecraft properties or force-model adequacy. Apollo is a nominal orbit, with no flown Apollo trajectory oracle.
- Optional mesh fitting, the separately supplied CDN sharing tool, the accelerometer-density variant and fresh mission-kernel downloads were not exercised by the full default runs. Standalone HTML output is the tested default. These mission pages did not receive new browser interaction acceptance in this review.
- No public API symbol is added. No before/after whole-simulation bit-identity, performance improvement or broad scientific-accuracy claim is made. Scope and file coverage must be refreshed if the publication base differs from the stated viewer parent.

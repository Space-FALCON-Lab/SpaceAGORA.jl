Detailed Description

Override the default SPICE leapsecond file name.

Critical to timekeeping is the SPICE leapsecond file. The location of this file within the SPICE data folder can be specified with this function. The relative path/name is typically of the form "/lsk/naif0012.tls".

Parameters
lskA string containing the LSK file path within the SPICE data folder

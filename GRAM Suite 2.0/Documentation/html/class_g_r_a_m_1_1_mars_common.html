Detailed Description

Common values for the Mars atmosphere models.

Common values for the Mars atmosphere models. All Mars atmosphere models should inherit this class.

(1) Data from NSSDCA Planetary Fact Sheet for Mars (https://nssdc.gsfc.nasa.gov/planetary/factsheet/marsfact.html). Page last updated on Sept 27, 2018.

(2) Data from NAIF Spice files (mar098.cmt).

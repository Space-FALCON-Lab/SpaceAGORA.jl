# AI Review Artifact — PR #232

## Scope
Physics fix: coupled cloth robot-arm links now receive gravity at their own inertial positions. Before, only joint reactions acted on them, so the joint springs carried each link's weight and the system's total gravity was short by the arm mass.

## Changed Files
- src/dynamics/multibody_cloth/cloth_robot_arm_dynamics.jl — optional `link_gravity_ii` keyword on `assign_coupled_cloth_robot_arm_rhs!`; when it is given, each link's force gains `m * g(r_link)`. The default `nothing` is the old behavior.
- src/simulation/engine/dynamics_rhs.jl — `_gravity_only_acceleration_ii(p, r_ii, t)` sums `gravity_backbone_acceleration_ii` over position-only gravity effectors through a type-stable tuple recursion. `_ArmLinkGravity` is the callable passed from `_apply_coupled_robot_arm_rhs!`.

## Findings
- P1 (fixed): missing gravity on arm links. Measured static deflection of m g / k = 8.65e-4 m for a 0.5 kg link at k = 5e3 N/m in a 410 km orbit, falling to 1.31e-8 m (integrator floor) with the fix.
- P2 (reported, not fixed): the flat constellation effector-queue route never calls the arm hook and can be selected for arm runs, because route selection checks only dynamic effectors. An arm in such a run is silently uncoupled. Left for a follow-up so this PR stays a single physics fix.
- P3: the gravity sum uses the same effectors and samples the bus uses, so arm links and bus share one gravity model. Third-body and SRP terms are not applied to links.
- P3: the new engine test runs 120 s because a 300 s run hit `MaxIters`. It was not established whether that predates the fix.

## P1 Assessment
One P1 (missing arm-link gravity), resolved by this PR. Unresolved P1: No

## Tests Added/Updated
- test/unit/robot_arm_gravity_tests.jl (new, registered in `test/unit/runtests.jl`) covers two cases:
  - Engine run: a static arm in orbit keeps its joint deflection below 1e-4 of the pre-fix m g / k. The tolerance is set above the ~1e-8 m floor that comes from differencing ~7e6 m absolute positions; the reason is recorded in the test.
  - Direct RHS check: without gravity the spring carries m g within 10% (measured 0.4%), and with gravity it carries none.
- The existing robotics and arm visualization tests pass unchanged.

## Residual Risk
Low. The change only adds a gravity term to the coupled arm path. Robot-arm run outputs change, which is the intent.

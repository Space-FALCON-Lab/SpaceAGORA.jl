# parallel/policy/types.jl

## Purpose
The state types of the threading policy: contexts, telemetry counters, adaptive controllers, worker pools and persistent-hint state.

## Design & Implementation
`PolicyContext` owns a `PolicyTelemetry`, per-source `AdaptiveControllerState` and decision memos; `AdaptiveChoiceStats` accumulates samples and timings; `_PersistentForeachPool` and `_SpinBarrierPool` describe pools; `_PersistentHintState` and `_HintLayerStatsAccumulator` back the hint file and its reporting.

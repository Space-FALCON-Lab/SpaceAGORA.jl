## Findings
- P2 (addressed): warn condition changed from "link wind nonzero" to "link wind ≠ spacecraft wind", which is precisely the set of evaluations where discarding the link sample changes the physics.
- Codex P2 (DECLINED with quantitative bound): "compare winds in a common frame" — the triples are indeed local E/N/U components at each sample's position, but the positions are one spacecraft apart (`body.r`, meters), so the two local bases differ by ≤ |body.r|/R_planet ≈ 2e-6 rad. Identical triples therefore represent the same planet-fixed wind to ~ppm and any model-meaningful difference dominates the basis mismatch; the raw-component comparison is the correct first-order predicate. A frame-resolved comparison would add a per-link geodetic conversion + basis construction in the aero hot loop every integrator step for a maxlog=1 diagnostic. The ENU pole singularity implicit in the convention is shared by the spacecraft-level wind path itself (`latlongtoNED` at the planet frame), so the predicate is not held to a lower standard than the physics it annotates. Bound recorded in the code comment.

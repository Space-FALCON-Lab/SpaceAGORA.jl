## Thread-safety follow-up

The original extraction omitted the engine capability declaration, so adding the torque-only model to a harmonics constellation forced the requested flat route back to satellite batching. The preserved one-line specialization fixes that routing regression without changing force or torque formulas. Tests reuse the same model from spawned tasks and compare actual serial, forced-flat and automatic-route propagation while checking the chosen plans and populated torque slots. Spawned task reuse is not a sustained contention stress test. The flat-route case requires at least two Julia threads; a single-thread invocation explicitly skips that case. No performance improvement is claimed.

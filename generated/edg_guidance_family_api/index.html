EDG Guidance Family API

This page documents the supported public interface available from SpaceAGORA.

EDG guidance family

SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceFamily — Type
EDGGuidanceFamily()

The EDG guidance family of the GNC algorithm contract: the energy-depletion guidance decision for one spacecraft's drag passages. Its request is an EDGGuidanceRequest, which copies the observation, the EDG configuration and the run's EDG state; its product an EDGGuidanceDecision, proposed in an AlgorithmResult; its trusted validation validate_edg_guidance_decision; its install target the run's AerobrakingEnergyDepletionState, which the AerobrakingEnergyDepletionControlModel reads; and its rejection policy :fail, as when the provider raises: a refused decision stops the run. The family is served by the EDGServices facade, and its contract version is the facade's (family_contract_version).

An AlgorithmGuidance runs EDGGuidanceAlgorithm() with EDGGuidanceSettings. The run has one spacecraft; a run with several uses AerobrakingEnergyDepletionGuidanceModel.

source
SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceCapabilities — Type
EDGGuidanceCapabilities(; guidance_modes=())

What an algorithm of the EDG guidance family supports: the guidance modes (:max_energy_depletion, :targeting) it can decide. The family's default supports none.

source
SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceAlgorithm — Type
EDGGuidanceAlgorithm()

The energy-depletion guidance decision of the optional SpaceAGORAEDG package, as an algorithm of the EDG guidance family. It supports the maximum-depletion and targeting modes, needs the package to be loaded (require_algorithm_support), and draws no random numbers (consumes_rng is false). Each proposal calls the provider's guidance_decision! on a copy of the request's EDG state and returns the spacecraft's decision fields; a provider that changes anything else in that state fails the proposal (:failed, termination :changed_outside_decision).

source
SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceSettings — Type
EDGGuidanceSettings(; config, state)

The settings of an AlgorithmGuidance that runs the EDG guidance family: the run's AerobrakingEnergyDepletionConfig and AerobrakingEnergyDepletionState, the same objects the AerobrakingEnergyDepletionControlModel holds. Decisions are installed in state; the binding's link stays unset.

source
SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceRequest — Type
EDGGuidanceRequest

The EDG guidance family's owned request for the spacecraft at spacecraft_index (its position in the run, from 1) at elapsed time time_s (s), with its request_id and reason:

  • config: the run's AerobrakingEnergyDepletionConfig;
  • observation: copied inertial position (m), velocity (m/s), mass (kg) and cumulative per-link heat (J/cm²) of every spacecraft, as the provider receives them;
  • state: a copy of the run's AerobrakingEnergyDepletionState, including the control clock the engine reported when the run started;
  • services: an opaque handle to the run's prediction services. Copies of the request share it; each provider call borrows its own call-scoped prediction context from it.

Trusted family code builds it (family_request); the algorithm receives its own copy.

source
SpaceAGORA.EDGGuidanceFamilies.EDGGuidanceDecision — Type
EDGGuidanceDecision

The EDG guidance decision for the spacecraft at spacecraft_index: the values of that spacecraft's guidance fields of the AerobrakingEnergyDepletionState. They are selected_mode, targeting_active, safe_low_drag, energy_bracketing_evaluated and energy_bracketing_count, the target and bracket specific energies target_energy_jkg, target_perturbation_energy_change_jkg, bracket_min_energy_jkg and bracket_max_energy_jkg (J/kg), the targeting switch time targeting_switch_s and the time of the last switch solve last_switch_solve_t (elapsed s), and the copied targeting_diagnostics.

source
SpaceAGORA.EDGGuidanceFamilies.validate_edg_guidance_decision — Function
validate_edg_guidance_decision(request::EDGGuidanceRequest, result) -> ValidationResult

The EDG guidance family's trusted validation of a proposal result against the lifecycle's own copy of request. A result for another request is refused with :request_mismatch, and one that is not a :candidate with its status. A candidate is accepted, with reason :accepted and metrics selected_mode and targeting_switch_s, when its product is an EDGGuidanceDecision (:invalid_product) for the request's spacecraft (:spacecraft_mismatch) whose mode is :inactive, :safe_low_drag or a guidance mode of the request's configuration (:unknown_mode, :mode_not_configured), whose targeting plan is consistent (:inconsistent_targeting: targeting_active exactly in the :targeting mode), whose switch time is a time (:invalid_switch_time: never NaN, and finite for an active targeting plan; Inf means no switch), and whose bracketing count has not decreased (:count_decreased). Validation installs nothing and draws from no random stream.

# analysis/verification/telemetry_verification/manifest_parsing.jl

## Purpose
Turns the TOML manifest into typed scenario configurations, validating every field so a malformed manifest fails before any simulation runs.

## Design & Implementation
Small required and optional field accessors build up to parsers for each sub-table — initial time, spacecraft, units, tolerances, manoeuvres, atmosphere truth, calibration — and `_load_scenarios_from_manifest` assembles either an `OrbitEventsScenarioConfig` or a `TimeAlignedScenarioConfig` per entry. Environment-variable readers for solver settings live here too.

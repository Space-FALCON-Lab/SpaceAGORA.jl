# simulation/engine/setup.jl · _srp*

## Purpose
Configuration and keying of the SRP Sun-position table that lets the solar radiation pressure effector interpolate the Sun's position instead of querying SPICE per RHS call.

## Design & Implementation
`_srp_ephemeris_cache_enabled`, `_srp_ephemeris_cache_dt_s` and `_srp_ephemeris_cache_max_samples` read the environment knobs with the same names and defaults pattern as the N-body and planet-frame tables; `_srp_ephemeris_reuse_key` keys a table by primary body, epoch, span and step for the process-wide reuse cache.

## Limitations
The Sun moves slowly relative to any planet, so the default step is coarse; a step chosen for accuracy near a planet-shadow crossing is not tuned by anything here.

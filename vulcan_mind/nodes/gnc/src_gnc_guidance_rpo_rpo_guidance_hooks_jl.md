# gnc/guidance/rpo/rpo_guidance_hooks.jl

## Purpose
The RPO guidance effector: builds the initial plan, runs replanning checks each guidance tick, and records replanning events.

## Design & Implementation
`build_rpo_plan` and `build_rpo_plan_from_start` run the planner and retime the result; `calcGuidanceEffect!` calls `maybe_update_rpo_replanning!`, which applies the replanning decision; `_rpo_record_replanning_event!` logs triggers for analysis.

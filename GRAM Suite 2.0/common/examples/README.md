# GRAM Examples

The code in this folder can be used by any GRAM model.  The calling source should properly initialize the model.

Files and Subfolders:
- GramExamples.h: Header for declaring example functions.
- AtmosphereExample.cpp: A very simple example of calling an atmosphere model and printing results.
- PerturbationExample.cpp: A slightly more complicated example that demonstrates setting perturbation states.
- TrajectoryExample.cpp: An example of evaluating an atmosphere along a trajectory.
- EphemerisExample.cpp: An example of evaluating an atmosphere over an ephemeris profile.
- MonteCarloExample.cpp: Run a Monte Carlo of trajectories.
- NamelistExample.cpp: A Monte Carlo example that reads inputs from a namelist file.
- UnitTestRunner.cpp: This is an example of how to invoke unit testing.

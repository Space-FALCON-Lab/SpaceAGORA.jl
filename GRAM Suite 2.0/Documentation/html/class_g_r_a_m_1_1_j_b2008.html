Detailed Description

The JB2008 empirical model of the Earth thermosphere.

The Jacchia-Bowman 2008 Model Atmosphere. This is the CIRA "Integration Form" of a Jacchia Model. There are no tabular values of density. Instead, the barometric equation and diffusion equation are integrated numerically using the Newton-Coates method to produce the density profile up to the input position.

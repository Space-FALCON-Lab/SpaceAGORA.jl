# simulation/engine/adapters/

## Purpose
Reads engine configuration from the environment with override scopes, so tests and campaigns can set engine settings without mutating `ENV`.

## Design & Implementation
`_engine_env_get` and `_engine_env_haskey` consult an override dictionary before `ENV`; `_with_engine_env_overrides` scopes overrides; typed parsers for booleans, floats and the solver-mode symbols; `simulation_engine_config_from_env` and `_solver_config_from_env` build the typed configs.

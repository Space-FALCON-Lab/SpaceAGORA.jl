# core/types/compat_model_codes.jl

## Purpose
Backwards compatibility for configurations that name density models by legacy integer codes.

## Design & Implementation
`LegacyDensityModelCode` enumerates the old codes, `_compat_enum_parse` converts strings or integers to the enum with a clear error, and `LegacyModelCodes` packages them for the configuration parser.

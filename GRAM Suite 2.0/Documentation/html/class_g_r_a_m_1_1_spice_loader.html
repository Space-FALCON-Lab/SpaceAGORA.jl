Detailed Description

This is a utility class for loading Spice data files into memory.

This utility class wraps the NAIF Spice furnsh function for loading data into memory. Consecutive calls of the same file to furnsh will result in memory bloat. So the SpiceLoader will only load unique files into memory. The methods in this class are static and may be called directly.

Examples
Earth/examples/EarthCorrMulti.cpp.

void GRAM::SpiceLoader::setSpiceDataPath ( const std::string &  path)

Set the path to the Spice data files.

Spice data is distributed in a folder containing lsk, pck, and spk subfolders. The spice data path should be set to point to this root Spice folder. This static method may be called directly with SpiceLoader::setSpiceDataPath("mypath").

Parameters
pathThe path to the root folder of the spice data.

GNC Algorithm Contract API

This page documents the supported public interface available from SpaceAGORA.

GNC algorithm contract

SpaceAGORA.GNCAlgorithms.AbstractGNCAlgorithm — Type
AbstractGNCAlgorithm

An algorithm whose output is consumed later or can be rejected: a planner, a scheduler or a decision service. It runs in the planning profile of the GNC contract: its family builds an owned request, the algorithm proposes a product, trusted code validates the proposal, and only a validated copy is installed. Feedback control laws that act at once use the feedback profile instead (a tick that computes and holds a command).

An algorithm declares algorithm_family and implements propose!; the other algorithm-side functions have defaults. AbstractRPOPlanner is a subtype.

source
SpaceAGORA.GNCAlgorithms.AbstractAlgorithmFamily — Type
AbstractAlgorithmFamily

The trusted definition of one problem: its request and product types, how a proposal is validated (validate_proposal), where an accepted product is installed (install!), when an installed product stops being usable (is_current) and what happens on rejection (on_rejection). Algorithms declare a family; they never validate or install their own products. RPOReferenceFamily is a subtype.

source
SpaceAGORA.GNCAlgorithms.AbstractAlgorithmRequest — Type
AbstractAlgorithmRequest

An owned snapshot handed to an algorithm, in SI units, carrying a positive request_id. The lifecycle keeps its own copy for validation and passes the algorithm a separate deep copy. RPOPlanningRequest is a subtype.

source
SpaceAGORA.GNCAlgorithms.AbstractAlgorithmResult — Type
AbstractAlgorithmResult

An algorithm's outcome for one request: request_id, status (:candidate, :infeasible, :unsupported or :failed), termination, the proposed product (present exactly for :candidate) and diagnostics. A candidate still needs trusted validation. AlgorithmResult and RPOPlanningResult are subtypes.

source
SpaceAGORA.GNCAlgorithms.AbstractValidationResult — Type
AbstractValidationResult

The outcome of trusted validation, with fields accepted::Bool, reason::Symbol and metrics. ValidationResult and RPOValidationResult are subtypes.

source
SpaceAGORA.GNCAlgorithms.GNCAlgorithmError — Type
GNCAlgorithmError <: Exception

Supertype of the errors an algorithm lifecycle raises when a request fails under the :fail policy. Subtypes carry a copied run report, the reason, and the original cause and backtrace. RPOPlanningError is a subtype.

source
SpaceAGORA.GNCAlgorithms.AlgorithmResult — Type
AlgorithmResult(; request_id, status, termination, product=nothing, diagnostics=NamedTuple())

A generic algorithm outcome for families that need no result type of their own. status is one of :candidate, :infeasible, :unsupported or :failed; only a :candidate carries a product, and it must carry one. Construction deep-copies the product and the diagnostics, so later edits through an algorithm-held handle cannot change them. Diagnostics are never read by validation or installation.

source
SpaceAGORA.GNCAlgorithms.ValidationResult — Type
ValidationResult(accepted, reason, metrics=NamedTuple())

A generic validation outcome: whether the proposal is accepted, a machine-readable reason and the measured values behind it.

source
SpaceAGORA.RPOPlannerInterfaces.RPOReferenceFamily — Type
RPOReferenceFamily()

The RPO reference-planning family of the general GNC algorithm contract. Its request is an RPOPlanningRequest, its product an RPOReference, its trusted validation validate_rpo_result, its currency rule rpo_reference_is_current and its rejection policy :fail. Every AbstractRPOPlanner belongs to it, and the general functions forward to the RPO names: propose! to plan_rpo!, propose_revision! to retime_rpo!, algorithm_capabilities to planner_capabilities, initialize_algorithm to initialize_planner and require_algorithm_support to require_planner_support.

source
SpaceAGORA.GNCAlgorithms.algorithm_family — Function
algorithm_family(algorithm) -> AbstractAlgorithmFamily

Required. The family whose request, validation, installation and failure rules govern algorithm. The fallback throws an ArgumentError that names the type.

source
SpaceAGORA.GNCAlgorithms.default_capabilities — Function
default_capabilities(family)

The capabilities an algorithm of family has when it declares none: support for nothing. The fallback is an empty NamedTuple; a family with a capability type returns its empty instance.

source
SpaceAGORA.GNCAlgorithms.algorithm_capabilities — Function
algorithm_capabilities(algorithm)

What algorithm supports, in its family's capability type. Defaults to default_capabilities(algorithm_family(algorithm)), which supports nothing. Declaring capabilities never loads algorithm configuration.

source
SpaceAGORA.GNCAlgorithms.require_algorithm_support — Function
require_algorithm_support(algorithm) -> nothing

Throw before a run starts if something algorithm needs is missing, such as an optional package. The default checks nothing.

source
SpaceAGORA.GNCAlgorithms.initialize_algorithm — Function
initialize_algorithm(algorithm, run_context) -> state

Create fresh run-owned state for algorithm; stateless algorithms return nothing (the default). run_context is a copied NamedTuple (for example seed, stream_words, epoch and spacecraft IDs).

source
SpaceAGORA.GNCAlgorithms.propose! — Function
propose!(state, algorithm, request, rng) -> AbstractAlgorithmResult

Required. Propose a product for request using run-owned state. rng is the only random stream the algorithm may draw from; there is no default global stream. The algorithm receives its own copy of request and must not install anything. The fallback returns an :unsupported result and draws nothing.

source
SpaceAGORA.GNCAlgorithms.propose_revision! — Function
propose_revision!(state, algorithm, request, active_product, rng) -> AbstractAlgorithmResult

Optional. Revise the installed active_product instead of proposing from scratch (RPO calls this retiming). The fallback returns an :unsupported result and draws nothing; an unsupported revision never falls back to a full proposal.

source
SpaceAGORA.GNCAlgorithms.consumes_rng — Function
consumes_rng(algorithm) -> Bool

Whether algorithm draws from the stream passed to propose!. The default is true. A deterministic algorithm declares false; its contract tests then check that a proposal leaves the stream unchanged.

source
SpaceAGORA.GNCAlgorithms.validate_capabilities — Function
validate_capabilities(family, algorithm, request; checkpoint=false) -> AbstractValidationResult

Check algorithm's declared capabilities against request before asking for a proposal; checkpoint=true also requires restart support. The default accepts, for families that have no capability rules.

source
SpaceAGORA.GNCAlgorithms.validate_proposal — Function
validate_proposal(family, request, result, trusted) -> AbstractValidationResult

Required for each family. Validate result against the lifecycle's own copy of request. trusted holds queries the lifecycle supplies independently of the algorithm (for RPO, clearance_at). Validation never installs a product, never advances a random stream and never reads diagnostics as geometry.

source
SpaceAGORA.GNCAlgorithms.install! — Function
install!(link, family, product, request, t) -> nothing

Required for each family. Install a validated copy of product into link, the object the family shares with the product's consumer, at time t. Installation is atomic: no yield or user callback runs between validation and installation.

source
SpaceAGORA.GNCAlgorithms.is_current — Function
is_current(family, request, product, t) -> Bool

Required for each family. Whether an installed product (accepted for request) may still be used at time t, including any preview the consumer needs.

source
SpaceAGORA.GNCAlgorithms.on_rejection — Function
on_rejection(family) -> Symbol

What the lifecycle does when capability checks or validation reject a proposal: :fail raises a GNCAlgorithmError (the default), :keep_previous keeps the installed product, and :install_fallback installs fallback_product.

source
SpaceAGORA.GNCAlgorithms.fallback_product — Function
fallback_product(family, request)

The product installed on rejection by a family whose on_rejection is :install_fallback, such as a hold. Families with another policy need no method.

source
SpaceAGORA.GNCAlgorithms.family_contract_version — Function
family_contract_version(family) -> Union{Nothing, VersionNumber}

The version of family's request, product and validation contract, so that a companion package can require the one it was built for. The default nothing means unversioned.

source

# PR176: wind corrections, atmospheric phase settings and opt-in frozen sampling

## Scope

This current assessment supersedes the earlier acceptance of automatic frozen sampling in this artifact. The earlier analysis and reproductions remain in Git history. The candidate incorporates PR176 head `2a69ece4503d014e362355e970ae22ec4f1ead28`, main `3287f0fc145d779ce3bd0ac608eb3352d671b85e`, and the separately prepared atmospheric-phase repair `b2f83f960b450fbf5e89b97f22424f45552bd56f`. The opt-in runtime change is `b1b375afc1609f0b33bf3043cb5e7bd2a756223e`; subsequent artifact and comment edits do not change behavior.

The decision is to fix and narrow this PR. Preserve the wind mask, initialization/reseed protections, pool guards, E-EDG relative-velocity correction and atmospheric phase repair. Keep per-stage sampling when `SPACEAGORA_DENSITY_FREEZE_PER_STEP` is unset, empty or off. Explicit `auto` freezes only history-dependent winds; explicit `1`/`on` freezes every model. Frozen sampling remains an approximation requiring application-specific accuracy acceptance.

This is implementation-task verification, not an independent signoff or merge authorization. Existing remote CI applies to the published head above. Fresh CI and independent review must assess the revised candidate.

## Findings

1. **Default sampling change removed.** The prior report accepted automatic freezing using a few numerical comparisons. That acceptance is withdrawn. Reconstructed native three-orbit Earth comparisons after the phase repair still differ by approximately 0.53 to 2.20 km between frozen and per-stage sampling, depending on seed and atmospheric boundary. No mission accuracy budget was supplied. The revised default is per-stage; the approximation requires explicit opt-in.
2. **Phase-policy prerequisite integrated.** Previously, startup inside the atmosphere could retain the orbital cap and tolerances; crossings, mixed spacecraft and reuse also required repair. The aggregate policy now follows active spacecraft from startup through crossings, deactivation, reuse and checkpoint segments. Explicit step overrides remain effective.
3. **Native initialization and reseed protections retained.** History-dependent models are reseeded after calibration, re-warmed serially under the shared native lock, and their caches cleared. This preserves the earlier fix for concurrent first-update CSPICE corruption. History-free and wind-disabled runs do not get unnecessary reseeds. Earth static-table initialization remains guarded.
4. **Surrogate and pool rules retained.** A pure-grid surrogate does not become history-dependent merely because its base model is native; a configured native point fallback does. Automatic pools decline history-dependent requested winds, regardless of default versus explicit-auto sampling. Forced pool modes still require care.
5. **Wind and E-EDG corrections retained.** `wind=false` masks native-Julia consumers; E-EDG uses air-relative velocity `v - wind`, consistent with aerodynamic force calculations. Prior native Mars runs reproduced approximately 134 m apoapsis and 185 m endpoint-position effects with winds on, and bit-identical recorded endpoints with winds off.
6. **Accuracy wording corrected.** Frozen-sample error is not established by solver tolerances or a few random seeds. The orbital cap matters outside the atmospheric boundary as well as the atmospheric cap inside it. Altering perturbed-query count changes the wind realization, so a same-seed comparison is not a converged physical error bound.

## Tests Added/Updated

A one-thread order-sensitive negative control verifies default equals explicit off and differs from explicit auto. Native short runs compare their saved time arrays and complete final state vectors for default versus empty/off and explicit auto versus on. Intermediate state vectors are not retained by that helper. Wind masking and pool guards are checked under both unset and explicit-auto settings.

Explicit auto/on endpoints reproduce the prior frozen reference. Every run reaches its endpoint and obeys the 1 s atmospheric interior cap. This is preservation of the repaired candidate's explicit-off behavior, not a claim of identity to pre-PR main.

The selected required-native regression run passes **590 assertions**: 156 GRAM history/freeze/reseed assertions, 123 wind-mask assertions, nine analytic E-EDG checks, 47 atmospheric lifecycle checks and 255 density-service checks. ## Residual Risk

- Per-stage perturbed native winds retain query-order/thread-scheduling dependence and may be slow. The one/four-thread agreement guarantees cover the explicitly frozen dynamics route, not the default or arbitrary custom native-querying GNC.
- Explicit frozen sampling has no general application accuracy acceptance. The reported comparison is not a mission error bound. Both phase caps and any extra native queries must be considered.
- The default is preserved relative to the repaired explicit-off candidate. Wind masking, E-EDG sign, initialization/reseed and atmospheric phase corrections intentionally can change outputs relative to earlier main.
- Full large-constellation crash scenarios, all bodies' reseed identity, forced process-pool stochastic equivalence and custom guidance thread assumptions are not established by this review. Native Earth and Mars coverage does not generalize automatically to other bodies.
- The earlier reviewed cache semantics remain: explicit freezing takes precedence over per-stage look-ahead interpolation. Forced process-service modes can alter sample use. These are explicit advanced configurations, not newly accepted accuracy guarantees.
- Local checks do not replace fresh remote CI, telemetry review or independent review of the revised head. No merge authorization is implied.

# gnc/robotics/robot_arm_hypr.jl

## Purpose
The module file for the robot-arm HYPR planner, assembling its component files into one namespace in dependency order.

## Design & Implementation
Declares the module, imports the kinematics and HYPR utilities it builds on, and includes `config.jl`, `clearance.jl`, `rrt_warmstart.jl`, `swarm_and_retiming.jl` and `planner_core.jl` in that order so each file sees the definitions it needs. It exports `plan_robot_arm_motion_hypr` and the config and result types.

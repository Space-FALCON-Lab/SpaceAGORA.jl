# analysis/verification/telemetry_verification/reporting.jl

## Purpose
Renders verification results into human-readable summary and error tables with display units, scaled columns, threshold verdicts and optional plots.

## Design & Implementation
Column helpers append scaled and unit-labelled metric and error columns, `_evaluate_thresholds` compares each channel against its tolerance set and records pass/fail, scenario metadata accessors fill provenance columns, and `_generate_plots` writes per-scenario figures into `_default_plots_outdir`.

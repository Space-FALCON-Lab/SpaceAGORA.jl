# simulation/engine/setup.jl/ (small files)

## Purpose
The remaining setup helpers: validation and reporting toggles, ephemeris payload and file handling, N-body and SRP effector detection, snapshot accessors, and the environment config initialiser.

## Design & Implementation
`_cache_from_nbody_ephemeris_payload`, `_load_nbody_ephemeris_cache!`, `_write_nbody_ephemeris_cache_file!` and `_prewarm_nbody_ephemeris_cache` handle table files; `_has_active_nbody_effector`, `_has_active_srp_effector` and `_collect_nbody_query_names` inspect effectors; `_policy_env_config`, `_rhs_env_config_from_buffers` and `_snapshot_rhs_plan_env_config` serve snapshots; the rest are single-purpose readers and keys.

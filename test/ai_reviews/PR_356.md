## Findings

The source search was `git grep -n -i "inertial-to-body\|body-to-inertial\|scalar-last" -- src`. The seven changed docstrings describe the absolute spacecraft quaternion used by `StateSample` or a commanded/visual substitute for it. This is a wording correction; it does not conjugate, reorder, normalize, or otherwise change a quaternion.

The following matches were inspected and left alone (paths below are repository-relative):

- `src/models/dynamics/external_propagation.jl` and `src/orchestration/simulation/external_propagation_services.jl`: reserved for #350, as required.
- `src/interfaces/analysis/visualization/scene/planet_spec.jl`: the J2000-to-planet-body-fixed quaternion is a different frame transform.
- `src/interfaces/analysis/visualization/scene/scene_visualization.jl`: `LinkBox.q` describes a link relative to the root bus.
- `src/models/dynamics/effectors/perturbations/control/lvlh_cascade.jl`: the command is relative to LVLH rather than inertial axes.
- `src/models/dynamics/multibody/compliant/compliant_attachment.jl`: mount orientation is relative to its link, and initial body state is relative to the mount frame.
- `src/models/vehicle/spacecraft/model.jl`: ball-joint quaternions describe relative joint coordinates.
- `src/foundation/core/numerics/orientation_quaternion_utils.jl`, `src/foundation/core/numerics/quaternion_utils.jl`, and `src/models/dynamics/rotational/attitude_kinematics.jl`: internal numerical-helper docs or implementation comments describe general quaternion arithmetic and kinematics; they are not public spacecraft-state docstrings.
- `src/models/dynamics/effectors/gravity/gravity_gradient_effector.jl`: the wording defines a rotation matrix, not the quaternion.
- `src/interfaces/analysis/visualization/scene/viewer_payload.jl`: `reference_payloads` is an internal helper, absent from the supported root API.
- `src/models/dynamics/multibody/articulated_body.jl`: the module convention, `ArticulatedBaseState`, and forward-kinematics helper docs are internal under the documented root API policy. The module also explains its distinct active rotation helper, and ball-joint wording concerns relative coordinates.
- `src/models/dynamics/multibody/compliant/compliant_attachment_dynamics.jl` and `src/models/dynamics/multibody/compliant/compliant_multibody.jl`: module/implementation conventions and mount/world-to-body helpers are internal rather than supported root API entries. Relative mount/link quaternions and the active `_rot` helper retain their separate frame meaning.
- `src/models/gnc/control/landing/apollo_descent_control.jl`: `attitude_error_vector` is an internal helper rather than a supported root API entry. Its source file is untouched.
- `src/models/gnc/guidance/landing/apollo_descent_guidance.jl`: the remaining passive-DCM comment and `quaternion_from_passive_dcm` helper doc are internal; the helper already gives `rot(q) == A` for its matrix argument.
- `src/orchestration/simulation/callbacks/save_fields.jl`: save-field implementation comments and the two unexported save-field helper docstrings remain internal.
- `src/interfaces/analysis/verification/telemetry_verification/manifest_parsing.jl`, `src/interfaces/analysis/verification/telemetry_verification/types.jl`, `src/models/vehicle/structure/mesh_geometry.jl`, and `src/orchestration/simulation/config/example_configuration.jl`: the hits are an error string or implementation comments, not public docstrings.

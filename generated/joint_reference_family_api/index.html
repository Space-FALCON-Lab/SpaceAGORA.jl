Joint-Reference Family API

This page documents the supported public interface available from SpaceAGORA.

Joint-reference family

SpaceAGORA.JointReferencePlanning.JointReferenceFamily — Type
JointReferenceFamily()

The joint-reference family of the GNC algorithm contract. Its request is a JointReferenceRequest, a snapshot of one spacecraft's arm and of the motion asked for; its product a RobotArmPlan, proposed in an AlgorithmResult; its trusted validation validate_joint_reference (joint limits, a uniform time grid, the goal and the obstacle clearance at the reference's samples); its install target the RobotArmPlanBuffer a RobotArmControlEffector reads (its plan_buffer); its currency rule joint_reference_is_current; and its rejection policy :fail: a refused proposal stops the run with an AlgorithmGuidanceError whose reason is the validation's.

An AlgorithmGuidance runs any planner of the family (an AbstractJointReferencePlanner, such as QuinticJointPlanner), with JointReferenceSettings as its settings and the controller's plan buffer as its link. The buffer is a GNC link: the binding produces it, the controller consumes it, and before the run the engine checks that one controller reads it, for the binding's spacecraft and arm. The buffer holds the plan the arm starts from, such as a hold at the start joints; each run starts from it again. The controller and the arm's coupled state track an installed plan from the time it is installed at.

source
SpaceAGORA.JointReferencePlanning.AbstractJointReferencePlanner — Type
AbstractJointReferencePlanner <: AbstractGNCAlgorithm

An algorithm of the joint-reference family (JointReferenceFamily, inherited). A planner implements propose!(state, planner, request::JointReferenceRequest, rng) and returns an AlgorithmResult whose product, for a :candidate, is the RobotArmPlan it proposes. QuinticJointPlanner is a subtype.

source
SpaceAGORA.JointReferencePlanning.JointReferenceRequest — Type
JointReferenceRequest(; request_id, reason, spacecraft_index, time_s, model, base_pose, q_start, target,
                      obstacles=RobotArmSphereObstacle[], dt_s, duration_s, clearance_m=0.0,
                      goal_tolerance_m=5.0e-3)

The joint-reference family's owned request snapshot, in SI units, for the arm of the spacecraft at spacecraft_index (its position in the run, from 1) at elapsed time time_s: the arm (model and base_pose), its start joints q_start (rad), the end-effector target (m), the sphere obstacles and the clearance clearance_m (m) the reference must keep from them, the sample step dt_s and duration duration_s (s) of the reference, and the goal tolerance goal_tolerance_m (m). Trusted family code builds it (family_request), with the arm's measured joints as the start; the planner receives its own copy. The reference's time axis starts at time_s.

source
SpaceAGORA.JointReferencePlanning.JointReferenceSettings — Type
JointReferenceSettings(; model, base_pose, target, obstacles=RobotArmSphereObstacle[], dt_s=0.1,
                       duration_s=12.0, clearance_m=0.0, goal_tolerance_m=5.0e-3)

The joint-reference family's settings for an AlgorithmGuidance: the arm, as a RobotArmModel and its RobotArmBasePose; the end-effector target position (m, in the frame the base pose is given in); the sphere obstacles the arm must clear by clearance_m (m); the reference's sample step dt_s and duration duration_s (s); and the distance goal_tolerance_m (m) within which the reference's last sample must reach the target. Each request starts from the arm's joints as the spacecraft's state measures them.

source
SpaceAGORA.SimulationModel.RobotArmPlanning.RobotArmPlanBuffer — Type
RobotArmPlanBuffer(; plan=nothing, updated_at_s=0.0)
RobotArmPlanBuffer(model, base_pose, q_start)

The link between a robot arm's planner and its controller: the RobotArmPlan the arm tracks and the time (s into the run) the plan's time axis starts from. A RobotArmControlEffector configured with plan_buffer= reads it at each tick, and the run couples the arm's state to it as to a controller's own plan: the arm's state is sized and started from the plan the buffer holds when the run starts, so it must hold one. The second form holds the arm of model at its base_pose still at the joint angles q_start (rad).

An AlgorithmGuidance of the joint-reference family (JointReferenceFamily) configured with link= the same buffer installs each accepted plan into it, at the time of its request. At each run's start, a plan and time a planner installed in the previous run return to the buffer's plan and time at that run's start, while a plan or time a user set since is kept as the new configuration.

SpaceAGORA.JointReferencePlanning.QuinticJointPlanner — Type
QuinticJointPlanner(; ik_tol_m=1.0e-4, ik_max_iters=100, ik_damping=1.0e-3)

A planner of the joint-reference family (AbstractJointReferencePlanner): the quintic joint-space blend of plan_robot_arm_motion, from the request's start joints to the inverse-kinematics solution for its target (solved to ik_tol_m, in at most ik_max_iters damped steps of damping ik_damping), sampled every dt_s over duration_s. It does not avoid obstacles, so the family's validation refuses a reference that does not clear them. When the inverse kinematics does not reach the target, its result is :infeasible, with termination :target_unreachable. It draws no random numbers (consumes_rng is false).

source
SpaceAGORA.JointReferencePlanning.validate_joint_reference — Function
validate_joint_reference(request::JointReferenceRequest, result) -> ValidationResult

The joint-reference family's trusted validation of a proposal result against the lifecycle's own copy of request. A result for another request (a different request_id) is refused with :request_mismatch, whatever its status. A :candidate for this request is accepted, with reason :accepted and metrics min_clearance_m, final_error_m and samples, when its product is a RobotArmPlan that:

  1. is for the request's arm and base pose (:model_mismatch, :base_pose_mismatch);
  2. has one row per joint and one column per sample in its joint and end-effector references, at least two samples, and finite times and references (:invalid_shape, :nonfinite_reference);
  3. is sampled on the request's grid: from 0 every dt_s, with a last step of at most dt_s, to duration_s (:invalid_timing);
  4. starts at the request's start joints, to 1e-9 rad (:start_mismatch);
  5. keeps every joint within its limits at every sample (:joint_limit);
  6. reaches the target within goal_tolerance_m at its last sample, by the arm's forward kinematics (:goal_not_reached);
  7. clears every obstacle by clearance_m at every sample, link by link (:insufficient_clearance).

Any other result is refused with its status as the reason (:infeasible, :unsupported, :failed), and a candidate whose product is not a RobotArmPlan with :invalid_product. Validation installs nothing and draws from no random stream.

SpaceAGORA.JointReferencePlanning.joint_reference_is_current — Function
joint_reference_is_current(request::JointReferenceRequest, plan::RobotArmPlan, time_s) -> Bool

Whether an installed plan may be used at time_s: from its request's time on. After its last sample the controller holds the final joints.

# HyPR paper reconstruction

The final iSpaRo reconstruction and its saved inputs now live in the private
SpaceAGORARPOStudies repository. Lab members with access use its pinned
environment and reconstruction guide for the scientific assumptions, commands,
retained failures and historical v0.4.0 results. Outside collaborators need an
invitation. The historical rerun remains unverified.

Core retains the generic MPC, batch, disturbance and replanning examples. Start
with [the planner guide](rpo_planner_pilot.md) for a new application, or
[the example catalog](examples_catalog.md) to select a maintained demonstration.
Moving the research source does not change its scientific claims or make the
reconstruction an exact reproduction of the original paper datasets.

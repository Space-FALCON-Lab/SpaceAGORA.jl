# core/simulation_model.jl

## Purpose
The umbrella module `SimulationModel` that includes every core, environment, vehicle, dynamics, GNC and simulation file into one namespace.

## Design & Implementation
A single `module SimulationModel` whose body is a long ordered list of `include` statements followed by `using` of the submodules it just defined. It exists so downstream code can write `SimulationModel.X` for anything in the engine.

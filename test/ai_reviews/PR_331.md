  visualization's atmosphere shell (`atmosphere_spec.jl:46-49`) samples its own

  and is not described.

  different type from the package's, so this PR does not affect it.

Reviewer to verify:

- The method body uses none of the renamed arguments, so the change cannot alter
  any result. The argument types (`Float64` ×4, `Bool`, `p::params`) are
  unchanged, so dispatch is unchanged.
- The docstring's statements match the code:
  - `rtolatlong` (`src/foundation/core/interfaces/reference_system.jl:377-411`)
    returns the geodetic altitude above the ellipsoid, the geodetic latitude
    (Bowring) and `atan(y, x)` longitude;
  - each engine caller passes those three values;
  - the wind components are east, north and up, as the EDG services unpack them
    (`typed_edg/services.jl:32` and `:90`).
- The batch docstring matches the generic `AbstractDensityModel` method, which
  loops over `_density_scalar_for_batch`.

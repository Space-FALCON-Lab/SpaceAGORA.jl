# AI Review — PR 69: attitude-kinematics frame fix + LVLH cascade attitude controller

## Scope
Two coupled changes discovered while adding closed-loop attitude capability:

1. **P1 physics fix: `quaternion_derivative` mixed frames with `angular_acceleration`.** The kinematics used the inertial-rate quaternion composition (`[ω,0] ⊗ q`, i.e. `+ω×qv`) while Euler's equations integrate body-frame torques and the gyroscopic term on the same ω state. Consequence, measured: a torque-free asymmetric tumble (I = diag(1.5,1.0,2.0), |ω| ≈ 0.04 rad/s) drifts its inertial angular momentum by **68% over 2000 s** — no consistent interpretation of the state exists. The fix is the body-rate composition (`q ⊗ [ω,0]`, i.e. `−ω×qv`); the same test then conserves to integrator accuracy (0.5% with explicit Euler at dt=0.05 s).
2. **New capability: `LVLHCascadeAttitudeControlModel`** — a closed-loop LVLH-pointing attitude controller as a dynamic effector: outer proportional attitude loop commanding a rate-limited body rate toward a configurable LVLH-relative setpoint, inner proportional rate loop with per-axis torque saturation (the cascade/rate-command architecture of small-sat ADCS flight software). Configurable gains only — no mission calibrations in the public repo.

## P1 Assessment
The kinematics fix is validated by a physical invariant (angular-momentum conservation in torque-free tumbling), which the probe suite now pins permanently at <1% — the pre-fix code fails that probe at 68%. The controller is validated end-to-end: a closed-loop simulation using the engine's own `quaternion_derivative`/`angular_acceleration` collapses a 5° offset to <0.35° (measured 0.03°) with generic gains.

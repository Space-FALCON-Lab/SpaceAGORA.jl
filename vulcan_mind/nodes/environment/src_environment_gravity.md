# environment/gravity/

## Purpose
Point-mass and J2 gravity effectors with optional gravity-gradient torque, and the acceleration kernels the flat RHS path reuses.

## Design & Implementation
`InverseSquaredGravityModel`, `InverseSquaredJ2GravityModel` and `ConstantGravityModel` with `calcForceTorque` and `wrench`; `_inverse_squared_gravity_accel` and `_inverse_squared_j2_gravity_accel` as the shared kernels; `_gravity_gradient_torque_body`, `j2_secular_rates`, and the backbone hooks that classify these as static gravity.

# gnc/navigation/

## Purpose
Navigation for RPO: station geometry, the chaser's body geometry, k-d tree nearest-point queries, and clearance measurements the planner and controller use.

## Design & Implementation
`RPOStationGeometry`, `RPOCubeSatGeometry` and `RPOReferenceGeometry`; a k-d tree over the station point cloud with nearest-point and nearest-distance queries; `rpo_clearance_to_station`, `rpo_clearance_distance_to_station` and `rpo_path_clearance_stats`; `rpo_goal_standoff_point`; `NavigationHooks` with `calcNavigationEffect!`.

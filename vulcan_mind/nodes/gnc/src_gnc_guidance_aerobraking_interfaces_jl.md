# gnc/guidance/aerobraking/interfaces.jl

## Purpose
The types that define an aerobraking guidance call: input state, output window, the strategy supertype and its two singletons.

## Design & Implementation
`AerobrakingGuidanceInput` carries entry state, vehicle and configuration; `AerobrakingGuidanceOutput` carries the switch window and profile; `AbstractAerobrakingStrategy` with `EEdgStrategy` and `TEdgStrategy`; `compute_aerobraking_guidance` is the generic each strategy implements.

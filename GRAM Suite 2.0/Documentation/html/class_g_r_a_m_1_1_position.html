#include <Position.h>

Detailed Description

An input state for an Atmosphere model.

The input state of an Atmosphere model is a point in space/time.

◆ convertToPlanetocentric()

void GRAM::Position::convertToPlanetocentric ( greal  polarRadius,
greal  equatorialRadius 
)

Converts a planetodetic position to a planetocentric position.

If the current position is flagged as planetodetic, then this method will convert the position values to planetocentric. The planetodetic values will be lost. The latitude, height, totalRadius, and latitudeRadius are updated.

Inputs

  • height
  • latitude
  • isPlanetoCentric
Parameters

Converts a planetocentric position to a planetodetic position.

If the current position is flagged as planetocentric, then this method will convert the position values to planetodetic. The planetocentric values will be lost. The latitude and height are updated. The totalRadius and latitudeRadius are set to zero.

  • totalRadius

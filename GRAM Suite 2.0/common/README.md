# GRAM Common Files

These files define the common framework for all GRAM models.

Files and Subfolders:
- cspice: Header files and libraries for NAIF SPICE.
- googletest: A unit testing framework.
- include: Header files for the common framework.
- source: Souce code for the common framework.
- examples: Common examples which can be used by any model.
- unittest: Source code for unit tests.

Note: Markdown files have been relocated to GRAM/Documentation/Markdown.

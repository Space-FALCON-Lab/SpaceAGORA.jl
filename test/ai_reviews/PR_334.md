## Findings

Author's notes for the reviewer (no P1 or P2 known to the author at the head):

- Fixed, P2 from the automated review (`effector_sampling.jl:53`, on 37984e087):
  - Before the field existed, Julia's default constructors included the
    parameterized `StateSample{S}(pos, vel, mass, q, ω, spacecraft)`.
  - 37984e087 restored only the unparameterized six-field form, so extension code
    that fixes the type parameter got a `MethodError`. `StateSample` is exported.
  - dd0371498 adds the six-argument `StateSample{S}` method, forwarding with index
    0 through the default seven-field constructor, so it converts its arguments as
    before. Its arity differs from the default constructors, and the constructor
    test checks that no two `StateSample` constructors are ambiguous.

- Low, design: `ReactionWheelMomentumModel` does not select by `x.spacecraft_index`
  in its pure `wrench`. Its docstring says a direct `wrench` evaluates the model
  "without index selection", and wrapper effectors that forward to it rely on
  that. Selection stays in `wrench_caching!`, which the engine calls.
- Low, compatibility: `StateSample` has one more field.
  - Both six-field positional forms that built a full sample before are kept and
    give index 0: the unparameterized one and, since dd0371498, the parameterized
    one.
  - Code that reads `fieldcount` or `fieldnames` would see one more field.
  - The repository, its examples and tests, and the companions (MuJoCo's
    `StateSample(r, v, m)`) use the keyword or three-argument form (checked by text
    search; nothing reads its field list).
- Note: the plume's five-argument `wrench` and its `wrench_caching!` are unchanged,
  so the engine path for the plume is unchanged.
- Note: `build_state_sample`'s new fourth argument defaults to 0, so the existing
  three-argument calls in tests and probes keep working. Engine sites pass the
  index; the new route probe would catch one that does not.

Reviewer to verify:

- Every `StateSample` construction in `src/` that describes a spacecraft of the run
  receives that spacecraft's index (`grep -rn "StateSample(\|build_state_sample("
  src`).
- The arithmetic at each site is unchanged: only an `Int` is added to a struct
  that is built in the same place.
- The base-versus-branch comparison reported above can be rerun from the PR text's description.
- The parameterized six-field form matches the default constructor it replaces:
  same arguments, same conversion to the field types, and index 0. It is not
  ambiguous with the default seven-field constructors or the other `StateSample`
  methods.
- The engine never calls the parameterized form (`grep -rn "StateSample{" src`
  shows only the struct and the new method), so dd0371498 cannot change results.

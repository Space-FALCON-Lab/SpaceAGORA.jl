# simulation/callbacks/control_callbacks.jl

## Purpose
Builds the control callbacks: periodic control ticks per effector rate, and event-driven thruster firings scheduled as integrator stop times.

## Design & Implementation
`get_control_callbacks` creates a `PeriodicCallback` per control effector; `schedule_all!` and `schedule_event_driven_thruster_controls!` register burn start and stop times as `tstops`; `_run_guidance_for_thruster_schedule!` runs guidance ahead of time to know when burns occur; `control_requires_periodic_callback` decides which path an effector takes.

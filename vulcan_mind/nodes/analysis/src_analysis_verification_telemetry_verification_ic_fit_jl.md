# analysis/verification/telemetry_verification/ic_fit.jl

## Purpose
Fits an initial state to time-aligned telemetry when the manifest supplies no trusted epoch state, by minimising position residuals over a short window.

## Design & Implementation
`fit_initial_state` drives `_ic_fit_run` over candidate perturbations of position and velocity, scoring each with `_ic_fit_mean_axis_rmse` on the series built by `_ic_fit_series`. The result seeds the time-aligned scenario builder.

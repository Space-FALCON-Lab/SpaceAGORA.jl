# RPOStationAssets — internals

## Purpose
Stands for the `RPOStationAssets` module on workflow sheets: the loader that locates target-station geometry for rendezvous scenarios and turns either a demo point cloud or a Gateway CAD mesh into the sampled surface points that path planning and clearance checks consume.

## Design & Implementation
Members are the STL reader (`_load_stl_triangles`, `_stl_is_binary`), the triangle sampler (`_sample_triangle_point`, `_stl_pointcloud`), the centring helper and the public `load_rpo_station_cad_pointcloud` / `load_rpo_station_pointcloud` entry points together with the path resolvers. On a workflow sheet they collapse to one node; calls in arrive on `members_in`, calls out to the file system helpers leave on `members_out`.

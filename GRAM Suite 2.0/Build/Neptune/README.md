# NeptuneGRAM

Targets:
* all: builds all of the following
* gram: builds the NeptuneGRAM namelist program
* examples: builds the C++ NeptuneGRAM examples
* cexamples: builds the C NeptuneGRAM example
* fexamples: builds the FORTRAN NeptuneGRAM example
* clean: deletes libraries, object files, and executables.

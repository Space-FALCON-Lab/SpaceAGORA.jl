## Findings
- P2 (fixed during review): MuJoCo resets the simulation state on an instability (bad qacc/qpos/qvel) and continues, so a scene could silently produce corrupted results. Fixed in #237: `scene_step!` reads MuJoCo's warning counters and throws.
- P2 (fixed during review): `integrator=:rk4` silently ran Euler on the `mj_step1`/`mj_step2` path. Fixed in #237 by refusing it.
- P3: overwriting shadows with the raw scene state at a sync introduced up to 94 m of error, because the scene trails the solver by up to one dt. The sync now advances the scene state through the lag using the same model as the shadow RHS.
- P3: an ordinary spacecraft in a mixed run is not bit-identical to running it alone. Step-size control uses the norm of the whole state, so any added spacecraft shifts step times at roundoff level (1.5e-8 m). Accepted and documented.
- P3: `scene_body_state` now returns the body-frame rate (an API change to the unmerged #237).

# core/types/effector_sampling.jl

## Purpose
The wrench-based effector contract: typed samples of spacecraft state and environment, the requirements an effector declares, and the hooks the split solver classifies effectors with.

## Design & Implementation
`StateSample`, `PlanetFrameSample`, `AtmosphereSample`, `SolarEphemerisSample`, `ThirdBodyEphemerisSample` and the aggregate `EnvironmentSample` carry exactly what an effector asked for through `EffectorEnvironmentRequirements`; `wrench_caching!` evaluates with memoisation; `solver_partition`, `gravity_backbone_structure` and `gravity_backbone_kick_structure` classify effectors for the partitioned solvers.

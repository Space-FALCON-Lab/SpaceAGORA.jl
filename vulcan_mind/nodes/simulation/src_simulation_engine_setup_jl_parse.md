# simulation/engine/setup.jl · _parse*

## Purpose
Typed environment-variable parsers used by the setup readers: non-negative integers, positive floats and unit-interval floats.

## Design & Implementation
`_parse_nonnegative_int_env`, `_parse_positive_float_env` and `_parse_unit_float_env` each read a variable, apply a default when unset, and raise a named `ArgumentError` on malformed or out-of-range input.

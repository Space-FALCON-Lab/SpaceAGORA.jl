**Animation**
Funciton is writtenn in functions/10_Animation.jl
code inspired from https://juliadynamics.github.io/DynamicalSystems.jl/dev/visualizations/
sample run is in Main3_N_Sats_Example.jl

Due to different step length in ODE solver (caused by adaptive step length), if I do the animation completely according to the status at each time step, there will be fast part in the animation and slow part in the animation.
Therefore, I interpolated the status between the time steps for a smoother animation. This is applied in animate_all_satellites_3d_smooth() function in 10_Animation.jl file.

Added animate_momentum_3d_smooth() function to visualize the moment of each satellite. "combine_vectors = false" means all momentum vectors start from zero. "combine_vectors = true" meanse connect momentum vectors in a head-to-taail manner
This is to investigate the change of angular momentum over time.

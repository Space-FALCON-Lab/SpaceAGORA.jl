Detailed Description

The ProfilePrinter class is an output utility class for Profile data.

This class will write a list of Profile data to a file in various formats. A new print format can be defined by:

  • Defining a style constant, such as GRAM_COLUMN_STYLE.
  • Defining a header function, such as printGramColumnHeader().
  • Defining a Profile print function, such as printGramColumnStyle().
  • Inserting the style into openOutput(), printFileHeader(), printSectionHeader(), printData(), and closeOutput().

This class is easily subclassed for customizing output. Existing print styles my be overridden, or a new print style can be created. For custom print styles, it is recommended that the style constant bit mask use a shift value of 16 or greater.

Examples
common/examples/EphemerisExample.cpp, common/examples/MonteCarloExample.cpp, common/examples/NamelistExample.cpp, and common/examples/TrajectoryExample.cpp.

◆ print()

void GRAM::ProfilePrinter::print ( const PerturbedAtmosphere &  atmos,
const std::vector< ProfileData > &  profile 
)
virtual

Output the profile data for the specified atmosphere.

For all of the selected print styles, this routine will print the provided Profile data for the specified atmosphere. This method will open files, print the data, and close the files. If more than one set of Profile data is to be output, then the openOutput(), printData(), and closeOutput() methods should be called directly.

Parameters
atmosThe PerturbedAtmosphere which generated the data.
profileA list of ProfileData objects.
Examples
common/examples/EphemerisExample.cpp, and common/examples/TrajectoryExample.cpp.

◆ setStyle()

void GRAM::ProfilePrinter::setStyle ( size_t  styleFlag)
inlinevirtual

Designate the desired print styles.

The selection of print styles is accomplised by performing a bitwise-or, "|", of the style masks. For example:

size_t styles = GRAM_DENSITY_STYLE | GRAM_PERTURB_STYLE | GRAM_WINDS_STYLE;
printer.setStyle(styles);
Parameters
styleFlagA bitfield composed of style masks.

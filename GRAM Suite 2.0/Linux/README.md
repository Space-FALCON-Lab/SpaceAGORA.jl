# Linux Executables

These exectuables were created on Redhat 8 using GCC v8.5

To build your own executables on Linux, check out the README file in GRAM/Build.

Files and Subfolders:
- VenusGRAM: The VenusGRAM 2023a exectuable.
- EarthGRAM: The EarthGRAM 2023 exectuable.
- MarsGRAM: The MarsGRAM 2021b exectuable.
- JupiterGRAM: The JupiterGRAM 2021a exectuable.
- NeptuneGRAM: The NeptuneGRAM 2019d exectuable.
- UranusGRAM: The UranusGRAM 2021b exectuable.
- TitanGRAM: The TitanGRAM 2020c exectuable.
- EarthCorrMonte: The Earth CorrMonte exectuable.
- EarthCorrTraj: The Earth CorrTraj exectuable.
- MarsRad: The Mars solar and thermal radiation exectuable.

# AI Review — PR #79: attitude-aware fixed-attitude incidence modes for free-molecular aerodynamics

## Scope

Adds `fixed_attitude_incidence::Symbol` to `AerodynamicCoefficientfM`, consulted only when `orientation_sim=false`. The pre-existing fixed-attitude path pinned every link flow-normal (`α = π/2`) at its full `ref_area` — a permanent maximum-drag attitude. That accounting overstates drag for any vehicle whose mean projected area is smaller than the configured face area, and the error propagates directly into decay-rate predictions.

Three modes:

1. **`:max_drag`** (default) — the historical behavior, preserved bit-identical. The default field value plus an unchanged `else` branch mean previously calibrated scenarios (odyssey / vex / earth_gmat A/B) take exactly the pre-change code path, including the historical *uncomposed* child-quaternion incidence formula, which is deliberately kept verbatim in `_quaternion_link_alpha`.
2. **`:attitude`** — per-link incidence from the configured quaternions through the Hart closed forms (doi 10.2514/1.A33606), interpreted in a flow-aligned frame (velocity along reference +x), giving constant incidence around the orbit. Child quaternions are root-relative (see `vehicle/kinematics`), so `_attitude_link_alpha` composes them with the root attitude — `rot(child.q) * rot(root.q) * e1` — matching the `orientation_sim=true` velocity composition `R' * v`. Sideslip stays zero: pitch-plane attitudes are exact, a yaw-only attitude degenerates to `:max_drag` (documented in the docstring).
3. **`:tumbling_average`** — normal-incidence coefficients charged on the mean projected area per Cauchy's theorem (total surface area / 4, exact for convex bodies; thin-panel limit = one-sided area / 2), for uncontrolled spacecraft.

## Findings

- The review pass over the working tree confirmed one defect in the initial implementation, fixed before commit: `:attitude` originally used the uncomposed `rot(b.q)` incidence for every link, so a child rigidly mounted on a pitched root read flow-normal instead of sharing the root's incidence. Root cause: child quaternions are root-relative (`rotate_to_inertial(child) = rot(root.q)' * rot(child.q)'`), which the `orientation_sim=true` path composes but the historical fixed-attitude formula does not. The composed `_attitude_link_alpha` matches the `orientation_sim=true` convention exactly; the uncomposed formula survives only where bit-compat requires it (`:max_drag` children).
- Frame-convention audit: `rot(q)` maps reference→body, so `atan((rot(q)·e1)[1], (rot(q)·e1)[3])` equals the simulated-attitude convention `α = atan(v_body[1], v_body[3])` under flow along reference +x. Verified sign consistency (45° pitch about y gives the same α as the `orientation_sim=true` path); the transpose misreading would leave drag unchanged (CD even about π/2 at β=0) but flip lift — hence the guard comment at the helper.
- Validation runs in both entry points before any mode dispatch (`_aero_pure_wrench` first statement; `calcForceTorque` ahead of the vacuum early-return), so an invalid symbol can never silently fall through to `:max_drag` behavior. Construction-time validation was considered and deliberately omitted to keep the `@kwdef` struct plain; the fail-fast throw precedes any force computation.
- Probe methodology: dissipation ratios are measured against a drag-free J2-only twin at the **same** final time. The two-body osculating energy carries a J2 oscillation much larger than the drag signal over the probe arc; an early-time baseline aliases it (observed as a wildly wrong ratio in an intermediate probe draft), while the phase-locked twin cancels it to well below the test tolerances.

## P1 Assessment

No P1s. The default mode is bit-identical by construction (default field value + unchanged `else` branch + verbatim historical helpers), and the semantic equivalence pin (`:attitude` ≡ `:max_drag` at identity quaternions, rtol 1e-10 on final orbital energy after a 900 s integrated arc) passes. New behavior is opt-in per model instance.

## Residual Risk

- `:attitude` represents pitch-plane attitudes exactly but pins sideslip to zero, so a yaw-only fixed attitude silently behaves like `:max_drag` (flow into body ±y cannot reduce the modeled incidence). Documented in the docstring; full alpha/beta treatment requires `orientation_sim=true`.
- The `:attitude` quaternion is interpreted in a flow-aligned frame (constant incidence around the orbit). A genuinely inertially fixed body would sweep incidence with true anomaly; users wanting that behavior need `orientation_sim=true`. Documented.
- `:tumbling_average` charges the Cauchy mean projected area with normal-incidence coefficients — the standard randomly tumbling approximation. It does not model the coefficient's own incidence dependence averaged over attitudes (a second-order refinement for Hart-class closed forms) and treats each link's convex hull independently, ignoring inter-link shadowing (a limitation shared with every fixed-attitude path in this file).
- The mode symbol is validated at first force evaluation, not at construction; a misspelled symbol in a batch configuration surfaces when the first RHS evaluates rather than at config build. Fail-fast before any force computation is guaranteed by validation placement at both entry points.
- The quantitative probe tolerances (rtol 0.08 on the Hart CD ratio, 0.02 on the area ratio) rest on the drag-free J2-twin baseline cancelling the osculating-energy oscillation; the residual differential from trajectory divergence over the probe arc is orders of magnitude inside those tolerances, but shortening the probe arc or raising density substantially would need the tolerances revisited.

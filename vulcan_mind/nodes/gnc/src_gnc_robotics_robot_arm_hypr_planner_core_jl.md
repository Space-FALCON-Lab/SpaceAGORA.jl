# gnc/robotics/robot_arm_hypr/planner_core.jl

## Purpose
The top-level arm planner: evaluates joint-space candidates by forward kinematics, clearance and base-reaction cost, runs the swarm, refines, and returns a `RobotArmPlan`.

## Design & Implementation
`plan_robot_arm_motion_hypr` orchestrates; `evaluate_position` and `robot_arm_hypr_path_cost_components` score a candidate; `_robot_arm_hypr_post_refine_points` and `_robot_arm_hypr_refinement_better` refine; `_robot_arm_plan_from_q_reference` builds the timed plan.

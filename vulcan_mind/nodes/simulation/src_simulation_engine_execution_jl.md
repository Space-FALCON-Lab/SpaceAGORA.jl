# simulation/engine/execution.jl

## Purpose
Runs the configured problem: builds the typed solver problem and Jacobian prototype, integrates with checkpoint segments, and saves results.

## Design & Implementation
`run_simulation` (engine-level) drives `_build_typed_solver_problem` and `_build_block_diagonal_jac_prototype`, appends saved segments across checkpoint or backbone restarts, and calls `_save_simulation_results_if_enabled!` with a try-wrapped variant that reports rather than aborts on output failure.

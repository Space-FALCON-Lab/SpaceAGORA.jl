# parallel/process/

## Purpose
The process-worker pool for campaigns: spawns Distributed workers bootstrapped with SpaceAGORA, GRAMSuite and default SPICE kernels, and keeps them warm across campaigns.

## Design & Implementation
`ProcessPool` and the process-global `campaign_process_pool`; `ensure_process_workers!` grows the pool with `_bootstrap_process_worker!`, which loads packages by shipping expressions, furnishes kernels and warms the GRAM wrapper; `shutdown_process_pool!` tears it down.

## Limitations
Bootstrap is best-effort: a worker that failed to load GRAMSuite still joins the pool and fails later on a GRAM sample.

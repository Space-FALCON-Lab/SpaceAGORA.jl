Detailed Description

Set the surface roughness for the sigma-w model.

Parameters
z0Surface roughness for the sigma-w model ( < 0 to use 1-by-1 deg lat-lon surface data; = 0 for speed-dependent z0 over water; or enter a value between 1.0e-5 and 3 for a user-specified z0 value).
atmosAn Earth atmosphere handle.

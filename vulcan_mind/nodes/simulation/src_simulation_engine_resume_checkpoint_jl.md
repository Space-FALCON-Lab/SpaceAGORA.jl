# simulation/engine/resume_checkpoint.jl

## Purpose
Checkpoint paths and the engine-side write, load and clear operations used to resume a long run.

## Design & Implementation
`_checkpoint_directory` and `_checkpoint_paths` resolve locations from the configuration; `_write_checkpoint!`, `_load_checkpoint` and `_clear_checkpoint!` delegate to the IO serialization layer with the engine's schema version.

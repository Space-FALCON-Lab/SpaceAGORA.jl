Detailed Description

Override the default SPICE planetary constants file name.

The NAIF SPICE library use a file containing a number of planetary constants. The location of this file within the SPICE data folder can be specified with this function. The relative path/name is typically of the form "/pck/pck00011.tpc".

Parameters
pckA string containing the PCK file path within the SPICE data folder

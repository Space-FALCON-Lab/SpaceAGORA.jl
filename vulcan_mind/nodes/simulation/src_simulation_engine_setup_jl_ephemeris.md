# simulation/engine/setup.jl · _ephemeris*

## Purpose
The process-wide reuse cache for ephemeris tables, so repeated runs with the same epoch and span share one SRP, N-body or planet-frame table.

## Design & Implementation
`_ephemeris_reuse_enabled` and `_ephemeris_reuse_max_entries` gate it; `_ephemeris_reuse_lookup` and `_ephemeris_reuse_store!` operate under the reuse lock with an entry cap; `_ephemeris_explicit_cache_store!` registers prewarmed tables with optional replacement.

# gnc/control/momentum_manager.jl

## Purpose
Magnetic reaction-wheel desaturation: estimates stored wheel momentum and commands a torque-rod dipole to bleed it off.

## Design & Implementation
`MagneticMomentumManager` holds the estimate and callbacks; `calcControlEffect!` integrates wheel momentum from the commanded torque history each tick; `calcControlForceTorque` returns the latched body torque with zero force.

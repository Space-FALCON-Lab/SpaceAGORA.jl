# GRAM Examples

Files and Subfolders:
- ExampleRunner.cpp: Runs a number of examples from common/examples.  This example works for all planets.
- GRAM.cpp: The GRAM main program for all planets. This is meant as an example of using more than one GRAM model in a program.  It if recommended that you use the custom GRAM programs (EarthGRAM, MarsGRAM, etc.) for analysis.
- GRAM_C.c: An example of using the generic C interface for multiple planet models.

# GRAM

Each of the input files contains a SPICE data path that should be edited to match your system.

Files and Subfolders:
- Earth.txt: Inputs for EarthGRAM.
- Jupiter.txt: Inputs for JupiterGRAM.
- Mars.txt: Inputs for MarsGRAM.
- Neptune.txt: Inputs for NeptuneGRAM.
- Titan.txt: Inputs for TitanGRAM.
- Uranus.txt: Inputs for UranusGRAM.
- Venus.txt: Inputs for VenusGRAM.
- find_dates.txt: Sample namelist inputs for finding LS/LTST dates using GRAM.
- spice.txt: Namelist input file for overriding the default SPICE data path.

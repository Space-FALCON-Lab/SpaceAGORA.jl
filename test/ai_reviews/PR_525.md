## Findings

P2: automatic registration considered virtual terminals compatible even when a
mounted/pointing laser or Shannon radio budget requires physical hardware. It
could reject a configuration with valid mounted terminals. Filter virtual
candidates using the same hardware-requirement hook as explicit registration.

Independent review found a related inherited P2: automatic selection ignored the
endpoint role. On spacecraft carrying both a laser and a power receiver it chose
the laser at the receiver end, then explicit validation refused it. Derive the
roles from each pair's link and pass them to the three-argument support hook.

The selection keeps existing round-robin allocation among compatible terminals.
Virtual terminals remain supported for kinds that do not require hardware.
Explicit terminal choices retain their existing validation.

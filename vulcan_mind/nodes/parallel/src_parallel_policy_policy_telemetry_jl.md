# parallel/policy/policy_telemetry.jl

## Purpose
Records every threading decision and observation into the active context's telemetry and exposes a snapshot for reporting.

## Design & Implementation
`_record_policy_decision!` updates totals, per-bucket counters and the last-decision fields under the telemetry lock; `_adaptive_state_for` returns the per-source adaptive controller; `reset_policy_telemetry!` clears the context; `policy_telemetry_snapshot` returns a named tuple with derived efficiency fractions.

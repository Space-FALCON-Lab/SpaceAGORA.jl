# gnc/hypr/

## Purpose
The shared HYPR utilities both the RPO and robot-arm planners build on: path length, Bezier evaluation, PSO schedules and elites, and RRT tree operations.

## Design & Implementation
`HYPRUtils` exports curve, swarm and tree helpers that are agnostic to the state dimension, with duck-typed accessors that tolerate the two planners' different tree field names.

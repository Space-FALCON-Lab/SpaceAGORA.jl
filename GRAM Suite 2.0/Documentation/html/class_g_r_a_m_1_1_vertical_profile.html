Detailed Description

Generate a vertical height profile over a specified position.

A vertical profile is defined by specifying an initial position, a height delta, and the number of data points desired.

Usage
Instantiate an atmosphere for a planet and set its input parameters. Next, provide that object to the VerticalProfile with setAtmosphere(). Set the VerticalProfile's initial position and height conditions with setInitialPostion() and setHeightConditions(). Call the generate function to run the model. Access the results with getProfile().

Detailed Description

Common values for the Venus atmosphere models.

Common values for the Venus atmosphere models. All Venus atmosphere models should inherit this class.

(1) Data from NSSDCA Planetary Fact Sheet for Venus (https://nssdc.gsfc.nasa.gov/planetary/factsheet/venusfact.html). Page last updated on Sept. 27, 2018.

(2) Data from NAIF Spice files (de430_tech-comments.txt).

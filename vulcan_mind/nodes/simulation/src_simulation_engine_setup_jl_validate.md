# simulation/engine/setup.jl · _validate*

## Purpose
Configuration validation before a run: inertia tensors for attitude simulation, ephemerides support for the configured effectors, and thermal model support.

## Design & Implementation
`_validate_orientation_inertia!` requires finite, symmetric, positive-definite inertia when orientation is simulated; `_validate_ephemerides_support!` rejects SPICE-dependent effectors under the simple ephemerides; `_validate_thermal_model_support!` checks the thermal model against the density model.

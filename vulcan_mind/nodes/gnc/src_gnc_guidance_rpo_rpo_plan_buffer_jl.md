# gnc/guidance/rpo/rpo_plan_buffer.jl

## Purpose
The plan the RPO controller tracks and the buffer that swaps it atomically when guidance replans.

## Design & Implementation
`RPOPlan` holds time-stamped RTN reference positions and velocities; `RPOPlanBuffer` holds the current plan per satellite; `update_rpo_plan_buffer!` replaces it.

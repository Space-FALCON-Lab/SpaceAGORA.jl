# core/types/runtime_types.jl

## Purpose
Every runtime container a simulation carries: the legacy `Solution` record and its sub-structs, the scratch workspaces, ephemeris and density caches, environment snapshots, `SharedBuffers` and `ODEParams`.

## Design & Implementation
Thirty-five types. The push-based output structs (`Orientation`, `Physical_properties`, `Performance`, `Forces`, `Simulation`, `Closed_form`), the per-effector scratch workspaces, the three ephemeris caches and two density caches, the three env-config snapshots, `SpiceRuntimeCounters`, `SpiceRhsMemo`, and finally `SharedBuffers` and `ODEParams` which hold references to all of the above.

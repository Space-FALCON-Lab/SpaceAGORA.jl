Gravity and Forces

Use this page to choose the gravity model and the other force and torque models that act on your spacecraft. They are listed in the effector tuple of DynamicsModel, which Configuring a Simulation describes.

What to read next:

  • Adding a Force or Torque
  • Configuring a Simulation
  • The Integrated State

Built-in gravity models

The effector tuple accepts any combination of AbstractForceTorqueModel implementations. The built-in gravity models:

  • SM.InverseSquaredGravityModel() — inverse-square point-mass gravity
  • SM.InverseSquaredJ2GravityModel() — point-mass gravity with J2 oblateness
  • GravitationalHarmonicsModel(L, M, coefficients_file, planet) — spherical-harmonic gravity to degree L and order M
  • NBodyGravityModel(body_names=..., primary_body_name=..., planet=planet) — third-body gravity from ephemerides for the listed bodies, for example NBodyGravityModel(body_names=("Sun", "Moon"), primary_body_name="Earth", planet=planet)

Forces you write yourself enter the same tuple; see Adding a Force or Torque.

Spherical-harmonic gravity

GravitationalHarmonicsModel(L, M, coefficients_file, planet) evaluates the gravity field to degree L and order M (with M <= L) from a file of coefficients. By default it includes the central point-mass term, so use it instead of InverseSquaredGravityModel() or InverseSquaredJ2GravityModel(), not alongside them: listing both counts the central attraction twice. Pass the same planet object as the rest of the configuration and a coefficients file for that body. This is the Your First Script example with degree-8 Earth gravity:

using SpaceAGORA

planet = make_no_gram_planet(:earth)
spacecraft = make_three_body_spacecraft(
    bus_dims=(2.0, 2.0, 2.0), panel_dims=(0.01, 2.0, 1.0),
    bus_mass=500.0, panel_mass_each=10.0, panel_offset_y=2.0,
    ic=InitialCondition(ra=planet.Rp_e + 500e3, rp=planet.Rp_e + 500e3,
                        i=45.0, ω=0.0, Ω=0.0, ν=0.0),
)
coefficients = joinpath(pkgdir(SpaceAGORA), "data", "planets", "gravity", "EarthGGM05C.csv")
gravity = GravitationalHarmonicsModel(8, 8, coefficients, planet)
config = make_example_config(
    planet=planet, spacecraft=spacecraft, mission_time=300.0,
    initial_time=InitialTime(year=2024, month=1, day=1),
    dynamic_effectors=(gravity,),
    ephemerides_model=SimpleEphemeridesModel(), results=false,
)
run_simulation(config)

The repository's coefficient files, fully normalized with columns degree,order,C,S, are in data/planets/gravity/. They include EarthGGM05C.csv and egm96.csv for Earth, Mars50c.csv and GMM2B.csv for Mars, MGNP180U.csv for Venus, LP165P.csv for the Moon and titan5.csv for Titan; the README.md in that folder lists every file, including variants with other tide conventions, with its source. Asking for a degree beyond what a file contains is refused with an error. Run time grows with the degree, so start low and raise it once the setup works; AGORA_Earth_Aerobraking.jl, AGORA_Odyssey.jl and AGORA_Vex.jl use degree and order 50. Keywords select other coefficient normalizations (coefficient_normalization=:schmidt or :unnormalized) and a perturbation-only term (include_central=false); the Simulation Setup API entry lists them.

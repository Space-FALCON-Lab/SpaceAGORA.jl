SpaceAGORA.SimulationModel.RobotArmPlanning.plan_robot_arm_motion — Function
plan_robot_arm_motion(model, base_pose, q_start, target; config, planner=:cloth_quintic,
                      hypr_config=nothing, obstacles=RobotArmSphereObstacle[], rng=nothing)

Plan a joint-space motion from an initial state to a target surface point. The default :cloth_quintic planner is deterministic and draws no random numbers. planner=:hypr samples, so it requires an explicit rng (an AbstractRNG); there is no default global stream.

source
SpaceAGORA.SimulationModel.RobotArmPlanning.plan_robot_arm_motion_hypr — Function
plan_robot_arm_motion_hypr(model, base_pose, q_start, target;
    planner_config=RobotArmPlannerConfig(), hypr_config=RobotArmHYPRConfig(),
    obstacles=RobotArmSphereObstacle[], rng)

Plan a robot-arm trajectory with HYPR sampling, PSO search, optional RRT warm start, and retiming. q_start is the initial joint configuration; target is the end-effector target passed to inverse kinematics. rng (an AbstractRNG) is required and owns every random draw; there is no default global stream. Load SpaceAGORAHYPR before calling this function. The returned RobotArmHYPRResult holds the joint reference and end-effector trajectory in its plan field, together with planning metrics.

source

robot_arm_hypr_path_cost_components(points, model, base_pose, obstacles, cfg;
    cost_cutoff=Inf)

Evaluate HYPR objective components for a candidate robot-arm joint path. Columns of points are joint-space control points; cfg is a RobotArmHYPRConfig. Returns the sampled path's cost and feasibility components. Load SpaceAGORAHYPR before calling this function.

## Findings

- P2, fixed: the `MIXED` sentinel compared equal across unrelated inconsistent or empty state collections. A missing timed dump could also leave one digest and falsely qualify all repeats. Reports now require exactly `sum(raw.mc_samples)` regular state dump files and one distinct digest per point; sentinels never establish equality. Arbitrary code tags no longer produce an empty `pre`/`post` comparison.
- P2, fixed: a failed point or expired quiet wait printed a failure but the whole stage exited successfully. An aggregate counter now returns a nonzero stage status while later points still run and completed points remain resumable.
- P2, fixed: stripping `_saved` selected a longer mission for the saving-off allocation control at N >= 128 under smoke/full profiles. The control now reconstructs the original case and changes only `results=false`. The recorded default N=32 profile was unaffected by this duration mismatch.

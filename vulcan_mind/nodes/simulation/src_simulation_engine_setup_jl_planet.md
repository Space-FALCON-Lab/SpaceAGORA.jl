# simulation/engine/setup.jl · _planet*

## Purpose
Configuration and keying of the planet-frame orientation table that replaces per-step SPICE `pxform` calls with quaternion interpolation.

## Design & Implementation
`_planet_frame_cache_enabled`, `_planet_frame_cache_dt_s` and `_planet_frame_cache_max_samples` read the environment knobs; `_planet_frame_ephemeris_reuse_key` keys a table by planet name, ephemerides model key, epoch, span and step so the process-wide reuse cache can share it; `_planet_transform_key` identifies one frame transform request for memoisation.

## Limitations
Reuse requires an exact key match on epoch and span, so runs that differ by a second never share a table even though the orientation samples would be nearly identical.

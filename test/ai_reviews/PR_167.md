# PR 167: manuscript-conforming HyPR mode and acceleration-limited retiming

## Scope

Add a `:manuscript` HyPR mode that follows the HyPR manuscript (Sec. III.A to III.E): RRT-Connect warm start first, exploration score η from its detour and iteration count, η-derived coefficients and counts, Eq. 5 objective with the Eq. 6 threshold d_safe + τ_tol, the HCW fuel proxy on each candidate's retimed reference, and retiming with d_avail = c − d_safe. Add acceleration-limited retiming (forward and backward passes, boundary speeds, positions on the curve). Fix the LQ-MPC reference-preview index on floating-point update times. Add an optional controller log. Move the ISS viewer demo to its +XVV flight attitude and a V-bar relocation planned in the new mode. A later revision of the manuscript reverses the Sec. III.A coefficient equations to match its prose, defines the search region B as the station's bounding box with prescribed margins, states the culling start, σ_resp and α_bez, adds the departure-from-rest term to the fuel proxy and gives the global speed limit and the MPC horizon; the `:manuscript` mode follows that revision, the example gains MPC-horizon and epoch options, and the ISS demo uses Table I's horizon, the 0.25 m/s limit, a denser point cloud with a smaller τ_tol and a daylit epoch. Reviewed: the whole diff against `main`, the manuscript sections it implements in both revisions, and the legacy paths it must leave unchanged.

## Findings

- P2 (fixed in this PR), `src/gnc/control/rpo_mpc/lqmpc.jl`: `floor(t/dt)` dropped one sample whenever t/dt fell just below an integer (for example 16.2/0.1), so on those updates the MPC tracked a reference one step behind and commanded alternating corrections. Found from the new controller log; the preview now tolerates the rounding, and a unit test covers update times that trigger it. This changes tracking for every RPO MPC run.
- P2 (fixed in this PR), `scripts/dev/viewer_demos/iss_hypr.jl`: the identity model rotation held the ISS display model upside down with port and starboard swapped, because the model's height axis points toward nadir and its truss axis toward starboard. The truss and module directions were right, which is all the earlier test checked. A half turn about the module axis gives +XVV (forward along the velocity, starboard toward -N, zenith up), and the station test now pins the signs.
- P2 (fixed in this PR), manuscript Sec. III.A: the first revision's equations made c1 grow and c2 shrink with η while its prose said the opposite, and this PR first followed the equations. The revised manuscript corrects the equations to match the prose, and the mapping now follows it: c1 falls and c2 rises with η.
- P3 (fixed in this PR), manuscript Sec. III.C-D, Table I: in `:manuscript` mode the swarm searched the warm-start path's box, culling noise scaled with the box width, and the ISS demo culled from iteration 8. The mode now searches the station's bounding box with prescribed per-axis margins and uses σ_resp as a fixed length, and the demo culls from iteration 10 ("wait 10").
- P3 (fixed in this PR), manuscript Sec. III.B: the fuel proxy counted the braking at the goal but not the departure from rest that the revised text states. Both the stored and the streamed proxy now hold the reference at rest before its first sample and after its last.
- P3 (documented): choices where the manuscript is silent or scale-specific are stated in docstrings: the η-derived control-point count is kept (the warm start is fitted to it), warm-start edges keep d_safe + τ_tol, the warm start skips HyPR post-refinement, re-exploration raises the control-point count and the search margin but not the particle count, and continuous thrust stands in for the PWM throttle.
- The legacy mode was checked by running the same seeded inputs on `main` and on this branch: plans, costs, cost histories, cost components, references, retiming profiles, and RRT-Connect and RRT-Connect + Bézier paths are identical.

## Residual Risk

- Clearance to the station is checked at samples of the path against a point cloud, with τ_tol covering the cloud's spacing; it is not a continuous collision certificate, and the MPC has no collision constraint.
- The acceleration limit bounds the tangential term; the centripetal and HCW terms are bounded by the curvature limit and the scenario, and are reported rather than enforced.
- The demo's excluded meshes are named explicitly; a different display model would need its own review.
- With the manuscript's 0.25 m/s global limit and k_v = 0.5, the ISS demo's reference runs at the limit between its acceleration ramps; the clearance and curvature limits act only closer to the station than this route goes.

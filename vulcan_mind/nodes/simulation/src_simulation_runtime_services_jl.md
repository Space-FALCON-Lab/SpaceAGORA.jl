# simulation/runtime_services.jl

## Purpose
Process-wide runtime services: the SPICE and GRAM locks that every native call serialises on.

## Design & Implementation
`RuntimeServices` defines `SPICE_LOCK` and `GRAM_LOCK` as `ReentrantLock`s and documents why they must be shared — the native GRAM library statically links its own CSPICE with the same exported symbols as the Julia SPICE bindings.

#include <MarsAtmosphereState.h>

Detailed Description

The augmented output state of a Mars atmosphere model.

The MarsAtmosphereState provides Mars model specific metrics as an extension to the AtmosphereState class using AtmosphereState::planetSpecificMetrics.

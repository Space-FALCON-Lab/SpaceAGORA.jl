◆ initializeData()

void GRAM::VenusIRALow::initializeData ( )

Populate the lower atmosphere tables.

The lower atmosphere data is stored in static structures (shared by all instances). Initially, all data resides in a vector of VIRALowData structs. This data is relocated and possibly modified into vectors dimensioned by height and latitude.

Inputs

  • data The initial structure of the data.
  • initialized Flags when data has been initialized.
Returns
The static data tables are populated.

◆ setLowerHeightIndex()

greal GRAM::VenusIRALow::setLowerHeightIndex ( )

Finds and sets the lower bound index for the current height.

This routine finds the interpolation segment in the VIRA Low data based on the current height (so setPostion() should be called first). It then sets the internal height index to the lower bound of that segment.

Inputs

  • position The position must be set before calling this function.
Returns
The height at the lower bound index.

◆ update()

void GRAM::VenusIRALow::update ( )
overridevirtual

Interface for the primary atmosphere computations.

This routine computes the atmospheric state for the current position but at the height indicated by the current height index. Either setLowerHeightIndex() or setUpperHeightIndex() must be called prior to calling this function in order to set the desired height index.

Inputs

  • position The position must be set before calling this function.
  • heightIndex The height index must be set proior to calling this function.
Returns
The AtmosphereState is populated.

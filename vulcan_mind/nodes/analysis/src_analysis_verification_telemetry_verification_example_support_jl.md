# analysis/verification/telemetry_verification/example_support.jl

## Purpose
Shared helpers that let example scripts build the standard three-body vehicle and configuration, run, and report, with a CI smoke mode.

## Design & Implementation
`make_three_body_spacecraft` and `make_example_config` construct the reference vehicle and a full `SimulationConfiguration`; `run_and_report` runs and prints timing; the `_example_smoke_*` helpers read environment variables that shorten missions and suppress output for automated runs.

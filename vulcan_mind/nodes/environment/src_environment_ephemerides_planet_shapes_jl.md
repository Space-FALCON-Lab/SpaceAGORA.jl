# environment/ephemerides/planet_shapes.jl

## Purpose
Spherical-harmonic topography for Earth, Mars and Venus, used to measure altitude above terrain instead of above the reference ellipsoid.

## Design & Implementation
`calculate_topography_harmonics!` evaluates the expansion with `fnALF_IDR!` computing associated Legendre functions by recursion, and `Earth_elevation!`, `Mars_elevation!` and `Venus_elevation!` wrap it with each body's coefficient set.

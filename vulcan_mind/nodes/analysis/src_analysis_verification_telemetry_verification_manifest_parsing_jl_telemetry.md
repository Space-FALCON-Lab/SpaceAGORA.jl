# analysis/verification/telemetry_verification/manifest_parsing.jl · _telemetry*

## Purpose
Solver settings for verification runs resolved from environment variables: iteration cap per profile, retry cap, and solver mode.

## Design & Implementation
`_telemetry_solver_maxiters` picks a quick or full default and honours an override, `_telemetry_solver_retry_maxiters` guarantees the retry exceeds the first attempt, and `_telemetry_solver_mode` falls back from the telemetry-specific variable to the global one and then to `auto_stiff`.

## Findings

Resolved: default-field fusion could allocate fallback storage without calling its getter, leaving additional default values uninitialized and throwing during growth or materialization. The record function now executes each fallback getter independently of whether built-in fields were fused. Explicit field lists keep their getter semantics.

Resolved: explicit capacity bypassed sampling-rate validation. All construction paths now reject zero, negative and nonfinite rates with ArgumentError.

Default built-in output calculations were compared statically with the existing SaveField getters. The original integrated test compares vacuum translational snapshots. The new current-main regression compares all default fields during atmospheric drag/heating with propagated attitude, using both callback orders and requiring nonzero drag, heating, final heat loads and changing quaternions. It establishes recorder/getter parity, not an independent thermal physics oracle or native-GRAM equivalence.

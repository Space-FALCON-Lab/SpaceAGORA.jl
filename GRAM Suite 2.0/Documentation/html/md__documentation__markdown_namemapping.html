Variable Name Mapping (Legacy versus New GRAM)

This document contains a list of new variable names corresponding to the legacy FORTRAN names. Since the legacy GRAMs did not always follow a naming convention, this list may not be exhaustive. The units of the legacy and new GRAMs may differ. EarthGRAM names tend to differ from the other GRAMs and are presented in this table.

# dynamics/coupled/perturbations.jl · gravity*

## Purpose
The hooks that classify harmonics and N-body effectors for the split gravity-backbone solver and expose their accelerations to it.

## Design & Implementation
`gravity_backbone_structure` marks harmonics as position-only static gravity, `gravity_backbone_kick_structure` marks N-body as an explicit velocity kick, and `gravity_backbone_acceleration_ii` and `gravity_backbone_kick_acceleration_ii` return the corresponding accelerations from a state and environment sample.

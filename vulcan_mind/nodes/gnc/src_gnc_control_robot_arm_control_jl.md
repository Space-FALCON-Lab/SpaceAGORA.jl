# gnc/control/robot_arm_control.jl

## Purpose
The joint-space controller for the robot arm: tracks a planned joint trajectory with a joint MPC and applies the resulting joint torques and base reaction.

## Design & Implementation
`RobotArmControlEffector` with `RobotArmHeldActuation`; `init_robot_arm_joint_mpc` builds the joint prediction model, `robot_arm_joint_mpc_reference_preview` windows the plan, `robot_arm_measured_joint_state` reads joints from the state, and the `calcControl*` methods apply the held actuation. Quaternion helpers handle the arm's base attitude.

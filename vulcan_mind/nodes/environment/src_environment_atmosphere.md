# environment/atmosphere/

## Purpose
Every atmospheric density model the engine can fly: vacuum, exponential, piecewise, polynomial fit, NRLMSISE-00, GRAM (through the extension), tabulated flight data, and time-tabulated density.

## Design & Implementation
One file, `density_models.jl`, with a struct and `getDensity` method per model, batch evaluation for constellations, the GRAM wrapper types whose implementations arrive from `SpaceAGORAGRAMSuiteExt`, and the NRLMSISE-00 space-indices provider.

# analysis/visualization/

## Purpose
Plotting for rendezvous and proximity operations: the planned path against station geometry and the tracking error over time.

## Design & Implementation
`RPOVisualization` exposes `rpo_path_plot`, which draws the RTN path, keep-out sphere and station point cloud, and `rpo_tracking_plot`, which plots reference-versus-actual relative state. Both accept the plan and geometry types from the GNC navigation and guidance modules.

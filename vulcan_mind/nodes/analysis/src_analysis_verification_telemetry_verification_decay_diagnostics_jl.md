# analysis/verification/telemetry_verification/decay_diagnostics.jl

## Purpose
Physics-based diagnostics of orbital decay used to explain a verification result rather than score it.

## Design & Implementation
`visviva_sma` recovers semi-major axis from speed and radius, `secular_sma_slope` fits the long-term decay rate, `zero_referenced_decay` removes the initial offset so simulation and flight decay curves can be overlaid, and `flight_density_table` tabulates the density a decay implies for comparison with the atmosphere model.

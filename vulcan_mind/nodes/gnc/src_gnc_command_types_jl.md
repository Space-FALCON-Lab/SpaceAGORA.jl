# gnc/command_types.jl

## Purpose
The command records passed from guidance to control: aerobraking attitude commands, propulsive manoeuvre commands, and burn plans.

## Design & Implementation
`AerobrakingControlCommand` carries the angle-of-attack and mode a control effector should realise; `PropulsiveManeuverCommand` carries a requested delta-v and direction; `PropulsiveBurnPlan` is the scheduled burn window a thruster model executes. All three live in `CommandTypes` so guidance and control share them without a circular dependency.

## Limitations
Commands are mutable per-satellite records held in shared buffers, so a stale command persists until the guidance callback next fires.

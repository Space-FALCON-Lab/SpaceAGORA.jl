What it does:
- **Terminals.** Mounted terminal hardware becomes interlink terminals, numbered after the virtual ones.
- **Directed links and registration.** Links can be directed, and candidate links can be registered from a list of spacecraft pairs.
- **Link-driven terminals.** A hardware terminal that is a link endpoint runs at its link's level, draws that power, applies no recoil, and closes its links when the battery sheds it.

Rule: runs whose links join virtual terminals are bitwise unchanged.

## Findings

No P1 or P2 findings.

Points a reviewer should check:

- **Bitwise identity.** Every new path is gated by `link_driven`, which is
  false without hardware endpoints:
  - the controller-level mask returns the same vector;
  - no link load is added;
  - the saved power adds nothing (guarded, so a `-0.0` is not turned into `0.0`);
  - `terminal_availability` returns `nothing`;
  - the checkpoint configuration has no new key.

  Keys of undirected links are the same `minmax`. The extra initialization
  callback repeats the first scheduling, with the same selection, and runs at no
  step. The two laser examples and the fingerprints below confirm it.
- **Low, by design: both ends draw for a laser momentum link.**
  `link_terminal_levels(::LaserMomentumLink)` is `(power_w, power_w)`, as the
  design draft proposed. A kind that pays at one end only returns
  `(level, 0.0)`.
- **Low, by design: a shed terminal keeps its demand.** Without this, closing
  the link would drop the demand, the tier would clear, and the link would
  reopen every step. The tier now clears when the battery can supply the link
  again, which is the semantics of controller-driven lasers.
- **Low: faults.** Actuator faults on a link-driven terminal act on neither its
  link nor its draw. The interlinks page says so.
- **Low: the setup notice is `@info`.** "Setup says so once" (D-I2-2) is an
  `@info` rather than a pre-run warning. Pre-run warnings throw under
  `--depwarn=error`, which would refuse a valid configuration: a spacecraft with
  attitude control and linked laser terminals.
- **Merge with main.** Main's `docs/make.jl` (from #435) already has the
  Interlinks API page this branch had added. Only the Constellations line
  conflicted, and main's file was taken whole.

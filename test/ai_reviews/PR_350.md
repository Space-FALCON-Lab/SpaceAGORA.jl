## Findings

Author's notes for the reviewer (no blocking finding known to the author):

- **Low, compatibility by design:** this PR alone fails core CI's required
  `optional-mujoco-installation` job, because the gitlinked companion (0.1.0) asks
  for contract 1.0.0. That is the lockstep protocol (hook design 4.8): the gitlink,
  `packages/OptionalPackages.toml` (`mujoco` version 0.2.0) and the MuJoCo row of
  `packages/robotics/README.md` move in a second commit after the companion PR merges.
- **Low, silent swap for untyped user methods:** the two positions have different
  types, so a method typed `(rt, k::Int, t::Float64)` matches no 2.0.0 call. An
  untyped external method `(rt, k, t)` would receive the arguments swapped; the exact
  version check is the guard, and the reference page tells adapter authors to update
  the methods and the required version together. No such method exists in the
  repository or the companion.
- **Low, test coverage:** the core test owner owns one spacecraft, so `slot` is
  always 1 in core tests. A slot mix-up planted in the sync callback passes
  `external_propagation_tests.jl` unchanged. It is caught by the companion suite, which
  core CI runs (its scenes own two bodies), and by this PR's two-slot base-versus-branch
  driver (below).
- **Note, step 5:** #344 has merged, so the gitlink and the MuJoCo row of
  `packages/robotics/README.md` on `main` now name the companion's memory-test commit.
  The step-5 commit merges `main` into this branch first, then moves them.

Reviewer to verify:

- **Only order and wording change in `src/`.** In each changed call the arguments are
  the same expressions, reordered; no arithmetic changed.
- **No other caller or implementer is left in the 1.0.0 order:**
  `git grep -n "external_state\|external_acceleration" -- src test docs examples
  templates ext benchmarks scripts` (the only methods are the declarations and the
  test owner; `test/unit/simulation/interlink_tests.jl` and
  `test/unit/mission/operational_segments_tests.jl` define owners that never reach
  these hooks).
- **The documented formula is the engine's convention:** `rot(q) = (w^2 - e⋅e) I +
  2 e eᵀ - 2 w [e×]` equals `src/foundation/core/numerics/quaternion_utils.jl`'s `rot`
  (the new testset), and `dynamics_rhs.jl` uses `rot(q)` to map inertial to body.
- **The reference page and the adapter standard read correctly**, including the
  statement that `StateSample.spacecraft_index` was added while the contract was 1.0.0.
- **The companion PR's hosted CI result** against this head
  (Space-FALCON-Lab/SpaceAGORAMuJoCo.jl#8; the author's runs above are local).

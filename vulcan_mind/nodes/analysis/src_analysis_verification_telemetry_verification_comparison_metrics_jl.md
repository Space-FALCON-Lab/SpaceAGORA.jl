# analysis/verification/telemetry_verification/comparison_metrics.jl

## Purpose
The scoring functions that turn a simulated series and a telemetry series into residuals and summary statistics.

## Design & Implementation
`_compare_time_series` aligns two series on a common axis with `_interp_linear` and `_normalized_axis`, `_compare_orbit_curve` scores apsis altitudes against orbit number with optional bias and span masking, `_rates` derives per-orbit decay rates, and `_apo_decay_diagnostic` reports the apoapsis decay slope relative to flight. Each returns a summary named tuple plus the raw error table.

## Limitations

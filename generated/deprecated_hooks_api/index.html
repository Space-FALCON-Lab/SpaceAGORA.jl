Deprecated Hooks API

This page documents the supported public interface available from SpaceAGORA.

Deprecated hooks

SpaceAGORA.SimulationModel.DynamicEffectors.calcForceTorque — Function
calcForceTorque(model, x, p, i) -> (force_n, torque_n_m)

Deprecated: implement wrench(model, x::StateSample, env::EnvironmentSample, t::Float64) instead. calcForceTorque will be removed in SpaceAGORA 0.5.0.

The older force and torque hook for an AbstractForceTorqueModel. x is the spacecraft's state view (x.pos, x.vel, x.mass, and with attitude propagation x.q and x.ω), p the run's parameters and i the spacecraft's position in the run (from 1). It returns the force in the inertial frame in N and the torque in the bus frame in N·m. The dynamics call a model's own calcForceTorque method only when the model has no wrench method, and the run warns about it before integration.

Called on a model with wrench, as every built-in model is, it warns once per model type and evaluates that wrench at the run's current time with the state sample and environment built from x, writing spacecraft i's drag diagnostics.

source
SpaceAGORA.SimulationModel.ControlHooks.calcControlForceTorque — Function
calcControlForceTorque(model, u, p, spacecraft_index, t) -> (force, torque)

Deprecated, use control_wrench(model, x::StateSample, p, t); this name will be removed in SpaceAGORA 0.5.0. The new hook takes the spacecraft's state as a sample, the time before the index, and the index from x.spacecraft_index. Its frames and units are this hook's.

Until then the dynamics call an effector's own method of this hook when its type has no control_wrench, and run_simulation warns once per type before integration starts. u is the state of that spacecraft alone (u.pos, u.vel, u.mass, and with attitude propagation u.q and u.ω), and spacecraft_index its position in the run (Int, from 1). The returned force is inertial, in N, and torque is in the bus frame, about the root body's centre of mass, in N·m.

A direct call on an effector that implements control_wrench returns that hook's result, and warns once per type that it is deprecated (under julia --depwarn=error it throws instead).

source
SpaceAGORA.SimulationModel.ControlHooks.calcControlMassFlowRate — Function
calcControlMassFlowRate(model, u, p, spacecraft_index, t) -> Float64

Deprecated, use control_propellant_rate(model, x::StateSample, p, t); this name will be removed in SpaceAGORA 0.5.0. The sign changes: this hook returns the spacecraft's mass derivative in kg/s, negative while propellant is used, and control_propellant_rate returns the propellant used, positive.

Until then the dynamics call an effector's own method of this hook when its type has no control_propellant_rate, and run_simulation warns once per type before integration starts. The arguments are those of the deprecated calcControlForceTorque. An effector with neither method uses no propellant.

A direct call on an effector that implements control_propellant_rate returns that hook's result negated, and warns once per type that it is deprecated (under julia --depwarn=error it throws instead). On any other effector it returns 0.0.

source
SpaceAGORA.SimulationModel.ControlHooks.calcReactionWheelTorque — Function
calcReactionWheelTorque(model, u, p, spacecraft_index, t) -> Union{Nothing, AbstractVector}

Deprecated, use control_wheel_torque(model, x::StateSample, p, t); this name will be removed in SpaceAGORA 0.5.0. The torque, its frame and how the dynamics apply it are unchanged.

Until then the dynamics call an effector's own method of this hook when its type has no control_wheel_torque, and run_simulation warns once per type before integration starts. The arguments are those of the deprecated calcControlForceTorque. An effector with neither method drives no wheel.

A direct call on an effector that implements control_wheel_torque returns that hook's result, and warns once per type that it is deprecated (under julia --depwarn=error it throws instead). On any other effector it returns nothing.

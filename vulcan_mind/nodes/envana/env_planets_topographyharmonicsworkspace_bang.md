# TopographyHarmonicsWorkspace!

## Purpose
`TopographyHarmonicsWorkspace!` loads a topography coefficient file for a concrete planet and precomputes every constant needed by the normalised associated Legendre recursion, so that per-sample elevation evaluation performs no allocation and no repeated square roots.

## Theory & Math
Fully normalised associated Legendre functions are generated by the recursions `Pbar_{nn} = f_n * cos(phi) * Pbar_{n-1,n-1}` and `Pbar_{nm} = G_{nm} * sin(phi) * Pbar_{n-1,m} - H_{nm} * Pbar_{n-2,m}`. This function tabulates the three constant families: `f_n = sqrt((1 + delta_{n1})(2n + 1) / (2n))`, `G_{nm} = sqrt(((2n + 1)(2n - 1)) / ((n + m)(n - m)))`, and `H_{nm} = sqrt(((2n + 1)(n - m - 1)(n + m - 1)) / ((2n - 3)(n + m)(n - m)))`, all dimensionless. Here `n` is degree, `m` is order, and `delta_{n1}` is the Kronecker delta that handles the sectorial seed.

## Model & Assumptions
An empty `topo_harmonics_file` string is treated as a request to skip topography entirely, leaving the workspace untouched. Degree `N` and order `M` are inferred from the shape of the coefficient matrix returned by `read_topography_harmonics`, so the file itself defines truncation. `H_{nm}` is only defined for `n > m + 1`; the code guards this with `if i > j + 1` and leaves the remaining entries at zero.

## Design & Implementation
The `G` and `H` matrices are allocated with `Matrix{Float64}(undef, N + 1, M + 1)` for speed and then zero-filled so unused triangular entries are safe to read. The nested loops are `@inbounds`, iterating `j` over orders and `i` over degrees strictly above the diagonal. A `Plm` evaluation matrix of the same shape is preallocated last, giving the per-call kernel a ready scratch buffer. The trailing `!` marks in-place mutation of `planet.topography_workspace`.

## Limitations
The routine mutates a mutable workspace held by an otherwise immutable planet struct, so two simulations sharing one planet instance would share the buffer and cannot be evaluated concurrently. No validation is applied to the coefficient file contents beyond its array shape, and a mismatch between the file's normalisation convention and these recursion constants produces silently wrong elevations.

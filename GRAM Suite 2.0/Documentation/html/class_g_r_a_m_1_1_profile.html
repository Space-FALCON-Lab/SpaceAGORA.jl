Detailed Description

An abstract base class for collecting GRAM inputs and outputs.

This defines an interface class for collections of GRAM inputs and outputs. A Profile subclass is used to generate and store a one-dimensional vector of GRAM data. Subclasses must implement a generate() function which will generate inputs, call the atmosphere, and store the results.

Usage
A typical subclass of Profile will be used by first creating and initializing an atmosphere for the desired planet. Next, provide that atmosphere to the Profile subclass with setAtmosphere(). Then call the generate() function which will generate inputs, call the atmosphere model, and store the results. Finally, access the results with the getProfile() function. Results can be provide to a ProfilePrinter for output.

◆ generate()

void GRAM::Profile::generate ( )
pure virtual

Generates the profile data.

This pure virtual method should control the generation of the profile data. Typically, the override will loop over a number of steps, provide a position to the atmosphere, and collect the atmospheric data.

Implemented in GRAM::BallisticTrajectory, GRAM::EphemerisProfile, GRAM::TestingProfile, GRAM::Trajectory, and GRAM::VerticalProfile.

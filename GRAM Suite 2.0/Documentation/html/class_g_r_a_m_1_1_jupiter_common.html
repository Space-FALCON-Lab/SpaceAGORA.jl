Detailed Description

Common values for the Jupiter atmosphere models.

Common values for the Jupiter atmosphere models. All Jupiter atmosphere models should inherit this class.

(1) Data from NSSDCA Planetary Fact Sheet for Jupiter (https://nssdc.gsfc.nasa.gov/planetary/factsheet/jupiterfact.html). Page last updated on July 18, 2018.

(2) Data from NAIF Spice files (jup310.cmt).

# simulation/engine/setup.jl · _nbody*

## Purpose
Configuration, sizing, keying and serialisation of the N-body ephemeris table that lets third-body effectors interpolate positions instead of querying SPICE per RHS call.

## Design & Implementation
`_nbody_ephemeris_cache_enabled`, `_nbody_ephemeris_cache_dt_s` and `_nbody_ephemeris_cache_max_samples` read the environment knobs; `_nbody_ephemeris_cache_sample_count` sizes the table from mission length and step; `_nbody_ephemeris_reuse_key` keys it by primary, bodies, epoch, span and step; `_nbody_ephemeris_body_index_by_name` and `_nbody_ephemeris_cache_from_samples` construct the cache; `_nbody_ephemeris_cache_payload` packages it for `Serialization`.

## Limitations
The payload carries a wall-clock `created_utc` stamp, so two identical tables written at different times differ byte-for-byte and cannot be compared by digest.

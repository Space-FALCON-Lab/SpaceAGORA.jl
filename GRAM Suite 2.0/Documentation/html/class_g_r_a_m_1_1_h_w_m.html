Detailed Description

The HWM93 Horizontal Wind Model.

The HWM93 horizontal wind model extends the HWM90 wind model from 100 km to the ground and is thus a companion in a sense for MSISE90. The thermosphere portion is unchanged from HWM90. The extension is primarily based on MF / Meteor radar, rocket data, and gradient winds from CIRA86.

Horizontal wind model HWM93.

Horizontal wind model HWM93 covering all altitude regions, A.E. Hedin (1/25/93) (4/9/93) Calling argument list made similar to GTs5 subroutine for MSIS-86 density model and GWs4 for thermospheric winds.

## Findings

No P1 or P2 findings.

Points a reviewer should check:

- **The example.** With guidance A producing X and Y, B producing Y and C producing X, a controller consuming X and Y is prepared by A, C, B. This was run against the unchanged `gnc_link_groups` and `_linked_producers`.
- **The pending tick.** The run does not tick at its own end. The checkpoint written there lists the clocks whose tick was due, and a resumed run takes those ticks once when its callbacks initialize (`periodic_tick_callbacks.jl`, `_periodic_tick_checkpoint_state`). The text says "a longer run resumed from that checkpoint". A run resumed to the same end time has no solve, so it takes nothing.
- **Left for later.** The `before_reference_control!` docstring in `simulation_lifecycle.jl` still says "in configuration order". It is public API documentation, and the review asked for it to be tracked separately.

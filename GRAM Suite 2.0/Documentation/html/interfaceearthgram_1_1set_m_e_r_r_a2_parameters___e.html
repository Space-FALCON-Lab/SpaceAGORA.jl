Detailed Description

Identify the desired MERRA-2 data.

The MERRA-2 data is identified by specifying an hour code. MERRA-2 monthly climatology is determined by the value of month in the initial time input. One can also reduce the amount of data read from the MERRA-2 data file by specifying bounds on latitude and longitude. Data analysis must, of course, fall in this range.

Parameters
M2HourThe M2Hour code specifies the UT hour of day for MERRA-2 climatology: 1 = 00 UT, 2 = 03 UT, 3 = 06 UT, 4 = 09 UT, 5 = 12 UT, 6 = 15 UT, 7 = 18 UT, 8 = 21 UT, 9 = all times of day combined, or 0 to use time-of-day code based on input UTC hour.
latMinThe lower latitude boundary for reading MERRA-2 data.
latMaxThe upper latitude boundary for reading MERRA-2 data.
lonMinThe lower longitude boundary for reading MERRA-2 data.
lonMaxThe upper longitude boundary for reading MERRA-2 data.
atmosAn Earth atmosphere handle.

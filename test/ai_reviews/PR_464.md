# Review record: PR 464: the order in which linked producers prepare their consumer

## Scope

Review of the SpaceAGORA `linked-producer-docstring` branch against main (c22d7c5ee). The public docstring of `before_reference_control!` said a consumer's linked producers are called "in configuration order", but `_linked_producers` traverses links in first-declared order and does not repeat a producer. The post-release review of #449 (2026-10-20) found this and asked for it to be tracked separately from the maintainer-documentation fix in #463.

Documentation only: the docstring describes the actual order, with an example, and says a producer must not rely on another having been called first. The contract and the runtime behavior do not change.

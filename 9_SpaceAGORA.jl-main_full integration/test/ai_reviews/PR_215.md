## Findings
- P3: the `@kwdef` keyword constructor still calls each struct's validating inner constructor, so the rate-count and positive-rate checks apply to defaulted and explicit calls alike (the test checks `guidance_rates=[1.0]` with no effectors still throws).

- `initial_time` deliberately stays required: `InitialTime()` is J2000, and a silent 2000 epoch would be wrong for nearly every scenario (atmosphere and ephemeris models sample by date).

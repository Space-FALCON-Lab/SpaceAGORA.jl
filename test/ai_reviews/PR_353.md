## Findings

Author's notes for the reviewer (no P1 or P2 known to the author):

- **Design deviation, low: no shared helper.** Design section 6.1 planned to route
  this warning through the hook study's `_hook_deprecation` (#349, open). That
  helper throws under `--depwarn=error`, and the required `example-suite-smoke`
  check runs every example that way, including the two RPOGuidanceModel examples
  (`examples/Earth_RPO_CubeSat_MPC.jl`,
  `examples/Earth_RPO_HyPR_FinalISpaRo_Replanning.jl`), until PR 19c migrates them.
  The warning therefore follows the Apollo pairing warning (#337): a plain `@warn`
  with `maxlog=1` in the model's pre-run check. The PR does not depend on #349.
- **Low, semantics: once per session.** `maxlog=1` limits the warning to once per
  Julia session (per logger): once for a run with several models, and not again
  for later runs. The Apollo warning behaves the same way.
- **Low, location.** The warning sits in the HYPR adapter module because that
  method is the model's only `preflight_guidance` method, and one signature allows
  only one method. The warning fires before `require_hypr`, so a user without the
  companion sees the deprecation first.
- **Note: three docs files are unchanged on purpose.** They still call the model
  "the existing" one: `docs/contributing/architecture.md`,
  `docs/contributing/gnc_ownership.md` and `src/models/gnc/README.md`. The local
  G-10 branch edits all three.

Reviewer to verify:

- **The warning fires only from the pre-run check:** only
  `src/orchestration/simulation/engine/execution.jl` calls `preflight_guidance`,
  once per guidance model before integration. No callback or right-hand-side path
  reaches it.
- **It never throws:** a plain `@warn`, with no `Base.depwarn` and no
  `JLOptions().depwarn` check.
- **The method reads no `args` field before the warning,** so
  `test/optional/hypr/core.jl` (which passes `args=nothing`) still sees
  `HYPRUnavailableError`.
- **Every RPOGuidanceModel run is otherwise unchanged:** the HYPR condition and
  the return value are as before.
- **No test that builds the model checks a run's logs.** The strict `@test_logs`
  in `rpo_final_isparo_reconstruction_tests.jl` call
  `_rpo_advance_replanning_hold!` directly, not `run_simulation`.

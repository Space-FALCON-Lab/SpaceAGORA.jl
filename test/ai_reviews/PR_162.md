# PR 162: mesh aerodynamic threaded execution

## Scope

Enable the existing pure mesh wrench in automatic and forced threaded routes. Preserve serial fallback for multiple aerodynamic diagnostic writers. No force, torque, atmosphere, solver formula or scheduler threshold changes.

## Changed Files

- `src/simulation/engine/setup.jl`: declare mesh effectors thread-safe and count both mesh and box effectors when excluding multiple drag/lift/cross cache writers.
- `test/unit/dynamics/mesh_aero_threading_tests.jl`: shared coefficients, eligibility guards and actual multithreaded propagation checks.
- `test/unit/runtests.jl`: register the regression.
- `docs/src/user/mesh_aerodynamics.md`: route eligibility, read-only input requirements and serial fallback.

## Findings

The coefficient evaluator uses per-call scratch. Wrench evaluation reads shared coefficients and geometry. The caching hook writes per-spacecraft diagnostic slots, so a single aerodynamic effector can run across spacecraft, but multiple box/mesh effectors cannot share an effector queue. The previous box-only guard is broadened before enabling the mesh trait. Original input coefficients remain unchanged after the tested runs.

No blocking finding in the implementation review. Independent review remains pending; this artifact does not claim Claude has reviewed this change.

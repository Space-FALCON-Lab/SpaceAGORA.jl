# environment/ephemerides/ephemerides_models.jl

## Purpose
The `EphemeridesModels` module file that includes the SPICE and simple ephemerides implementations and defines the shared time and frame interface.

## Design & Implementation
Declares the module, includes the concrete models, and defines `ephemerides_time_seconds`, `planet_frame_lpi`, `ephemerides_requires_spice` and `ephemerides_cache_key` as the generic functions each model implements.

# gnc/guidance/rpo/hypr/pso_helpers.jl

## Purpose
Conversions between the swarm's flat position vector and a control-point path, and the search bounds the swarm is confined to.

## Design & Implementation
`rpo_position_to_path` unpacks a flat vector into a three-by-N polygon with fixed endpoints, `rpo_pso_bounds` builds the box around the chord with the search margin, and `rpo_pso_warmstart_bounds` builds it around an RRT seed instead.

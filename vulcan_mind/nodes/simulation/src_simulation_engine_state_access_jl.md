# simulation/engine/state_access.jl

## Purpose
Uniform accessors for the satellite state under every layout the engine uses: component tree, gravity-backbone arrays, and optional mass, quaternion and heat-load slots.

## Design & Implementation
`_state_position_ii`, `_state_velocity_ii`, `_state_mass_kg`, `_state_quaternion` and `_state_heat_loads` with their `_state_has_*` predicates; `_gravity_backbone_*_state` split the second-order layout; `_is_gravity_backbone_state` detects it; `_gravity_backbone_initial_states` builds the split initial condition.

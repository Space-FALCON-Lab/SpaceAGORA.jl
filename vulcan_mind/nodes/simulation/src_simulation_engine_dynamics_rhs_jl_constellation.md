# simulation/engine/dynamics_rhs.jl · _constellation*

## Purpose
The satellite-major encoding of flat-queue work items as plain integers, so the constellation effector queue can carry its work list as a `Vector{Int}` and hand contiguous ranges to workers.

## Design & Implementation
`_constellation_node_work_item` packs a `(satellite, effector)` pair as `(sat - 1) * n_effectors + effector`; `_constellation_node_sat_idx` and `_constellation_node_eff_idx` unpack with `fld` and `mod`. Satellite-major order keeps one satellite's effectors adjacent, which the packet grouper exploits so a packet touches few satellites' state. All three are one-line `@inline` arithmetic.

# analysis/verification/telemetry_verification/manifest_parsing.jl · _parse*

## Purpose
Parsers that convert manifest strings and sub-tables into the enums, tuples and configuration structs the verification scenarios are built from.

## Design & Implementation
Vocabulary parsers map spelling variants onto symbols — altitude mode, element frame, comparison mode, reference frame, truth mask, gravity model. Table parsers build `InitialTime`, `SpacecraftConfig`, `AtmosphereTruthConfig`, `CalibrationConfig`, the manoeuvre tuple, units and tolerances. Two environment parsers read positive ints and floats for solver overrides.

# simulation/callbacks/density_callbacks/model_selection.jl

## Purpose
Chooses the density model instance for each satellite and provides the isolated GRAM pool that lets several satellites sample concurrently.

## Design & Implementation
`_density_model_for_sat` returns the per-satellite copy or the shared model; `_gram_density_cache_for_sat!` allocates track caches; `_ensure_gram_isolated_pool!` builds a pool of native GRAM instances with their own locks; `_gram_isolated_pool_batch_eval!` and `_gram_isolated_pool_density_state` evaluate through the pool; batch model selectors decide when a whole-constellation call is possible.

# analysis/verification/telemetry_verification/manifest_parsing.jl · _optional*

## Purpose
Accessors for manifest fields that may be absent, returning a caller-supplied default when the key is missing.

## Design & Implementation
One accessor per value shape — int, float, bool, string, and vectors of strings, `Int64`, `Float64` and symbols, plus a fixed-length float tuple — each testing `haskey` and converting the TOML value. They are the building blocks of every table parser in this file.

## Findings

- **Sign and frame of the facet force:** ŝ points from the spacecraft to the Sun, so F = −P·A·cos θ·[(1 − δ)ŝ + 2(ρ/3 + δ cos θ)n̂] pushes away from the Sun. δ is specular and ρ diffuse, matching the `Facet` field comments and Montenbruck and Gill, Sec. 3.4.
- **Torque convention:** the force is in J2000 and the torque in the root body frame. Facets are rotated facet → link → root → J2000 with the same conventions as `_aero_pure_wrench`: `rot(q)` maps parent to child, and link offsets `link.r` are root-frame. The tests check the attitude path and the r × F torque.
- **Without a propagated attitude** (`q_ib === nothing`): the body axes are taken as J2000 and no torque is returned. This is documented in the docstring.
- **`TabularHeat` interpolation:** bilinear in velocity and log density. Holding the edge value below the grid would put a vacuum flux on every coast arc, so below the lowest density the flux scales in proportion to density instead, going to zero. The CSV loader rejects missing columns, repeated points and incomplete grids.
- **Units:** `SuttonGravesHeat` returns W/cm², like `MaxwellianHeat`, from `planet.k` in kg^0.5/m (SI).

## P1 Assessment

No P1 found. The changes add new types and methods; no existing dispatch target changes, and the support check `_validate_thermal_model_support!` accepts both new thermal models.

## Tests Added/Updated

test/unit/dynamics/facet_srp_and_thermal_models_tests.jl (36 assertions, no SPICE or native GRAM) checks each model against its closed form. An end-to-end 3000 s `run_simulation` (outside the suite, needing SPICE kernels) used each thermal model with the facet model as an effector. All runs finished with retcode Success and non-zero heat loads, and the facet model changed the trajectory.

## Residual Risk

- No flight or cross-tool validation of the facet force or of either thermal model is included.
- `TabularHeat` applies one vehicle-level flux to every link, by design.
- The facet model is not on the `gravity_backbone_split` kick path and has no parallel-cost entry, so the cost model treats it as an unknown effector.

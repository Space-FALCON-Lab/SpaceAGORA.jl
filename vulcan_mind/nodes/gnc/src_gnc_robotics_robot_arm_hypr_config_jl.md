# gnc/robotics/robot_arm_hypr/config.jl

## Purpose
The configuration, obstacle and result types of the robot-arm HYPR planner, validated at construction so a bad setting fails before any swarm runs.

## Design & Implementation
`RobotArmHYPRConfig` groups swarm size and iterations, sampling density, refinement passes, clearance margin and the base-reaction weighting; `_validate_robot_arm_hypr_config` checks positivity and ordering of every field; `RobotArmSphereObstacle` is a centre and radius in the base frame; `RobotArmHYPRResult` bundles the plan with cost components and warm-start diagnostics.

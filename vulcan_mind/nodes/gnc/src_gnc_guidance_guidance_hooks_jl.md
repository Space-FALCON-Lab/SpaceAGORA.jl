# gnc/guidance/guidance_hooks.jl

## Purpose
Bridges the newer guidance models to the legacy aerobraking control functions so both can drive the same panel effectors.

## Design & Implementation
`GuidanceHooks` resolves the control module lazily and exposes `_control_asim_ctrl`, `_control_asim_ctrl_rf` and `_control_solarpanels_heatrate` as thin forwards to the legacy implementations.

# simulation/engine/dynamics_rhs.jl · _robot*

## Purpose
Locating the robot-arm coupling for a satellite: whether any arm exists, which effector holds its plan, and the stiffness parameters to couple with.

## Design & Implementation
`_robot_arm_present` caches the run-wide presence flag; `_robot_arm_effector_matches` tests an effector for a satellite's plan; `_robot_arm_coupling` scans the effector tuples; `_robot_arm_coupling_from_effector` extracts plan, elapsed time, stiffness and actuators with defaults.

## Findings

Resolved: property names and vector lengths alone did not establish field offsets. Custom ComponentArray axes could exchange position and velocity slots while passing the old probe, causing wrong derivative writes. Checking only the first and last child also missed incompatible intermediate layouts. The probe now verifies every child, exact offsets and contiguous Float64 storage.

Resolved: a cached stride could be reused after changing state or derivative layout. The cache now includes both complete ComponentArray types (which encode axes) and both lengths. Canonical layouts with fresh backing buffers remain eligible; unsupported storage is rejected.

Force evaluation and accumulation order are unchanged. The direct path retains the existing finite/near-zero mass handling and zeros inactive derivatives. It is off by default and declines atmosphere, orientation, controls, robot arms and unsupported RHS kinds. The new flag does not itself select the flat execution route.

## Findings

The default grid interface called the new helper through a lightweight shared-buffer context without gram_density_perturbation. An unconditional field access raised FieldError before any perturbation was enabled. The helper now returns the original density, temperature and wind when that optional field is absent, as it already does for an explicitly empty state. The existing grid tests are preserved, not weakened.

Source inspection confirms that step/pass modes use separate walk instances and the sampler reads stored factors; the callback initializes per-spacecraft state and applies the entry-interface cutoff. The native extension holds query and density-state read under the same lock. The naive_rhs mode remains a negative control whose evaluations advance the mean instance's walk; it is not scientifically accepted.

The PR's long native campaign records are referenced in an external paper repository and were not available in this local review. Scientific acceptance remains open, including solver-step sensitivity, lifecycle/reuse/checkpoint behavior and deployment scope of the new modes.

## P1 Assessment

The default grid regression is fixed. No additional P1 is demonstrated by the bounded checks, but the numerical-policy review is not closed. This artifact records work performed and must not be read as merge acceptance of the complete feature.

# parallel/routing/env_mapping.jl

## Purpose
Translates a parallel profile into the concrete environment variables the inner policy and engine read, and applies them for the duration of a call.

## Design & Implementation
`profile_env_pairs` lists the variable/value pairs for a `ParallelProfileConfig`, folding in machine class and inner-hint defaults; `with_parallel_profile` sets them, runs a function and restores the previous values.

## Limitations

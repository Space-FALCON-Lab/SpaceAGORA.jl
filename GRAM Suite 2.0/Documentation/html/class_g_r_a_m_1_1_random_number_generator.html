Detailed Description

This class generates random numbers.

A portable pseudorandom number generator with period of about (1/48)*(2^24)^24 = 2^570 = 10^171. Author F James, CERN, 1989. Algorithm due to: G. Marsgalia and A. Zaman. Code as in James, Comp. Phys. Comm., 60, 329-344 (1990).

void GRAM::RandomNumberGenerator::rcarin ( int  seed)
private

Initializes the random number generator.

Initializing routine for RCARRY. Must be called before generating any pseudorandom numbers with RCARRY. The input parameter should be in the range: 0 <= seed <= 2^24 = 16,777,216. Adapted from RMARIN subroutine of James, Comp. Phys. Comm. 60, 329-344 (1990).

Parameters
seedThis value determines the random number sequence.

# PR312 review: group the calibration, cross-validation and diagnostic scripts

## Scope

Review of the SpaceAGORA `scripts-layout` branch against `main`. The PR moves 16
files inside `scripts/` into three new homes, `calibration/`, `xval/` and
`dev/diagnostics/`, and leaves the public setup commands at the root. The review
covers the complete diff: the moves, the repository-root constants inside the
moved files, and every reference that follows them in source comments, docs,
benchmark drivers and tests.

Authorship disclosure: this record was drafted by the author of the PR and
committed by the principal investigator, because the independent reviewer was
unavailable. Readers should weigh the record accordingly.

## Findings

No defects. The moved Julia files resolve the repository root from `@__DIR__`;
each constant goes one level deeper (`calibration/`, `xval/`) or one further
level (`dev/diagnostics/`), and the full-arc entrypoint's usage string names its
new path. `calibrate_machine.jl`, `xval_provenance.jl` and the two Python tools
resolve nothing from their own location and need no internal change. The
probe test's script directory and its usage-string assertion follow, as does
the export test's script path. The paper figure and targeted-points drivers
invoke the calibration command from its new path; the parallel execution,
scenario-matrix debug, user architecture and predictive routing pages name the
new paths. A sweep for every old path finds no remaining reference outside the
historical review records. `generate_gmat_comparison_data.jl` has no references
anywhere and moves with the cross-validation tools; keeping it is a separate
decision.

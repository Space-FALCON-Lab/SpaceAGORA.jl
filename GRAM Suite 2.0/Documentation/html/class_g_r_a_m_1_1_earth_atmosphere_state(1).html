#include <EarthAtmosphereState.h>

Detailed Description

The augmented output state of an Earth Atmosphere model.

The EarthAtmosphereState provides Earth model specific metrics as an extension to the AtmosphereState class using AtmosphereState::planetSpecificMetrics.

Examples
Earth/examples/Earth.cpp, and Earth/examples/EarthCorrMulti.cpp.

## Changed Files

- `src/core/simulation_model.jl`: include the new configuration owner.
- `src/core/state/simulation_configuration.jl`: retire the old combined source file.
- `src/simulation/config/configuration.jl`: keep the existing SimConfig module, exports and imports and include its separated definitions.
- `src/simulation/config/run_settings.jl`: existing mission compatibility, epoch, duration, sampling and output/checkpoint settings.
- `src/simulation/config/solver_settings.jl`: existing SolverConfig and IntegrationTolerances, including the parallel flag from PR171.
- `src/simulation/config/environment_settings.jl`: existing EnvironmentModel and validation.
- `src/simulation/config/constellation_configuration.jl`: existing DynamicsModel, included from SpacecraftModels to preserve type identity and collection aliasing.
- `src/simulation/config/simulation_configuration.jl`: final container and shallow copy helper.
- `src/vehicle/spacecraft/model.jl`: include the moved DynamicsModel without changing its module or constructor.

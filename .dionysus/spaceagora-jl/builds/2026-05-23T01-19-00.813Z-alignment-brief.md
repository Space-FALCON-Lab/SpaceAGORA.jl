## Model JSON Schema
### DiagramSheet
  id             — stable identifier; referenced by other sheets' parentId and by node.ownerNodeId
  parentId       — parent sheet ID (null = top-level)
  ownerNodeId    — if set, this sheet is the drill-down detail for that node in the parent sheet
  title          — human display name
  layer          — physical | logical | operational | requirements | software-data
  abstractionLevel — 0 = system-level; higher integers = more detailed
  summary        — what this sheet captures
  verificationIntent — what must stay true for this sheet to be considered correct
  nodes[]        — array of DiagramNode
  edges[]        — array of DiagramEdge

### DiagramNode
  id             — referenced by edges (sourceNodeId / targetNodeId) and by sheet.ownerNodeId
  title          — display name of the block
  role           — system | subsystem | component | function | interface | register-block | rail | requirement
  description    — what this block is responsible for (human-authored or auto-generated)
  parentNodeId   — if set, this node is visually and semantically contained inside the named parent node
  tags[]         — categorisation labels (e.g. ["repository", "aligned"])
  ports[]        — named I/O connection points (see DiagramPort)
  aiModificationPolicy — "protected" = do not change without explicit user instruction; "default" = normal
  workspaceDirectory   — if set, binds this node to a subdirectory in the code workspace
  packageId      — if set, this node is linked to an installed component package
  x, y, width, height  — LAYOUT ONLY — canvas rendering positions; irrelevant for semantic analysis

### DiagramPort
  id        — referenced by edge.sourcePortId / edge.targetPortId
  name      — human-readable label (e.g. "Outputs", "Commands In")
  kind      — pin | bus | signal | power | data
  direction — in | out | bidirectional

### DiagramEdge
  id           — stable identifier
  sourceNodeId — references a node.id in the same sheet
  targetNodeId — references a node.id in the same sheet
  sourcePortId — references a port.id on the source node (optional)
  targetPortId — references a port.id on the target node (optional)
  kind         — physical | logical | data | control | requirement
  label        — human-readable description of the relationship (e.g. "imports", "commands", "telemetry")

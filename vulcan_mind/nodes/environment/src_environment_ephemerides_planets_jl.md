# environment/ephemerides/planets.jl

## Purpose
The planet definitions: radii, gravitational parameters, rotation, atmosphere constants, gravity-field coefficients and SPICE kernel furnishing for Earth, Mars, Venus and the Moon.

## Design & Implementation
One struct per body subtyping `AbstractPlanet`, with constructors that load the kernel set from a path and compute derived constants; helper functions read polyfit coefficients and validity bounds.

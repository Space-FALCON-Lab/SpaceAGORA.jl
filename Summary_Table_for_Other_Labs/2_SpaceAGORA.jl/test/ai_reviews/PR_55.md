# AI Review — PR 55: Distribute the GMAT-matrix Mars/Moon gravity assets (closes #54)

## Scope
`test/gmat_scenario_matrix.jl` asserted the presence of two gravity-coefficient CSVs that were never committed (`GGM2B.csv`, `LP165P.csv`), so the file aborted partway on any fresh clone (issue #54). This PR adds the converted files and corrects a filename typo in the Mars constant.

## Changed Files
- `data/Gravity_harmonics_data/GMM2B.csv` (new, 80×80 Goddard Mars Model 2B)
- `data/Gravity_harmonics_data/LP165P.csv` (new, 165×165 Lunar Prospector model)
- `test/gmat_scenario_matrix.jl` (one constant: `GGM2B.csv` → `GMM2B.csv`)

## Findings
- P2 (fixed): the Mars constant referenced `GGM2B.csv` — a transposition of GMAT's `GMM2B.cof` (Goddard **Mars** Model 2B). GGM02B is a GRACE *Earth* model, so the stale name was actively misleading. The constant now names the model correctly.
- P3 (provenance): both CSVs are converted from the GMAT distribution's `.cof` files (`data/gravity/mars/GMM2B.cof`, `data/gravity/luna/LP165P.cof`) with the same conversion the existing assets used. The converter was validated by round-tripping GMAT's `Mars-50c.cof` against the repo's existing `Mars50c.csv`: 1326/1326 coefficients, zero difference — establishing that the in-repo assets share this exact provenance.
- No P1 findings.

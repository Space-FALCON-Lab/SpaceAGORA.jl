# core/types/

## Purpose
The type layer under the whole engine: abstract effector and model supertypes, the effector sampling contract, runtime buffers and caches, and legacy model-code compatibility.

## Design & Implementation
Four files. `abstract_types.jl` declares the supertypes every model subclasses; `effector_sampling.jl` defines the `StateSample`/`EnvironmentSample` wrench contract; `runtime_types.jl` holds `SharedBuffers`, `ODEParams`, the caches and the run-scoped environment snapshots; `compat_model_codes.jl` maps old integer model codes.

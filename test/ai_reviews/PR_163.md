# PR 163: automatic fixed-grid atmosphere display

## Scope

Automatically sample verified pure analytic atmosphere models and native-free fixed GRAM grid snapshots during scene export. Keep native, hybrid, empirical and arbitrary custom models behind explicit standalone sampling. Respect fixed-grid spatial coverage in exported profiles, maps and viewer density shells.

## Changed Files

- `src/analysis/visualization/scene/atmosphere_spec.jl`: narrow fixed-grid bounds hook, bounded equatorial profile, globally covered latitude map, explicit map-height validation and bounded default height.
- `src/analysis/visualization/scene/scene_export.jl`: describe the new automatic-sampling boundary in the engine export docstring.
- `ext/gram_grid_atmosphere.jl`: opt in only the exact validated native-free GRAMSuite grid core; keep older optional wrappers loadable.
- `viewer/src/atmosphere.js`: no density extrapolation or shells beyond the sampled profile, and finite opacity scaling within available coverage.
- Dedicated grid-adapter tests, JavaScript viewer regression, user guide and viewer README accompany these changes.

## Findings

The optional extension supplies altitude/latitude bounds only for its fixed snapshot type. Unknown grid cores do not gain automatic sampling. Native/custom models are rejected by the default guard before density evaluation, including when engine parameters are supplied. Fixed-grid profiles intersect display and stored altitude ranges; an absent equator produces no profile. Regional grids are never stretched into global maps. Explicit out-of-range map heights throw; only the default display height is bounded and recorded.

The viewer previously extended profile endpoints outside the sampled interval. It now omits unsupported shells and returns an unavailable density there. The existing full analytic profile still generates six shells. Grid profiles/maps describe their stored snapshot and do not regenerate it for the mission epoch.

No blocking finding in the implementation review. Independent review and browser visual acceptance remain pending.

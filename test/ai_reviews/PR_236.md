## Findings
- P2 (fixed during review): with the switch off, a gravity-gradient request on an articulated spacecraft was silently dropped. The `gravity_gradient` flag was filtered with the gravity effector, and `GravityGradientTorqueModel` double counted through `inertia_tensor`. It is now refused at setup, naming the effector and the switch; with the switch on the request becomes a per-body torque from the link inertias.
- P3: the per-link aero kernel duplicates `_aero_pure_wrench`'s orientation-sim branch on purpose, because refactoring the shared kernel would change rigid rounding. It is a candidate for consolidation once rigid bit-identity can be relaxed.
- P3: a symmetric-panel hinge without gravity gradient drifts 7e-4 in attitude against the rigid run. That is the real inter-body gravity-gradient torque, so the stiff-joint equivalence test runs with gravity gradient on in both runs.

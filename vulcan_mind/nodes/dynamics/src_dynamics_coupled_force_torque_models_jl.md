# dynamics/coupled/force_torque_models.jl

## Purpose
The module file for `DynamicEffectors`, which includes each effector family and re-exports the shared `calcForceTorque` generic.

## Design & Implementation
Declares the module, includes gravity, perturbation, aerodynamic, thruster and robot-arm effector files from the `force_torque_models/` directory, and defines the fallback `calcForceTorque` method that names an unsupported effector type.

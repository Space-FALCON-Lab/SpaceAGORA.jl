# AI Review Artifact — PR #113

## Scope
Follow-up to #105: the single-satellite serial gate for effector-level threading reads the active satellite count instead of the configured one.

## Changed Files
- src/simulation/engine/setup.jl — `_dynamic_effector_thread_decision` (core overload and the four-argument overload) takes `active_sats::Int=num_sats`; the serial gate tests `active_sats <= 1` while the satellite share budget keeps `num_sats`; `_rhs_execution_plan_uncached` passes the `active_sats` it already computes from `p.is_active`.

## Findings
- P2 (Codex on #105): with the configured count, a constellation reduced to one active spacecraft by the impact callback kept threading that spacecraft's effectors. Resolved by gating on the active count; the plan cache keys on the active count already, so the decision is recomputed when a satellite deactivates.
- P3: callers that do not know the active count get the previous behaviour through the keyword default.

# PR 159: public named-surrogate workflow

## Scope

Deliver a named, versioned bounded Odyssey P20 atmosphere for ordinary guidance/control work without native GRAM. Runtime interpolation stays with the existing accepted adapter. Public Julia artifacts carry the unchanged accepted grid and the independently hash-verified public scenario assets.

## Changed Files

- `src/environment/atmosphere/surrogate_presets.jl`: exact catalog/version selection, lazy artifact resolution, checksums, metadata/domain validation and provenance.
- `src/assets/odyssey_surrogate_assets.jl`: public kernel/gravity retrieval and per-file checksums.
- `src/SpaceAGORA.jl` and `src/environment/physical_models.jl`: package include/export/documentation wiring.
- `src/cli/assets.jl`, `src/cli/spaceagora_cli.jl` and `src/cli/main.jl`: list/fetch/check commands and real package extension loading.
- `src/io/outputs/io_outputs.jl`: atmosphere provenance in the ordinary bundle manifest.

Catalogs, dedicated environment, active panel-cap example, synthetic-data tests, fresh-process CLI test, public-only CI and documentation complete the workflow.

## Findings

The independent workflow source review found one P1: the old CLI raw-included SpaceAGORA and did not activate the optional wrapper extension. The entrypoint now imports the package and conditionally imports GRAMSuite for preset validation; the new regression invokes this actual entrypoint in a child process. Scenario downloads preserve user interrupts. No unresolved source blocker remains in that review.

Public delivery was independently checked by anonymous download: both archive SHA256 values, both unpacked Julia artifact trees, the unchanged raw grid, all 14 manifest entries, catalog and source asset bindings agree. The versioned release is explicitly a bounded initial data snapshot; it adds no numerical release requirement.

## Residual Risk

The snapshot is frozen at the documented epoch and bounded in height/latitude. Exact-pole winds retain native longitude-label semantics. Pressure is absent and the existing wind Boolean does not suppress grid winds. The active panel-cap example does not validate closed-loop thermal feedback or mission accuracy. Arbitrary planets/epochs and the separately reviewed global Mars grid remain outside this change. New public workflow CI runs without native setup, private credentials or submodule materialization; existing full CI retains its separately provisioned native coverage.

# simulation/engine/reporting.jl

## Purpose
Diagnostics and policy enforcement around results normalisation and NaN parameters.

## Design & Implementation
`_enforce_typed_normalize_policy!` and `_warn_typed_normalize_transition_flag!` apply the transition rules for the typed normalisation flag; `_debug_print_nan_parameter_paths!` walks a parameter tree and prints the path of any NaN.

# simulation/callbacks/save_fields.jl

## Purpose
Declares the columns a run can save — positions, velocities, mass, altitude, latitude, longitude, quaternion, forces, heat rates and loads, density and wind — as `SaveField` getters.

## Design & Implementation
`SaveField` pairs a name with a getter closure and per-satellite column naming; one `_save_*` getter per quantity reads state or the save cache; `default_save_fields` lists the standard set and `_resolve_save_fields` merges user additions.

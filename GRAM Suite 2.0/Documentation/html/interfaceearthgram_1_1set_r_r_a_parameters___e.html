Detailed Description

Set the RRA parameters.

This method selects the year of the RRA data set and defines a region in which RRA data is used. There is a smooth transition between the outerRadius (no RRA) and the innerRadius (all RRA) of the region.

Parameters
yearYear code: 1 for 1983 RRAs, 2 for 2006 RRAs, 3 for 2013 RRAs, 4 for 2019 RRAs.
innerRadiusLat-lon radius from RRA site, inside which RRA data is used with full weight of 1 \([degrees]\).
outerRadiusLat-lon radius from RRA site, outside which RRA data are NOT used \([degrees]\).
atmosAn Earth atmosphere handle.

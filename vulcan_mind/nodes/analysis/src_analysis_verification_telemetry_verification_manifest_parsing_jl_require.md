# analysis/verification/telemetry_verification/manifest_parsing.jl · _require*

## Purpose
Accessors for manifest fields that must be present, producing an error that names both the key and its table.

## Design & Implementation
`_require_key` is the base; `_require_table`, `_require_str`, `_require_float`, `_require_int` and `_require_str_vector` wrap it with a type conversion. Every mandatory field in the scenario parsers goes through one of these.

# gnc/control/control_hooks.jl

## Purpose
The generic functions every control effector implements, so the engine can call any effector without knowing its type.

## Design & Implementation
`ControlHooks` declares `calcControlEffect!`, `calcControlForceTorque`, `calcControlMassFlowRate` and `calcReactionWheelTorque` with fallback methods returning no effect, zero wrench, zero mass rate and `nothing`. Concrete controllers add methods on their own types.

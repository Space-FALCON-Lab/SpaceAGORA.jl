# simulation/callbacks/density_callbacks/config.jl

## Purpose
The run-scoped snapshot of every callback-side environment knob and the thread decisions derived from it for the density, control and thermal callbacks.

## Design & Implementation
`_callback_env_config` returns the snapshot or parses live; readers for parallel mode, thresholds, batch mode, isolated-pool settings, GRAM cache flags and the freeze-per-step switch; `_density_callback_thread_decision`, `_control_callback_thread_decision` and their `_use_threads` wrappers consult the policy.

# UranusGRAM

Targets:
* all: builds all of the following
* gram: builds the UranusGRAM namelist program
* examples: builds the C++ UranusGRAM examples
* cexamples: builds the C UranusGRAM example
* fexamples: builds the FORTRAN UranusGRAM example
* clean: deletes libraries, object files, and executables.

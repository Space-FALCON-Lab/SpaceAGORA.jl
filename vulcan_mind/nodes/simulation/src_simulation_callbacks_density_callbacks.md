# simulation/callbacks/density_callbacks/

## Purpose
Atmosphere staging for the right-hand side: once per accepted step, evaluate density, temperature and wind for every satellite as cheaply as the configured caches allow.

## Design & Implementation
`assembly.jl` decides which callbacks a configuration needs and builds them; `config.jl` snapshots the environment knobs; `model_selection.jl` picks per-satellite models and the isolated GRAM pool; `planet_frame.jl` shares the planet rotation per step; `runtime.jl` is the callback body; `vacuum_predicted_gram.jl` is the spline cache along a drag-free prediction.

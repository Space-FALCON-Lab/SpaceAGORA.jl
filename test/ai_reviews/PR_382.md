# Review record: PR 382: guidance, navigation and control model checks (contributor kit K3)

## Scope

Review of the SpaceAGORA `conformance-gnc-models` branch (head `afb45efa1`, one commit)
against `conformance-sensors` `476cf9b4a` (K2), which is on main `427d9bbea`. This is
K3 of the contributor kit approved on 2026-10-16.

The PR adds `check_guidance_model`, `check_navigation_model` and `check_control_model`,
with `test_guidance_model`, `test_navigation_model` and `test_control_model`, to
`SpaceAGORA.Conformance`. A model runs in the K1 fixture as one of the configuration's
GNC effectors. The checks reuse the engine: its pre-run hook check
(`_missing_model_hooks`), its list of deprecated hooks (`_deprecated_model_hooks`),
`run_simulation` with `return_results=true` (the model's own state at the end of a run
is read from the configuration the run returns), `build_state_sample` for the control
output hooks, and the engine's own `bind_spacecraft` binding of models declared on each
spacecraft. The check ids:

- guidance: `hooks_present`, `repeatable_run`, `deepcopy_equivalent`,
  `global_rng_independent`, `concurrent_equals_sequential`, `bind_fresh_state`;
- navigation: the same, with `initialize_resets` before `bind_fresh_state`;
- control: `hooks_present`, `no_deprecated_hooks`, `supported_sample_signature`, the
  four run-level checks, `output_hook_pure`, `positive_consumption`, `bind_fresh_state`.

`check_force_torque_model` gains `no_deprecated_hooks`. The built-in guidance and
control models run through the checks (or, where they cannot run in the fixture, the
checks that need no run), and the built-in loops of the preflight test move onto them.

replace an independent review. Giusy accepted this record as reviewer on 2026-10-17.

## Findings

No P1 findings.

Points a reviewer should check:

- Medium, design scope: the design lists `initialize_resets` for guidance, control,
  navigation and sensors, available "after PR 12; navigation PR 6". Here it is in the
  navigation report only. On main some built-in guidance and control models keep run
  state across runs (the momentum manager, for example), so a guidance or control
  version would fail built-ins until PR 12 states the reset guarantee.
- Medium, design scope: `no_deprecated_hooks` is listed for "all" targets. It is in the
  force/torque and control reports; the engine has no deprecated guidance, navigation
  or sensor hooks, so those reports would always pass it.
- Medium, the run-level comparison: guidance and navigation ticks need not change the
  saved states in a 60 s fixture run, so the run-level checks also compare the model's
  own state at the end of each run (`_same_state`, K1's structural comparison through
  every reachable field). Dictionary keys are looked up, not matched, so a model whose
  state holds a dictionary keyed by mutable objects (an `IdDict` keyed by its own
  arrays, say) would compare unequal between two runs and fail the run-level checks
  without a real defect. The built-in models that run here pass; the same limit
  applies to the K1 and K2 comparisons.
- Low, `bind_fresh_state` scope: it watches the mutable objects reachable from both of
  two copies bound by the model's own `bind_spacecraft`, in a run with
  `isolate_state=false`. A model whose copies share an object they only read passes; one
  whose copies share and change it fails. Sharing through a global is not reachable
  from the copies; `concurrent_equals_sequential` covers part of that.
- Low, the built-in instances: the energy-depletion and Apollo descent models (which
  need the optional SpaceAGORAEDG package, an atmosphere, a landing-site configuration
  or terrain) and the deprecated `RPOGuidanceModel` get only the checks that need no
  run. `PlannerGuidance` is exempt here and checked with the algorithm contract.
- Low, overlap with #373 (`gnc_period_s`): #373 warns before a run whose control model
  declares a period other than its callback rate. The robot arm instance declares the
  fixture's 1 s rate (its default is 0.1 s); the RPO MPC default is 1 s. `period_declared`
  itself waits for PR 8.

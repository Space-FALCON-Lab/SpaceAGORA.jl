Eight separate checks against the original PR121 source reproduce these input/helper/purity behaviors. The original module was renamed only to allow both implementations to load in one process. The malformed original arrays were inspected without invoking their unsafe evaluators. Actual-engine tests distinguish the selected craft from a wheel-free baseline and check inertial total angular momentum using saved attitude/rate and queried wheel momentum.

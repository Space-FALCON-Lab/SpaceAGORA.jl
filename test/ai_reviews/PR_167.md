# PR 167: manuscript-conforming HyPR mode and acceleration-limited retiming

## Scope

Add a `:manuscript` HyPR mode that follows the HyPR manuscript (Sec. III.A to III.E): RRT-Connect warm start first, exploration score η from its detour and iteration count, η-derived coefficients and counts, Eq. 5 objective with the Eq. 6 threshold d_safe + τ_tol, the HCW fuel proxy on each candidate's retimed reference, and retiming with d_avail = c − d_safe. Add acceleration-limited retiming (forward and backward passes, boundary speeds, positions on the curve). Fix the LQ-MPC reference-preview index on floating-point update times. Add an optional controller log. Move the ISS viewer demo to a flight-like attitude and a V-bar relocation planned in the new mode. Reviewed: the whole diff against `main`, the manuscript sections it implements, and the legacy paths it must leave unchanged.

## Findings

- P2 (fixed in this PR), `src/gnc/control/rpo_mpc/lqmpc.jl`: `floor(t/dt)` dropped one sample whenever t/dt fell just below an integer (for example 16.2/0.1), so on those updates the MPC tracked a reference one step behind and commanded alternating corrections. Found from the new controller log; the preview now tolerates the rounding, and a unit test covers update times that trigger it. This changes tracking for every RPO MPC run.
- P3 (documented), manuscript Sec. III.A: the prose says c2 grows and c1 shrinks with η, while the equations give the opposite. The implementation follows the equations and says so in the docstring and the plan record.
- P3 (documented): choices where the manuscript is silent or scale-specific are stated in docstrings: the η-derived control-point count is kept (the warm start is fitted to it), warm-start edges keep d_safe + τ_tol, the warm start skips HyPR post-refinement, and the candidate fuel proxy counts the arrival at rest.
- The legacy mode was checked by running the same seeded inputs on `main` and on this branch: plans, costs, cost histories, cost components, references, retiming profiles, and RRT-Connect and RRT-Connect + Bézier paths are identical.

## Residual Risk

- Clearance to the station is checked at samples of the path against a point cloud, with τ_tol covering the cloud's spacing; it is not a continuous collision certificate, and the MPC has no collision constraint.
- The acceleration limit bounds the tangential term; the centripetal and HCW terms are bounded by the curvature limit and the scenario, and are reported rather than enforced.
- The demo's excluded meshes are named explicitly; a different display model would need its own review.
- The full test suite and Linux CI are still to run.

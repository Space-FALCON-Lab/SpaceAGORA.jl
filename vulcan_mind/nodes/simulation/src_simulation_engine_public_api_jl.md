# simulation/engine/public_api.jl

## Purpose
The public entry points of the engine: `run_simulation` on a `SimulationConfiguration`, and the N-body ephemeris prewarm and load helpers.

## Design & Implementation
`run_simulation` validates through `_require_simulation_configuration`, warns on the deprecated untyped form with `_depwarn_untyped_run_simulation`, and delegates to execution; `prewarm_nbody_ephemeris_cache` and `load_nbody_ephemeris_cache!` expose the setup-time cache builders.

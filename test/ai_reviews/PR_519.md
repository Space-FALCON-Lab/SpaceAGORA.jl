## Findings

The subsequent external review found that MRI's outer error estimate does not
control fast microstep error or stability. The solver guide now documents this
limitation, the need to vary substeps and the outer cap against a single-rate
reference, and the stiff-solver alternative. This is the review's minimum
documentation remedy; it does not add fast error control or make stiff fast
dynamics supported. Independent follow-up review found no P1/P2 in this documentation remedy;
runtime limitations remain as documented.

One shared event timeline avoids
separate subsystem callbacks disagreeing at events. Mounted recoil appears in
the fast partition with its lever-arm torque; the initial exported force agrees
with the assembled model. Unsupported articulated, compliant, robot-arm and
external configurations are refused explicitly.

The production-aware parent is included. New actual DP8 and MRI runs verify that
an empty store with ongoing production stays selected, reaches the requested
horizon and conserves produced, sent, received, stored and lost data. Streamed
interruption tests compare recovered trajectory rows and the resumed schedule;
they do not reconstruct pre-checkpoint schedule history.

# Independent review: public research setup models

## Scope

Expose the existing SPICE ephemerides and solar-radiation-pressure model types
through the supported root setup API. No model implementation changes.

## Changed Files

- `src/SpaceAGORA.jl`: root imports/exports and actual constructor doc bindings.
- `docs/public_api_symbols.jl`: root API inventory.
- `docs/src/user/simulation_configuration.md`: public names and boundary guidance.
- `test/unit/public_setup_api_tests.jl`: root-only research setup regression.

## Findings

An independent reviewer checked the diff and existing backend requirements.
The first test proposal paired active solar pressure with the simple ephemerides
backend; that is deliberately unsupported. The corrected test preserves the
baseline simulation, constructs the SPICE research configuration separately,
and asserts rejection of active solar pressure with the simple backend.
The public docstring now states the kernel/backend requirement. No remaining
source-review blocker was found. The root bindings preserve type identity and
dispatch; no force or ephemerides mathematics changed.

## P1 Assessment

No unresolved P1 finding in this bounded API change. Original research campaign
completion and prediction accuracy are separate qualification work.

## Tests Added/Updated

The final setup/initial-state suite passes 21 checks. Public API surface,
documentation contract and naming gates pass locally. The reviewer inspected
source and test design; the author executed these checks. Remote CI remains
required before merge.

## Residual Risk

The SPICE constructor does not load kernels. Runs must supply kernels covering
the body and epoch. This API repair does not certify the long MPC campaigns,
which retain separate optimizer and numerical-propagation limitations.

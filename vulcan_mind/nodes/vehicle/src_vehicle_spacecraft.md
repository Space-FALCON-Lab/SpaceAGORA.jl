# vehicle/spacecraft/

## Purpose
The spacecraft model: links assembled into a tree with joints, facets, thrusters, magnets and reaction wheels, plus the initial-condition types and the model containers a configuration carries.

## Design & Implementation
`Components` defines `Facet`, `Thruster`, `Magnet` and `ReactionWheelAssembly`; `Assembly` adds them to links with `add_facet!`, `add_joint!`, `add_thruster!` and `add_magnet!`; `model.jl` defines `SpacecraftModel`, `Link`, the initial-condition family (`CartesianInitialCondition`, orbital elements with oblate-altitude helpers) and the `DynamicsModel`, `GuidanceModel`, `NavigationModel` and `ControlModel` effector containers.

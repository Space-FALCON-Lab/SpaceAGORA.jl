# PR 158: preserve requested UTC epochs in SPICE conversion

## Scope

Integrates Claude's epoch candidate `0f03736f` onto main `bf71adc6`. The requested Apollo PDI time was converted 0.9 seconds early by a calendar-to-TAI-to-UTC detour. Formatting the existing millisecond-resolved DateTime directly for SPICE removes that detour in the ephemerides method and the engine fallback. No requested epoch, force model, landing parameter, simple-model clock or public signature changes.

The implementing reviewer inspected the candidate and independently executed the baseline and corrected source. Claude's candidate tests and prior landing rerun are separate retained evidence. This record does not claim a new independent human review or full-suite execution.

## Changed Files

- `src/environment/ephemerides/simple_ephemerides.jl`: one shared ISO UTC-string helper uses the existing millisecond DateTime conversion; the SPICE method calls `utc2et` under its existing lock.
- `src/environment/ephemerides/ephemerides_models.jl`: removes the AstroTime import no longer used by this module.
- `src/simulation/engine/setup.jl`: the flexible resolver calls the same helper in its SPICE fallback, retaining its lock and dispatch behavior.

The other changes add and register the epoch test and retain this artifact. The helper documentation was narrowed to the two SPICE routes; other package time conversions are not claimed to use it.

## Findings

Independent baseline execution on `bf71adc6` sampled 30 times across 1969, the 1971/1972 boundary and 2025. It reproduced a -0.899999976 s offset at the requested Apollo PDI through both routes and a -0.108000040 s offset at 1971-12-31T23:59:59.000. The same samples on corrected source `63634ead` have exactly zero offset from directly parsed requested UTC through both routes.

The candidate test originally required lunar frame/orientation assets merely to furnish an LSK. The integrated test requires only `lsk/naif0012.tls`, honors `SPACEAGORA_SPICE_PATH`, uses the existing tracked kernel loader, and explicitly skips only the SPICE subsection when that asset is absent. An additional pre-1972 boundary case is pinned.

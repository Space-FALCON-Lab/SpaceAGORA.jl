# Contributing to SpaceAGORA

For work on this repository, start with the
[contributor guide and checklist](docs/contributing/index.md). It covers source
ownership, configuration and numerical contracts, runtime isolation, and the
evidence to retain with a change.

- [Architecture and source ownership](docs/contributing/architecture.md)
- [Configuration ownership](docs/contributing/configuration_ownership.md)
- [Documentation policy and release checks](docs/contributing/documentation_policy.md)
- [Canonical architecture and quality contracts](docs/contributing/contracts.md)
- [Optional adapter conformance and release evidence](docs/contributing/adapter_maintenance.md)
- [GNC and planning ownership](docs/contributing/gnc_ownership.md)

If you are adding a model in your own project, use the public
[extension guide](docs/src/extensibility.md) and
[API compatibility reference](docs/src/public_api_policy.md). The published user
site explains supported use; contributor procedures remain here in the repository.

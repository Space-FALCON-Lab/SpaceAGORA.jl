Constellations API

This page documents the supported public interface available from SpaceAGORA.

Constellations

SpaceAGORA.SimulationModel.SpacecraftModels.OrbitalPlane — Type
OrbitalPlane(; a, e=0.0, i, Ω, ω=0.0, M)

One orbital plane of a constellation: the semimajor axis a (m), eccentricity e, inclination i, RAAN Ω and argument of periapsis ω (degrees) its spacecraft share, and the mean anomaly (degrees) of each of its slots, in slot order, as M. Lay out a constellation from planes with build_constellation; walker_planes gives the planes of a Walker pattern.

source
SpaceAGORA.SimulationModel.SpacecraftModels.build_constellation — Function
build_constellation(factory, planes; first_id=1) -> Vector{SpacecraftModel}

The spacecraft of a constellation laid out in planes (OrbitalPlanes), plane by plane and slot by slot. For each slot it calls factory(plane, slot, index), with the plane and slot numbered from 1 and index the spacecraft's position in the returned vector. The factory builds and returns a new SpacecraftModel; the builder then sets on it:

  • the orbit of its slot: an InitialCondition with the plane's elements and the slot's mean anomaly, keeping the attitude q and body rate ang_vel of the factory's own initial condition;
  • id = first_id + index - 1;
  • constellation_slot = ConstellationSlot(plane, slot).

Spacecraft, links, mounted devices and many GNC effectors hold state, so the factory must build them anew on every call. A factory that returns the same spacecraft twice, or shares a joint, link, mounted device, attachment or mutable GNC effector between two spacecraft, is refused.

source
SpaceAGORA.SimulationModel.SpacecraftModels.walker_planes — Function
walker_planes(; total, planes, phasing, a=nothing, altitude=nothing, planet=nothing,
              e=0.0, i, ω=0.0, raan0=0.0, M0=0.0, pattern=:delta) -> Vector{OrbitalPlane}

The planes of the Walker constellation i: total/planes/phasing: total spacecraft in planes equally populated planes, all at inclination i (degrees).

  • Plane j (from 0) has RAAN raan0 + j * spread / planes, where the spread is 360° for pattern=:delta and 180° for pattern=:star.
  • Slot k (from 0) of plane j has mean anomaly M0 + k * 360 / s + j * phasing * 360 / total (degrees, reduced to [0, 360)), with s = total / planes slots per plane. phasing is an integer from 0 to planes - 1.
  • Give the semimajor axis a (m), or the altitude (m) above the equatorial radius Rp_e of planet.

e and ω (degrees) are shared by every plane.

source
SpaceAGORA.SimulationModel.SpacecraftModels.walker_constellation — Function
walker_constellation(factory; total, planes, phasing, first_id=1, kwargs...) -> Vector{SpacecraftModel}

The spacecraft of a Walker constellation: build_constellation(factory, walker_planes(; total, planes, phasing, kwargs...); first_id). For example, a Walker delta 53°: 24/3/1 at 550 km:

factory(plane, slot, index) = begin
    bus = Link(root=true, m=150.0)
    SpacecraftModel(root=bus, links=[bus], inertia_tensor=bus.inertia)
end
spacecraft = walker_constellation(factory; total=24, planes=3, phasing=1,
    altitude=550e3, planet=planet, i=53)
source
SpaceAGORA.SimulationModel.SpacecraftModels.ConstellationSlot — Type
ConstellationSlot(plane, slot)

Where a spacecraft sits in a constellation: its orbital plane and its slot in that plane, both numbered from 1. build_constellation and walker_constellation set it on each spacecraft they build, as spacecraft.constellation_slot; any other spacecraft has nothing there.

source
SpaceAGORA.SimulationModel.SpacecraftModels.scoped — Function
scoped(effector, scope) -> ScopedEffector

A dynamic effector, as an entry of a DynamicsModel's effector tuple, that acts only on the spacecraft scope names: BoundSpacecraft(positions), a SpacecraftSelection (by position, id, constellation plane or slot, or a predicate), or AllSpacecraft(), which is the same as no scope.

DynamicsModel(spacecraft, (
    InverseSquaredJ2GravityModel(),
    scoped(AerodynamicCoefficientConstant(), SpacecraftSelection(planes=1)),
))

Outside its scope the effector does not exist for that spacecraft: it is not evaluated, samples no environment, adds no force or torque and writes no diagnostics there, on every solver route. The run resolves the scope to run positions once, when it starts, and its configuration then holds the effector itself with the resolved positions (see DynamicsModel). A CoupledSpacecraft scope is refused: a force model acts on one spacecraft at a time, and forces between spacecraft are interlinks.

source
SpaceAGORA.SimulationModel.SpacecraftModels.ScopedEffector — Type
ScopedEffector

A dynamic effector with the scope scoped gave it: the effector itself in effector, and the spacecraft it acts on in scope. Build one with scoped.

source
SpaceAGORA.SimulationModel.SpacecraftModels.SpacecraftSelection — Type
SpacecraftSelection(; positions=nothing, ids=nothing, planes=nothing, slots=nothing, where=nothing)

The spacecraft of a run that meet every criterion given; give at least one.

  • positions: run positions, from 1, in the order of DynamicsModel.spacecraft.
  • ids: spacecraft ids.
  • planes: constellation planes, matched against spacecraft.constellation_slot.plane (build_constellation sets the slots).
  • slots: constellation slots, as ConstellationSlots or (plane, slot) pairs.
  • where: a function (position, spacecraft) -> Bool, called once per spacecraft when the run starts.

Each criterion takes one value or a collection (planes=1, ids=101:108). A run resolves the selection to run positions once, when it starts, and refuses a selection that names an id no spacecraft or two spacecraft hold, a plane or slot no spacecraft holds, or a position outside the run. Use it as the scope of scoped.

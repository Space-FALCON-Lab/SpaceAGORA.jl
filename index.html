SpaceAGORA Documentation

SpaceAGORA is a Julia toolkit for spacecraft orbit and atmospheric-flight simulation. This site is organized for three audiences:

  • users who want a first successful run
  • users who need command, API, or extension reference material
  • maintainers working on package surface, documentation, and repository rules

Start in under a minute

Use this path if you want the fastest successful run on a machine that does not have GRAM or SPICE configured yet.

git clone https://github.com/Space-FALCON-Lab/SpaceAGORA.jl
cd SpaceAGORA.jl
julia --project=. -e "using Pkg; Pkg.instantiate()"
julia --project=. examples/AGORA_Basic_Quickstart.jl

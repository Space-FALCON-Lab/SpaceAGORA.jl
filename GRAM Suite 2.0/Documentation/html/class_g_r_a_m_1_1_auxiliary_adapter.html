Detailed Description

A container interface for multiple auxiliary atmospheres.

Inheriting the AuxiliaryAdapter class will give an atmosphere class the ability to add and utilize mulitple auxiliary atmospheres. The order in which AuxiliaryAtmospheres are added, with addAuxiliaryAtmosphere(), is important. If A is added before B, then the current AtmosphereState is faired with A. The result is then faired with B. The fairings are performed by calling updateAuxiliaryAtmosphere().

Performs an update() on each auxiliary atmosphere.

In the order in which atmospheres have been added to the list, each atmosphere gets the position and the current state (as recieved from the previous atmosphere). The atmosphere is updated and the current state is retrieved.

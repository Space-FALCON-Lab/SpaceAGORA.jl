Set the MGCM dust levels.

For the MGCM model, dust optical depths may be controlled using this method. For a constant dust optical depth. set constantDustLevel between 0.1 and 3.0. For a seasonal effect, set the constantDustLevel to 0 and set minDustLevel (at Ls = 90) and maxDustLevel (at Ls = 270).

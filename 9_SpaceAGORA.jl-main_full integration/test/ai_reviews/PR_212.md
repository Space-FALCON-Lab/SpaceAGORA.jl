## Findings

The original depot job
[111716496900](https://github.com/Space-FALCON-Lab/SpaceAGORA.jl/actions/runs/37295771008/job/111716496900)
and nightly job
[111716496527](https://github.com/Space-FALCON-Lab/SpaceAGORA.jl/actions/runs/37295771013/job/111716496527)
failed authentication to private dev-GRAMSuite after package precompilation,
before scientific tests. Neither sampled log establishes a Base64 compatibility
failure. Skipped shards and missing-report failures follow the failed setup.

`Project.toml` already requires `julia = "1.12"`; README installation guidance
and hosted workflow setup also use Julia 1.12. Under
[Pkg compatibility semantics](https://pkgdocs.julialang.org/v1/compatibility/),
this declares Julia >=1.12.0 and <2.0.0. The new Base64 range declares Base64
>=1.11.0 and <2.0.0. It is not a request to run SpaceAGORA on Julia 1.11.

The committed manifest already records Base64 1.11.0. Official
[Julia 1.12.0 Base64 metadata](https://github.com/JuliaLang/julia/blob/v1.12.0/stdlib/Base64/Project.toml)
also records Base64 1.11.0. Local Julia 1.12.3 loads Base64 1.11.0. The new bound
therefore admits the bundled standard library at the documented Julia baseline
and the locally tested runtime. Julia 1.11 and earlier were already outside the
root project's declared support; this change does not lower or raise that
existing Julia minimum. Future versions admitted by the ranges are not claimed
to have been runtime-tested by this review.

Existing source usage is limited to standard `base64encode` / `base64decode`
calls for viewer payloads, data URLs and mesh buffers. This PR changes their
compatibility declaration, not their implementation or the manifest version.
No compatibility blocker was found in the bounded review and checks below.

## Tests Added/Updated

No permanent tests were added or weakened for this metadata-only change.
A focused check used Julia 1.12.3, the candidate's Project/Manifest files and
its bundled Base64 1.11.0, in offline package mode:

- Parsed both compatibility ranges with Pkg's version-specification parser.
- Verified Julia 1.12.0 and the running Julia 1.12.3 satisfy the Julia bound;
  Julia 1.11.9 and 2.0.0 do not.
- Verified Base64 1.11.0 and the loaded Base64 version satisfy the new bound;
  Base64 1.10.0 and 2.0.0 do not.
- Verified the committed manifest's Base64 version equals the loaded version.
- Verified fixed encoding and decoding of `SpaceAGORA`, plus lossless round-trip
  of all 256 byte values.

Result: **13/13 pass**. The existing `test/gates/ci_project_compat_gate.jl`
also reports `project_compat_gate_ok`. These are bounded metadata/API checks,
not a simulation campaign. Full fresh hosted CI remains required.

## Residual Risk

This author review does not replace full CI, final integration review or
post-merge verification. Supported-range membership is distinct from testing
all releases in that range. Hosted checks continue to target Julia 1.12;
older Julia releases are not newly supported. A manual rerun of the original
Dependabot run keeps its original restricted context. This repair starts a new
maintainer-triggered run without changing the underlying credential stores.

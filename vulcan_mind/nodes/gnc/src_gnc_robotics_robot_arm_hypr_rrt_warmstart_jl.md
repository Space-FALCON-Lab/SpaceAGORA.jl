# gnc/robotics/robot_arm_hypr/rrt_warmstart.jl

## Purpose
RRT-Connect in joint space to seed the arm swarm with a collision-free trajectory.

## Design & Implementation
Joint-space random states within limits, nearest queries, steering, collision-checked extension by sampled forward kinematics, bidirectional connect, shortcutting and resampling to the swarm's waypoint count; diagnostics record whether a path was found.

About the GRAM Interfaces

Interfaces have been developed for C++, C and FORTRAN. The GRAM atmosphere models are designed around a common C++ framework. The C and FORTRAN interfaces are wrappers around the C++ implementation. The call patterns and data structures of all three interfaces are very similar. And since all of the GRAM models share a common framework, they operate in a unified form. The unified interface is detailed below with the details about model specific parameters following.

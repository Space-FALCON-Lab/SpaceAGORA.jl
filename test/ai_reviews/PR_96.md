# AI Review — PR #96: Delete dead helpers and the dev-only hot-reload plumbing

## Scope

Phase A item "dead helpers" of the September 2026 structure audit. The PR deletes definitions that have no reference anywhere in the tracked tree (module-qualified uses included) other than tests written to cover them, and removes the `SPACEAGORA_DEV_HOT_RELOAD` / `Base.invokelatest` plumbing that duplicated every guidance, navigation and control hook call behind an environment flag. Files under active change in PR #90 (engine scheduler, `src/parallel`, `solver_policy.jl`, `runtime_types.jl`) were deliberately left alone, as were dead helpers whose deletion would sit next to hunks on the RL or Gen-EDG branches. Reviewed: every deleted definition against a whole-tree search, the four modules that include `quaternion_utils.jl`, the callback call graph for the hot-reload removal, and the updated tests.

## Findings

- P3 — Three removed functions could never have executed (`srp!`, `get_magnetic_field(::DateTime, …)`, `heat_rate_control_firing_plan` each reference a global that does not exist); their removal turns a latent `UndefVarError` into nothing.
- P3 — The hot-reload flag was read straight from `ENV` in `registry.jl`, outside the adapter files that `ci_architecture_contract_gate` scans, and its `true` branch forced the control-callback thread policy off. Because `run_simulation` is invoked from top level, methods redefined between calls are already visible without `invokelatest`; nothing in the repository documented a workflow that needed the flag.
- Behaviour preserved: every remaining call site dispatches exactly as the former "production" branch did. Thread-decision helpers lose an argument; the two tests that called them with the removed argument (suite 02, `coverage_threaded_probes.jl`) are updated, and the probe assertions that only existed to cover `interp`, `temperature_linear` and the periapsis alias are removed.
- Deliberately not removed here (in files PR #90 rewrites, or adjacent to in-flight hunks): `_DEBUG_COMPARE_J2` in `perturbations.jl`, `_simulation_model_module_for_aero`, the engine's `_state_has_*` helpers, `_prefill_atmosphere_samples!`, `ConstellationInteractionEdgeWorkItem`, `record_route_discard!` and the other parallel-policy items, the `:symplectic` solver mode, and the two unused `SaveCache` fields.

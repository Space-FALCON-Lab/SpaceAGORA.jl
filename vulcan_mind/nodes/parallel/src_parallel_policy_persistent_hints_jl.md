# parallel/policy/persistent_hints.jl

## Purpose
A persistent bandit that remembers which thread allotment was fastest for each workload signature and proposes it on the next run.

## Design & Implementation
Workload signatures bucket item counts and budgets; candidate allotments are powers of two plus the cap; `_hint_choose_allotment` explores under-sampled candidates then picks the lowest confidence-bound mean; observations update per-signature statistics; the state is loaded once and saved atomically at exit as TOML.

# simulation/engine/config/

## Purpose
The typed engine configuration: solver choice, parallel settings, runtime policy and artifact output, as an alternative to environment variables.

## Design & Implementation
`SimulationEngineConfig` aggregates `SolverConfig`, `ParallelConfig`, `RuntimePolicyConfig` and `ArtifactConfig`; each mirrors a family of environment variables with validated fields and defaults.

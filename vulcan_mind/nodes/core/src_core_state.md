# core/state/

## Purpose
The configuration and reference-system types a run is described by: `SimulationConfiguration` and its sub-configs, initial conditions, clocks, and the no-GRAM presets.

## Design & Implementation
`simulation_configuration.jl` defines `SimulationSettings`, `MissionConfiguration`, `EnvironmentModel`, `IntegrationTolerances`, `SolverConfig`, `InitialTime` and the aggregate `SimulationConfiguration`; `ReferenceSystems` names the frames; `NoGramPresets` builds a runnable environment without GRAM or SPICE assets.

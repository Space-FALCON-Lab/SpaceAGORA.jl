Detailed Description

Set user defined the initial perturbations.

Typically, the initial perturbations are randomly derived in the Earth model. Calling this method allows the user to set those initial perturbations.

Parameters
densPertInitial density perturbation value \([\text{\% of mean}]\).
tempPertInitial temperature perturbation value \([\text{\% of mean}]\).
ewPertInitial eastward velocity perturbation value \([m/s]\).
nsPertInitial northward velocity perturbation value \([m/s]\).
verticalPertInitial upward velocity perturbation value \([m/s]\).
atmosAn Earth atmosphere handle.

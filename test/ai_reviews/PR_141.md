# PR 141: regional terrain queries

## Scope

Extract the terrain grid, query and local-file layer from Evan's PR121 (`cc891c76`) onto main `f0ccc21`. Regional planetocentric latitude/east-longitude queries return metres above an explicit reference sphere. Landing, altimetry, plume physics, viewer terrain, native atmosphere and mission assets are separate changes. Evan's attribution is retained.

## Changed Files

- `src/environment/terrain/terrain_models.jl`: canonical owner for grids/models, bilinear queries, longitude coverage, explicit datum consistency and strict local loaders.
- `src/core/types/abstract_types.jl`: the documented terrain extension interface.
- `src/core/simulation_model.jl`: include/reexport the terrain owner without adding aggregator behavior.
- `src/SpaceAGORA.jl`: root imports, exports and documentation forwarding to the owners.

## Findings

Independent bounded source review found no remaining blocker. Corrections made before final acceptance include: reject nonfinite and unrepresentable grids; reduce huge longitudes without loops; test canonical longitude intervals before shifting so just-outside seam queries are not rounded onto an edge; require resolvable cell centres; retain a model's datum on owned grids; and reject mismatched header, site-entry or explicit query radii. The raw local data are explicitly decoded as little-endian Float32 with validated dimensions and exact length. No default Moon radius is inferred.

The implementation and test/guide preparation were split between two agents. A separate reviewer checked the numerical, ownership, datum and binary contracts; root executed the package tests and contract gates. Review is bounded to this query/file layer, not the residual PR121 mission features.

## Residual Risk

Full-globe grids, NaN holes/nodata filling, ellipsoidal height conversion, automatic map downloads and scientific registration of mission assets are unsupported here. Grid bounds are outer cell edges, samples are cell centres, edge half-cells clamp to the edge samples, and the first covering grid wins. Known radii must match exactly after Float64 conversion. Normalized western bounds are stored in [0,360), and the eastern bound may exceed 360. Source arrays are copied, but exposed model/grid arrays remain mutable and must be treated as read-only after construction. No allocation, speedup, native-GRAM, propagation or viewer-parity claim is made.

# gnc/guidance/rpo/hypr/path_sampling.jl

## Purpose
Discretises candidate paths — Bezier or polyline — at fixed or clearance-adaptive spacing for cost evaluation.

## Design & Implementation
Fixed samplers for both curve types, the adaptive spacing law and its minimum near obstacles, per-segment adaptive sampling, a Bezier speed estimate for parameter stepping, and `rpo_sample_path` as the single configured entry point.

Detailed Description

Common values for the Uranus atmosphere models.

Common values for the Uranus atmosphere models. All Uranus atmosphere models should inherit this class.

(1) Data from Lindal, G.F.; Lyons, J.R.; Sweetnam, D.N.; Eshleman, V.R.; Hinson, D.P.; and Tyler, G.L.: "The Atmosphere of Uranus: Results of Radio Occultation Measurements with Voyager 2", Journal of Geophysical Research, Vol. 92, No.A13, pp. 14, 987 - 15, 001, December 30, 1987.

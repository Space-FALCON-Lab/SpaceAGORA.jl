## Findings

The original PR121 combined display and physics work and had failing docs, stale dependencies, an incomplete review artifact, and an unsafe native-GRAM reconstruction path after serialization. This extraction does not import that reconstruction. It does not claim those defects have been fixed on the original branch.

The original Sun/thruster fields were added even with visualization disabled. They are now opt-in and included once alongside other viewer fields when an explicit save-field list is supplied. Scene/result-directory builders inherit all configuration fields through the existing helper; tests cover typed solver and file paths.

New user documentation describes a no-GRAM first run, output locations, approximate standalone frames, illustrative heating/pressure overlays, and spherical periapsis ensemble labels. Display geometry does not become an aerodynamic model. The automatic atmosphere profile is restricted to the verified pure built-in exponential and piecewise exponential models. Other models retain the shell and saved trajectory density without any new atmosphere queries; supplying integrator parameters does not enable sampling. Only an explicit standalone low-level opt-in can sample another model. Its profile reference is latitude/longitude/time zero.

The Monte Carlo viewer assigns separate checkpoint directories through the existing ensemble settings helper and preserves typed solvers/configuration fields. A two-sample resume regression was added. Python 3.9 standalone assembly works without an extra TOML dependency. Exact mp4-muxer 5.1.5 licensing is retained in source and generated HTML.

## Residual Risk

The renderer is substantial third-party and project JavaScript. This extraction retains five reusable 4k planet textures and one ISS example mesh, totaling 11,493,353 binary bytes; research-specific spacecraft meshes and 8k tiers are deferred. Automatic scene export does not query native or arbitrary atmosphere models; only verified pure analytic profiles are sampled. The explicit standalone live-sampling option can mutate model state and is not used by scene/run export. Display-derived heating and dynamic pressure are illustrative and should not be used as the validated scientific diagnostics. The standalone Sun/frame approximations are not a replacement for saved ephemerides metadata. Optional CDN builds and user-supplied models with external resource URLs can make network requests; offline behavior is limited to embedded assets. Startup/compile cost and output overhead are unmeasured. Native model behavior, checkpoint routing, and numerical identity must be assessed in the stated executed scopes, not promised globally. The new checkpoint regression follows existing index-based campaign identity; callers must preserve sample ordering on resume.

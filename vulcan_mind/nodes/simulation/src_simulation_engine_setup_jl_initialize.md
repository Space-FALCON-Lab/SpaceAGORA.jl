# simulation/engine/setup.jl · _initialize*

## Purpose
The initialisation sequence for shared buffers at run start: workspaces, density caches and model instances, in-atmosphere flags, ephemeris tables, SPICE memo and counters, save caches and the environment snapshots.

## Design & Implementation
Seventeen `_initialize_*!` functions, each resetting or building one buffer family, called in order from `run_simulation` setup. The ephemeris initialisers build, reuse or load tables; the rest resize and clear.
